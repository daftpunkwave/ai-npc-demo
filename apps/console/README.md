# @world-prism/app-console

控制台浏览器宿主，静态资源由服务端 `127.0.0.1:3000/console/` 提供，不新增监听端口。

当前包含：

- 控制台令牌登录与当前角色切换；
- 在线分支跟踪：宿主独立于页面定期读取 `GET /api/v1/session` 核对在线分支，其他会话恢复或重开后侧栏与页面随之更新；
- 运行总览、模块目录/装配详情、模型布局只读与静态校验；
- 时钟暂停/继续/单步、快照创建与在线恢复，在线名册休眠释放名额与恢复名额；
- 事件时间线、Agent 检查器、记忆与观察、turn 证据、artifact 查看和 trace；
- 评估与对比（实验列表、分组指标汇总与 run 报告）；
- 调试队列、归档请求 hash 校验与调试唤醒；
- 按角色禁用页面与服务端重复鉴权。

页面模块可替换；页面隐藏或置灰不能替代服务端权限校验。
