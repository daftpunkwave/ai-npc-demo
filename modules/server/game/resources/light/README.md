# game.resources.light

轻量资源服务。库存点归属于派系与节点，保存数量、预留量与开局基线。

## 边界

- 提供能力：`game.resources`（`exactly-one`，run 作用域）。
- 拥有聚合：`stockpile`。
- 写入入口：`reserve`、`release`、`consume`、`transfer`、`adjust`；资源事件在同一个 authority 事务内发出。
- 开局库存由 `campaign.start` 后续钩子初始化，不发布额外的“库存创建”事件。

## 规则

- 可用量 = `amount - reserved`，预留不得使任一资源超过库存。
- 预留不足返回 `insufficient-resource`；任务取消时由调用方释放预留。
- 消耗默认要求对应预留存在；每日公共消耗使用非预留消耗，不能挤占其他任务预留。
- 展示等级按基线比值：`< 0.3` 短缺、`0.3–1.2` 可维持、`> 1.2` 有余量。

## 参数与限制

- 配置提供短缺与余量阈值，默认 `0.3` / `1.2`。
- 模块不判断谁有权动用库存；委托余额由 world 模块裁决，调用方先校验再调用。
- 转移只改变库存数量与来源预留，不改变目的地预留。
