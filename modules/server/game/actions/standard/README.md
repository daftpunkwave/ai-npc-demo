# game.actions.standard

标准任务服务。负责运输、护送、救援、修复与侦察的派遣、邀请、出发、风险、完成与取消。

## 边界

- 提供能力：`game.actions`（`exactly-one`，run 作用域）。
- 拥有聚合：`task`、`task-invitation`。
- 依赖：`game.world`、`game.map`、`game.resources`、`game.comms`。
- 命令：`task.dispatch`、`task.respond`、`task.cancel`；job：出发、完成、延误完成、运输取消返回。

## 规则

- 派遣按固定顺序校验：参数、授权、队伍状态、能力、起点、运力、参与者、路线、委托余额与库存；第一个失败即拒绝。
- 接受后预留资源并扣减委托余额，按邀请人数决定默认出发延迟；出发时重新检查路线与运力，未回复邀请视为过期。
- 出发时对路径风险道路抽样；延误先发 `TaskDelayed`，累计延误后再完成；受伤角色记录 48 tick，队伍无角色时完成回复整 24 tick。
- 运输、护送、救援与侦察在完成时按规则交付物资或解除阻碍；已进入施工阶段的修复任务取消后不退还已消耗材料。

## 参数与限制

- 模块没有独立配置；任务默认值与风险概率来自规则与内容包。
- 孵化中：行动模块只处理首版五类任务，不实现战斗或被俘。
- 任务查询端口供协议模块判定履约；完成事实以 `TaskCompleted` 事件为准。
