# 势力运营页面

提供时钟暂停、继续、受控单步、快照创建与在线分支恢复入口，以及在线名额面板：展示在线名册状态与部署级名额占用，并提供“休眠并释放名额”与“恢复名额”。所有操作沿用服务端运营角色鉴权、运行版本和 operationId 幂等语义。名册休眠期间继续与单步按钮置灰，服务端同样拒绝这两项操作。休眠与恢复名额的请求携带页面当前的在线分支；其他会话已恢复存档或重开、页面尚未跟上时，服务端按分支不一致拒绝，页面展示该错误，不会作用到页面没有展示的分支。

页面订阅宿主维护的在线身份（世界与分支）。其他会话恢复存档或重新开局使身份变化时，页面中止在途读取、丢弃进行中操作的结果，清掉旧分支的时钟、快照、名额与提示，并按新分支重新读取时钟、快照与名额；旧分支的迟到结果不会展示。
