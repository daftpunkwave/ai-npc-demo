# 建模规格

> 本页是「建模精良」的可执行定义。它不描述风格（风格见[表现与资产方向](../../game/art-direction.md) 第 1 节），只描述**做到什么程度算合格**。
> 所有数字都是**上限**，不是目标值；能省则省，省下来的预算给剪影与磨损。

## 一、七条硬原则

1. **剪影优先。** 25% 缩放、纯黑剪影下仍能认出是什么，才算建模完成；认不出，加多少细节都没用。
2. **一栋楼不超过 3 个材质槽。** 超过就是没做图集，退回。
3. **模块化。** 墙、屋顶、门窗、附属、地基分开做；整栋一体建模只允许用于中继炉与议事厅。
4. **损坏是替换，不是重做。** 每栋楼只做一套完好模型 + 可替换损坏模块。
5. **雪、湿、烟、锈是参数。** 不画死在贴图里；同一栋楼要在四季与三种损坏下都能用。
6. **两级网格。** 建筑构件落在 1m 网格；地块内的占地按 8m 摆放网格计算，不跨地块。
7. **没有无来源的细节。** 每一处磨损、每一根管子都要能回答「它为什么在这里」。

## 二、单位、坐标与轴心

| 项 | 规定 |
|---|---|
| 单位 | 1 单位 = 1 米；不允许「导出时放大 100 倍」 |
| 上方向 | Y 轴向上 |
| 正方向 | +Z 为模型正面；角色面朝 +Z |
| 手性 | 右手系 |
| 建筑轴心 | 底面中心，落在 (0,0,0) |
| 道具轴心 | 重心投影到底面；可悬挂物用挂点 |
| 角色轴心 | 双脚中间，脚底 y=0 |
| 载具轴心 | 履带/轮胎接地面的几何中心 |
| 旋转 | 导出前应用全部变换；缩放必须为 1 |
| 负缩放 | 禁止（会导致法线翻转与光照错误） |

Blender 内为 Z 上、-Y 前；导出 glTF 时由导出器转为 Y 上、+Z 前。**不允许在引擎里手工补旋转**，那说明导出设置错了。

## 三、拓扑

| 项 | 规定 | 检查方法 |
|---|---|---|
| 面类型 | 四边面为主；导出前三角化；允许 ≤5% 三角面用于硬表面收口 | 选择非四边面统计 |
| 三角面预算 | 见第四节；超出即退回 | 引擎统计 / 导出报告 |
| 非流形 | 0 | `Select Non-Manifold` |
| 翻转法线 | 0 | 背面剔除预览 |
| 孤立顶点/边 | 0 | 清理 |
| 重叠面 | 0（贴花除外，贴花用独立面片并偏移 2mm） | 检查 |
| 穿插 | 允许结构内藏，不允许外露穿插 | 转一圈看 |
| 倒角 | 硬表面边缘至少 1 段倒角（0.5–2cm），否则高光会断 | 拉近看高光 |
| UV | 0–1 空间，无重叠（图集除外）；棋盘格 1:1 无拉伸 | 棋盘格贴图 |
| Lightmap UV | UV2，不重叠，边距 4px | 引擎检查 |

LOD 比例上限：LOD1 ≤ LOD0 × 45%，LOD2 ≤ 16%，LOD3 ≤ 6%。超过说明减面没做，只是复制。

### 4.2 角色

| 级别 | LOD0 | LOD1 | LOD2 | LOD3 | 材质槽 | 贴图 | 骨骼 | blendshape |

| B 级 | 30,000 | 13,000 | 4,800 | 1,800 | 4 | 2K ×2（身/配件） | 68 | 12 |

### 4.4 纹素密度

| 资产 | 密度 | 说明 |
|---|---|---|
| 角色脸部 | ≥ 4,096 px/m | 头骨 0.25m，用 2K 脸部贴图 |
| 角色身体 | 512–1,024 px/m | — |
| 建筑（主立面） | 256 px/m | 2K 覆盖 8m 墙面 |
| 建筑（地标） | 512 px/m | 4K |
| 道具 | 256 px/m | — |
| 群众 | 128 px/m | 拉近看会糊，这是有意的 |

检查方法：贴一张 1m×1m 棋盘格，数格子；偏差超过 ±15% 即重做 UV。

## 五、材质

### 5.1 PBR 通道

| 通道 | 规定 |
|---|---|
| Base Color | sRGB；不含光照与阴影；金属的底色是反射色，不是黑 |
| Roughness | 线性；布 0.8–0.95、木 0.6–0.8、锈 0.7–0.9、湿石 0.25–0.45、抛光金属 0.15–0.3 |
| Metallic | 0 或 1 为主；避免 0.3 这种「脏金属」 |
| Normal | OpenGL 格式（+Y）；强度 0.6–1.2；不做假细节 |
| AO | 烘焙进独立通道或顶点色；不叠加在 Base Color 里 |
| Height/Displacement | 仅地标与近景建筑使用；其余用 Normal |

### 5.2 图集与 Trim Sheet

**建筑主材走 Trim Sheet**：一张 2K 竖向长条，横向分格（石、混凝土、铁皮、木、玻璃、铜、涂装金属），纵向分三层（上/中/下磨损）。所有墙体、屋檐、裙边从同一张 trim 取 UV，这是把 84 个建筑形态压进预算的唯一办法。

| 材质库 | 内容 | 数量 |
|---|---|---:|
| `trim.architecture` | 墙、屋檐、裙边、勒脚、栏杆 | 1 张 2K |
| `trim.metal` | 铁皮、铆接、格栅、管件 | 1 张 2K |
| `trim.wood` | 木板、梁、门、栈道 | 1 张 2K |
| `trim.fabric` | 帆布、麻袋、旗、绳 | 1 张 1K |
| `trim.nature` | 苔、根、树皮、菌 | 1 张 2K |
| `decal.damage` | 烟熏、水渍、锈流、弹孔 | 1 张 2K 图集（4×4） |
| `decal.signage` | 编号牌、警示条、价牌（文字不可读） | 1 张 2K 图集 |

### 5.3 动态参数（必须做进 Shader）

| 参数 | 范围 | 影响 | 用在哪 |
|---|---|---|---|
| `snowAmount` | 0–1 | 朝上的面积雪，边缘结霜 | 所有室外资产 |
| `wetness` | 0–1 | 降低粗糙度、加深底色 | 地面、墙脚、屋顶 |
| `sootAmount` | 0–1 | 烟囱口与炉边的黑 | 热站、工坊、矿井、中继 |
| `rustAmount` | 0–1 | 从下往上的锈流 | 铁皮、管道、闸门 |
| `frostAmount` | 0–1 | 白障时的整体结霜与能见度 | 全城 |
| `emissiveHeat` | 0–1 | 热站的橙、温室的补光 | 热相关建筑 |

**为什么必须做参数：** 本作一季 28 日，玩家会反复看到同一片街区从干到湿、从湿到雪、从雪到白障。画死贴图的做法在第二次寒潮就会穿帮。

## 六、LOD 与性能

| 项 | 规定 |
|---|---|
| LOD 数 | 建筑 4 级、角色 4 级、道具 3 级、群众 3 级 + impostor |
| 切换阈值 | LOD0 >25% 屏高；LOD1 25–10%；LOD2 10–4%；LOD3 <4% |
| 阴影 | 只有 LOD0/LOD1 投影；LOD2 以下不投影 |
| 全城视角 | ≤1,500 draw call；≤120 万三角面 |
| 街区视角 | ≤400 draw call；≤80 万三角面 |
| 群众 | 实例化渲染；同屏 ≤120 个；超过用 impostor |
| 贴图显存 | 首版 ≤2.5 GB（含 UI） |
| 半透明 | 温室玻璃、烟、雾；同屏半透明层 ≤6，避免过度绘制 |
| 遮挡 | 建筑内部不建（除 4 个室内场景）；屋顶单独成件以便「掀顶」 |

## 七、模块化建筑套件

### 7.1 网格与模块

| 项 | 规定 |
|---|---|
| 网格 | 构件 1m × 1m × 1m；占地按 8m 摆放网格（1×1 至 3×2），不跨地块 |
| 墙高 | 3m（单层）、4m（厂房）、3.2m（民居） |
| 墙宽 | 2m / 4m 两种；转角件单独做 |
| 屋顶 | 15° / 30° / 45° 三种坡；平顶带女儿墙 |
| 门窗 | 1m × 2.1m（门）、1.2m × 1.4m（窗）；工业卷帘 3m × 3m |
| 附属 | 烟囱、通风帽、管道、外梯、雨棚、招牌、天线 |
| 地基 | 0.3m 高石基；雪地加 0.1m 雪裙 |
| 对接 | 所有构件带 snap 点，命名 `snap.wall.a`、`snap.roof.ridge` |

### 7.2 三级加建规则

| 级 | 变化 | 玩家要看到什么 |
|---|---|---|
| 一级 | 基础体量 + 一个附属 | 「刚建起来」 |
| 二级 | 加一层或加一翼 + 第二个附属 | 「这栋楼在长」 |
| 三级 | 加塔/连廊/设备平台 + 专属装置 | 「这栋楼是这一带的中心」 |

**反例：** 把一级模型整体放大 1.2 倍当二级。这会让门窗比例失真、和相邻建筑对不齐，玩家一眼看出是假的。

### 7.3 套件数量

| 类别 | 件数 |
|---|---:|
| 墙体（含转角、勒脚、女儿墙） | 24 |
| 屋顶（3 坡 × 3 材质 × 平/坡） | 18 |
| 门窗（门 4、窗 6、卷帘 2、天窗 2） | 14 |
| 附属（烟囱 4、管 6、梯 3、雨棚 3、招牌 4、天线 3） | 23 |
| 地基/台阶/坡道 | 9 |
| 损坏件（屋顶 3×4、墙 3×3、门窗 3） | 24 |
| 施工件（脚手架 3 态、围挡、料堆） | 8 |
| **合计** | **120** |

## 八、损坏态

| 状态 | 模型处理 | 贴花 | 玩法读数 |
|---|---|---|---|
| 完好 | 基础模型 | 无 | 100% 产出 |
| 受损 | 换屋顶（破洞/塌角）+ 换 1–2 扇窗（钉板/碎）+ 加裂缝 | 烟熏、水渍 | 50% 产出；热需 +1 |
| 损毁 | 只留墙基 + 焦黑梁 + 塌落堆 | 大面积烟熏 + 火烧 | 0% 产出；先清墟 |
| 清墟后 | 空地 + 碎石堆 + 雪 | 无 | 可重建 |
| 施工 | 脚手架 + 半成品结构 + 料堆 | 无 | 进度可见 |

**一套损坏模块要能装在 28 类地块建筑上。** 做法：损坏件不按建筑分类，按「屋顶类型 × 尺寸」和「墙型 × 高度」分类；每类建筑在元数据里声明自己用哪套。

## 九、角色

### 9.1 比例

| 种族 | 头身比 | 关键比例 | 禁止 |
|---|---:|---|---|
| 人类 | 7.5 | 肩宽 = 2.2 头；手长 = 0.75 头 | 大头、长腿模特比例 |
| 巡裔 | 8.0 | 颈长 +15%；踝抬高 12cm（趾行）；重心偏后 3cm | 兽头人身、加尾巴（设定没有） |
| 根庭 | 8.5 | 关节粗 +20%；肩颈生苔；无眼白 | 树人、树人脸、藤蔓乱缠 |
| 泊星者 | 8.0 | 头骨延长 8%；鼻梁极小；指节 +1 | 灰外星人、发光皮肤（发光只在配件） |

### 9.2 脸部

- A 级：30 个 blendshape（眉 4、眼 6、鼻 2、嘴 12、颊 2、颌 2、舌 2）+ 15 个口型；眼球独立，虹膜贴图。
- B 级：12 个（眉 2、眼 3、嘴 5、颌 2）；口型用贴图切换或简化 5 口型。
- 群众：无表情绑定；用 2–3 个静态表情头模变体。

### 9.3 服装

| 层 | 内容 | 骨骼 |
|---|---|---|
| 基础层 | 内衣、衬衫 | 跟随身体 |
| 中层 | 毛衣、马甲、围裙 | 跟随身体 |
| 外层 | 大衣、斗篷、罩衫 | 2–4 根布料骨（只做摆动，不做模拟） |
| 配件 | 工具带、护目镜、徽章、围巾 | 挂点 + 1 根骨 |

**不做布料模拟。** 斜俯视里看不出来，性能却要付全额。

### 9.4 三个非人种族的「可信生物学」

- **巡裔**：短毛、背部深色脊线、后掠长耳（3 根骨）、小角芽（角质，非骨）；脚掌宽、趾行；衣服为迁徙而设，能单手系。
- **根庭**：树皮状纹理在关节外侧，苔只在背光面与肩颈；叶状冠（4 片，可动）；无眼白，虹膜占满；孢子囊在锁骨与前臂，只在近处可见（用粒子，不刷在贴图上）。
- **泊星者**：哑光蓝灰皮肤，细颗粒；头骨延长、鼻梁极小；虹膜外一圈冷青；衣物接缝等距如标尺；自发光只在配件与眼部微光。

## 十、动画

| 项 | 规定 |
|---|---|
| 帧率 | 30fps 烘焙 |
| 骨骼 | A 78 / B 68 / 群众 45 / 生物 40；具名角色共用同一套比例模板（除三个非人种族） |
| 根运动 | 战斗与位移用 in-place；载具与迁徙用 root motion |
| 脚部 | 脚掌必须贴地；滑动 ≤2cm；不做 IK 也可以，但要手 K 落地帧 |
| 循环 | 待机/行走/跑步首尾帧一致；循环接缝无跳 |
| 表情 | 口型按文本/音频时长驱动；情绪用 blendshape 组合，不做面部骨骼 |
| 共享 | 48 条共享动画必须能套在全部 A/B 级角色上，不穿模 |
| 极值 | 抬手、下蹲、转身、跌倒四个极值姿势下，衣物与身体不穿模 |

## 十一、载具与生物

- 履带：左右各一条独立骨骼链（≥6 节），转向时差速；不做物理履带。
- 轮式：轮子独立旋转；悬挂 2 根骨；雪地陷车用位移偏移，不改模型。
- 驮兽：脊柱 6 骨 + 四肢 + 耳/尾；负重时背部下沉 3cm、步幅缩短 10%。
- 幼体：不能做成「可爱宠物」；动作慢、重心低、有保护性蜷缩；靠近时孢子粒子增多。

## 十二、导出与接入

| 项 | 规定 |
|---|---|
| 格式 | glTF 2.0（`.glb`）+ 可选 USD；贴图内嵌或同目录 |
| 命名 | 见[总纲第八节](README.md#八命名与-id) |
| 碰撞 | `UCX_<name>`；建筑 8–24 三角面盒/凸包；角色胶囊体；道具单盒 |
| 挂点 | `socket.hand.R`、`socket.hand.L`、`socket.head`、`socket.back`、`socket.waist` |
| 材质命名 | `mat.<asset>.<slot>`；slot ∈ `skin/cloth/gear/hair` |
| 贴图命名 | `<asset>_<channel>_<res>.png`；channel ∈ `BC/N/R/M/AO` |
| 元数据 | 每个资产一份 `model.json`：面数、LOD、材质、占地、挂点、变体、许可 |
| 禁止 | 负缩放、非 1 缩放、隐藏面、双重材质、外链贴图、脚本 |

## 十三、验收

### 13.1 单件十检

1. **剪影**：25% 缩放、纯黑，能认出是什么。
2. **灰度**：去掉颜色，层次仍成立。
3. **磨损**：能说出每一处磨损的成因。
4. **一致**：与同批资产并排，不像来自另一个项目。
5. **预算**：三角面、材质槽、贴图尺寸、LOD 比例全部在表内。
6. **拓扑**：无非流形、无翻面、无孤立点、无重叠面。
7. **UV**：棋盘格无拉伸；图集无溢出；Lightmap UV 不重叠。
8. **材质**：PBR 四通道齐全；金属度非 0.3 灰区；法线无假细节。
9. **动画**：四个极值姿势不穿模；循环无跳；脚不滑。
10. **引擎**：导入无报错；LOD 切换无跳变；draw call 与显存达标。

### 13.2 批次验收

| 批次 | 门槛 |
|---|---|
| P0 建筑 12 类 | 全城视角 30fps（中配）；12 类并排剪影可分 |
| P0 角色 15 人 | 同屏 15 人不掉帧；拉近 1:1 脸部可读；共享动画不穿模 |
| P1 全部建筑 | 84 形态 + 损坏态在 4 个季节参数下无穿帮 |
| P1 全部角色 | 43 具名 + 18 群众同场（最大场景）≤ 800 万三角面 |
| 全量 | 贴图显存 ≤2.5GB；包体 ≤ 首版预算（另定） |

### 13.3 评审节点

| 节点 | 看什么 | 谁签字 |
|---|---|---|
| 灰模 | 剪影、比例、占地、镜头可读性 | 主美 + 关卡 |
| 材质 | 三材质槽、Trim 复用、磨损逻辑 | 主美 + TA |
| 动画 | 共享库套全部角色、极值不穿模 | 动画 + 主美 |

## 十四、禁止清单

- 禁止用整套放大做升级；禁止用换色做新建筑。
- 禁止把雪、湿、锈画死在 Base Color 里。
- 禁止一栋楼 5 个材质槽、一张贴图只服务一个零件。
- 禁止无理由的干净与无理由的脏。
- 禁止非人种族做成「兽头人身」或「人脸上加装饰」。
- 禁止角色穿模、脚滑、循环跳帧进引擎。
- 禁止外链贴图、脚本、负缩放、非 1 缩放。
- 禁止把立绘比例直接搬进 3D（大头娃娃）。
