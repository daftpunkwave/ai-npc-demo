# Q&A：已拍板与待拍板

> 本页记录设计决策。已拍板的条目不再重复讨论；待拍板的条目给出选项与推荐值，未回答时按推荐值执行。
> 最后校准：2964 年·第 1 季第 1 周（第二轮修订：新增多人、资产与计票口径）。

## 一、已拍板（来自玩家最新愿景）

| #   | 问题         | 决定                                                                         |
| --- | ---------- | -------------------------------------------------------------------------- |
| 1   | 玩家选什么开始    | 五个人类派系之一；玩家就是**本派党魁**，是派系领导者，但不是全人类的领导者；不设“前党魁/党鞭”这种内部权力中心 |
| 2   | 议事会票制      | 五派各 1 票，共 5 票；普通法案 **3 票通过**；宪制法案 4 票                                      |
| 3   | 计票口径       | **门槛是绝对赞成票数，不随弃权下降**：普通至少 3 张、宪制至少 4 张。2 赞成 + 3 弃权仍为失败；两派不能单独决定全城 |
| 4   | 玩家的投票权     | 玩家作为党魁**自己决定本派那一票**；8 个支持者代表可以反对、施压、怠工、请辞、倒戈，但不能替玩家投票，也不做正式的内部信任表决 |
| 5   | Agent 总数   | 每局 **15 个上场**：本派 8 名支持者代表 + 其余四派各 1 名党魁 + 三外域各 1 人                         |
| 6   | 本派 8 人是什么  | **支持者代表**，不含玩家；各有职务（工务、物资、医政、治安、配给、通信、档案等）、工作、性格、记忆、打算，可以支持、反对、离开 |
| 7   | 普通工人       | **不是 Agent**；由规则模拟，玩家按班组分配，会产出、生病、死亡                                       |
| 8   | 失败条件       | 8 个支持者不再支持，被其他派系吞并；是否吞并由 AI 决定，不是人数阈值                                      |
| 9   | 吞并的方式      | 其他派系通过挖角、提案、表决/政变接管；不是程序写死的 `support < X`                                  |
| 10  | 其他派系的行为    | 与玩家同构：党魁可指挥本派工人、建造、投票、提案、与所有 Agent 交流、挖角玩家的人                               |
| 11  | 非人势力的行为    | 可通信、贸易、巡逻、袭击、破坏、迁徙；会杀死人类、损毁建筑                                              |
| 12  | 建筑被破坏      | 有受损/损毁两态；需要派人、花材料、花时间修复                                                    |
| 13  | Agent 私下交流 | 玩家能看到**谁和谁见过面**，看不到内容；可以直接问，回不回答由 Agent 决定                                 |
| 14  | 驱逐         | 玩家可以驱逐本派 Agent；需要理由与证据；被驱逐者会带走记忆与关系，可能投靠对手                                 |
| 15  | 行为与工具      | 每个 Agent 有工具带；没有对应 tool 就不能做对应行为；所有副作用经命令网关                                |
| 16  | 世界导演       | 只给三外域下战略指令、发时代任务；不直接命令人类派系、不伪造结果                                           |
| 17  | 叙事         | 不设固定主线；用五印、白障、信号、第六席作为压力与钩子                                                |
| 18  | 表现         | 3D 斜俯视；可旋转缩放；不做贴地第一人称                                                      |
| 19  | 参考作品       | Frostpunk、Cities: Skylines、The Sims、Helldivers、十字军之王                       |
| 20  | Agent 死亡   | **永久死亡**；补位的新 Agent 是**全新 NPC**，有独立记忆、性格、关系，不继承前者的任何东西                     |
| 21  | 时间尺度       | **放慢**：单人默认 20 秒/tick，1 日 8 分钟，1 周约 56 分钟，1 季约 3 小时 44 分；多人同步局压缩为 15 秒/tick（1 日 6 分钟），异步局 12 分钟/tick |
| 22  | 失败之后       | 可以重新开始，也可以**以新身份继续当前世界**；上一回合发生的事成为下一回合的世界观与背景                             |
| 23  | 支持者反对       | **不做内部信任表决**。8 个支持者不支持玩家时，表现为怠工、请辞、倒戈、离开；当 8 席中 ≥5 席离心/敌对/空缺，本派失去合法性，其他派系可以吞并/政变 |
| 24  | 三个非人 Agent | 各 1 个，且**各自是本势力的最高决策者**；长老会/园护会/议会可以建议、制约、拖延，但最终决定由该 Agent 做出 |
| 25  | 多人           | **同城共治**：1–5 名人类各占一个派系席位，空席由 AI 党魁补齐；服务端唯一权威；**Demo 不实现联机**，只预留 `seatId` 与投影接口。见[多人总纲](multiplayer/README.md) |
| 26  | 会话形态       | 两种：**同步长局**（一季 1 场，约 2–3 小时，适合好友局）与**异步长局**（真实时间推进，议事周为同步窗口，适合长线 SLG） |
| 27  | 资产口径       | 3D 斜俯视 + 半拟真 PBR；**28 类地块建筑 ×3 级（+中继炉）**、43 名具名角色、4 个生物群系、120+ 道具；建筑走模块化套件，损坏态用可替换模块。见[资产总纲](assets/README.md) |
| 28  | 建模标准       | 1 单位 = 1 米；建筑 LOD0 三角面预算按体量分档；角色分 Hero/Support/Crowd 三档；纹素密度、材质槽位、LOD 比例与验收清单见[建模规格](assets/02-modeling-spec.md) |

## 二、已拍板的补充（按推荐执行）

| # | 问题 | 决定 |
|---|---|---|
| 29 | 宪制法案门槛 | **4/5**。普通法案 3/5；吞并、修宪、宣战、紧急状态、改变中继最高控制权、驱逐一个派系、改变票制，都要 4/5 |
| 30 | 对话时的时间 | **单人**：对话开始自动暂停，结束恢复。**多人**：世界不停，对话转异步消息；议事周提供同步协商窗口 |
| 31 | 死亡后的补位 | **3–7 日内补位**；新 Agent 从班组头目/外部人物中产生，是全新 NPC，有独立记忆与立场；补位期间岗位执行度 −30% |
| 32 | 遗产局的时间跳跃 | **默认跳 1 季**；玩家也可以选「立即接管」或「跳 1–4 季」 |
| 33 | 多人席位上限 | **5 席**（五派各一）。少于 5 人由 AI 补齐；不允许两个人共用一个席位（避免双人合谋绕过「一票」） |
| 34 | 多人缺席 | 断开 5 分钟进入 **AI 托管**（只做可逆决策）；连续缺席超过 1 个议事周按「弃席」处理，席位转 AI，玩家可回归观战 |
| 35 | 多人公平 | 不出售资源、票数与影响力；只卖外观与战役叙事。席位间不对称是设计（远星最弱），不是付费差异 |
