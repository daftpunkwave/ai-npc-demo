# 数值基线

本页集中列开放世界与序章的初始数值。单位为游戏小时、整数库存与 0–100 的仪表。数据是设计基线，不是调优结论；修改数值属于内容/规则版本变更，需要新 run。序章部分沿用 Demo 的“水闸之前”初态，开放世界部分为本稿新增。

## 1. 时间

| 项 | 数值 |
|---|---|
| 1 tick | 1 游戏小时 |
| 1 日 | 24 tick；`day = floor(tick / 24) + 1` |
| 1 议事周 | 7 日 = 168 tick；议事会固定在每周第 7 日 00:00（t144、312、480…） |
| 1 季 | 28 日 = 672 tick；季末寒潮 3–5 日 |
| 1 年 | 4 季 = 112 日 = 2688 tick |
| 默认速率 | 每 tick 20 秒现实时间；1 日 = 8 分钟；1 周 = 56 分钟；1 季 ≈ 3 小时 44 分 |
| 对话 | 对话开始时自动暂停；结束恢复；阅读与拟条款不限时 |
| 离线 | 运行中断开超过 60 秒自动暂停，不补算 |

## 2. 人口与劳力

| 项 | 初值 | 说明 |
|---|---:|---|
| 总人口 | 480 | 灰港登记人口；不含外域 |
| 劳力 | 300 | 可分配到建筑、工地、队伍 |
| 儿童/老人 | 180 | 不默认入劳力；《童工法》或《学徒法》可改变 |
| 住房容量 | 500 | 开放世界初始目标，布局待验算 |
| 无家可归 | 0 | 寒潮或灾害后上升；> 40 时疾病 +5/日 |
| 移民 | 0 | 收容法案、外域事件、战争难民可增加 |
| 死亡 | 0 | 寒冷、饥饿、疾病、战斗、事故 |

劳力不足时产出按比例下降：`实际产出 = 基础产出 × min(1, 分配人力 / 需求人力)`。疾病每 10 点减少可用劳力 5%；食物保障 < 1 日再减 10%。

### 3.1 城市公库与派系仓

开放世界有两条库存线，不能混用：

- **城市公库**：材料 160、食物 120、供给 60、能源 140、医疗 40。建造、维修、配给、医院与寒潮储备主要从这里出；动用要预算、委托或工务岗位/公社授权。
- **派系仓**：序章的八座仓继续存在，只存供给、能源、医疗三种（数值见 8.3）。派系可以把自己仓里的资源投入工程或交易；材料与食物要先进公库或建仓库后才能由派系持有。

水单列供水账，按日产与日用结算，上限等于初值。城市公库和派系仓只记各自上列的资源。

两条线的意义：玩家想用自己的能源修公地的楼，需要公社或工务岗位点头；想用公库的材料建本派的楼，需要预算或交易。库存从来不只是数字，是权限。 [城建](../gameplay/08-city-building.md) · [协议](../gameplay/03-agreements-and-policy.md)

|---|---|---:|---|

| 供暖覆盖 | 0–100% | 55% | <60% 疾病/不满加速；≥80% 支持加成 |

## 4. 城建

### 4.1 地块与热级

24 个地块，四环各 6 个；中继炉居中不占地。环带热级修正：核心 +2、内环 +1、外环 0、边环 −1。建筑三级；相邻三座同类形成街区，+20% 产出或 +1 保温。

| 热级 | 名称 | 住宅 | 医院/温室 | 工坊/矿井 | 仓库/回收 |
|---:|---|---|---|---|---|
| 0 | 严寒 | 冻伤 | 停机 | 停机 | 停机 |
| 1 | 寒冷 | 疾病 +5/日 | 停机 | 停机 | 低速 50% |
| 2 | 凉 | 疾病 +2/日 | 效率 50% | 正常 | 正常 |
| 3 | 宜居 | 正常 | 正常 | 正常 | 正常 |
| 4 | 温暖 | 不满 −1/日 | +10% | +10% | 正常 |

热级 = 中继基础 + 环带修正 + 热站 + 保温 − 寒潮。中继基础：通信优先 1、均衡 2、供热优先 3；能耗 8/12/16 每日；远程延迟 0/+1/+2 tick；中继日损 0/−1/−2。寒潮 −2，持续 3–5 日。热站覆盖相邻 3 格，3 能源/日；保温 +1，8 材料一次性。

### 5.2a 五人局的开局民意（仅多人）

五人局对开局民意做一次零和重分配，规则与阈值不变，只把“远星一开局就被集火”的概率压下来。2–4 人局按缺席席位数插值，余数给最低支持席。实现入口见[席位与时钟](../multiplayer/01-seats-and-clock.md#九席位平衡补偿)。

## 9. 调优说明

以上均为初始设计值，尚未经过完整试玩。优先观察四件事：3 票是否让玩家每周只能推一项法案；8 个人的支持态势是否让“自己人”成为真正的政治；供热与通信的切换是否形成真实取舍；白障是否能在 28 日内被准备。 [演算与调优](02-examples-and-tuning.md)
