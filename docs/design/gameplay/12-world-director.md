# 世界导演与战略指令

世界导演面向开放世界。序章《水闸之前》的局势压力来自内容包里的定时剧情卡，切片边界见 [00-scope-and-invariants.md — 序章切片范围](../../00-scope-and-invariants.md#1-切片范围)。

《炉边议会》没有固定主线。每一季的冲突由服务端的**世界导演**给出方向：它告诉巡裔（动物谱系）、根庭（植物谱系）、泊星者（地外）「这一季该往哪走」，再由三个阵营的 Agent 按自己的利益解释、执行、拖延或拒绝。玩家看到的不是任务列表，而是一个会自己动的世界。

这套设计参考《绝地潜兵》的全局战役：运营方不是写剧本，而是调压力、给目标、制造戏剧性；玩家不是演员，而是被卷入的第四方。区别在于，本作的基本盘是**单人长局**：服务端面对的不是百万玩家，而是一座城、三个外域与十五个 Agent。多人共治时（1–5 名人类党魁），导演仍然只有一条压力预算、一份日志，不因玩家变多而加码；它只把「这一季让谁动」的判断交给同一套规则。

## 导演是什么，不是什么

| 是 | 不是 |
|---|---|
| 给外域设定意图、姿态、期限与强度 | 直接替外域决定结果 |
| 发布公开的时代任务，给玩家方向 | 写死剧情、强制玩家按顺序做 |
| 注入天气、遗址、疫病、迁徙等世界事件 | 伪造证据、凭空变出资源、绕过世界规则 |
| 观察玩家行为，下一周期调整压力 | 直接命令人类派系投票或改政策 |
| 记录每次指令与 Agent 的解释，供研究对比 | 用「导演想让你输」来制造难度 |

一条硬规则：**导演只能改意图，不能改事实。** 它可以让巡裔「考虑与根庭结盟」，但不能让巡裔凭空多出粮食；可以让泊星者「在灰港北侧试探」，但不能让泊星者的巡逻队穿墙。所有结果仍由世界规则、Agent 决策与玩家行动结算。

三个外域 Agent（追风、青枝、洛）可以由 Agent 自主运行，也可以在服务端控制台由真人接管。接管保留原 agentId，递增 controllerEpoch，旧控制者的晚到命令被拒绝；真人接管不改变世界规则，也不免除预算、红线与日志。 [双端权限与运营](../sources-and-review.md)

## 战略指令

| 字段 | 说明 | 例子 |
|---|---|---|
| 目标 | 一个或多个外域阵营 | 巡裔 + 根庭 |
| 姿态 | 合作、试探、敌对、迁徙、封锁、结盟、渗透 | 结盟 |
| 目标描述 | 这一季想让它做成什么 | 就暖谷北缘的通行与取水达成默契，共同抵制灰港北扩 |
| 期限 | 1–4 周 | 2 周 |
| 强度 | 1 温和 / 2 明确 / 3 强硬 | 2 |
| 资源 | 可选的合法资源注入（有预算） | 巡裔获得 20 药 |
| 可见性 | 隐蔽 / 传闻 / 公开 | 传闻 |
| 底线 | 不得违反的阵营红线 | 不攻击灰港城区、不断根 |
| 理由 | 导演记录为什么下这条指令 | 玩家连续两周扩北，根庭求援 |

指令不是「命令」，更像「这一季的战略气候」。Agent 可以：

- **执行**：按指令调整目标与行动；
- **变通**：方向接受，手段自选（例如不结盟，只做一笔联合工程）；
- **拖延**：口头答应，等更有利的时机；
- **拒绝**：认为违反红线或自身利益，记录理由；
- **反卖**：把指令内容透露给人类，换取好处（这会掉该阵营内部信任）。

每次解释都写入导演日志，研究控制台可回放「指令 → 解释 → 行动 → 结果」的链路。 [研究用途](#研究用途)

## 指令示例

| 指令 | 目标 | 玩家可能看到的信号 | 可能的后果 |
|---|---|---|---|
| 牧道与根庭结盟 | 巡裔 + 根庭 | 两方使节互访；根庭粮价下降；巡裔拒绝单独与灰港签约 | 灰港北扩受阻；三方会谈被两家联手压价 |
| 锚区北侧试探 | 泊星者 | 观测塔扫描变密；北线通信抖动；修复报价上涨 | 边境紧张 +10；砾火要求增兵；误判可能开战 |
| 提前南迁 | 巡裔 | 隘口出现先遣队；畜群提前过境；粮价上涨 | 灰港要在一周内决定开不开路 |
| 暖谷育种 | 根庭 | 根庭寻求材料与热；提出新的粮药交换 | 灰港可用材料换到高产菌株，但要停北排水 |
| 残轨场封锁 | 泊星者 | 残轨场路口设卡；盗采队失踪 | 核心部件断供；黑市涨价 |
| 三方共同储备 | 三方 | 三方同时要求灰港开放仓库 | 寒潮前的外交大考；拒绝会掉三方关系 |

## 时代任务

时代任务是**公开**的。每季初，导演发布一个全城可见的目标，给玩家方向，也给五派一个共同议题。它像《绝地潜兵》的 Major Order：有进度、有期限、有失败后果，但不规定玩家怎么做。

| 例子 | 进度 | 成功 | 失败 |
|---|---|---|---|
| 寒潮前储备 400 食物与 200 能源 | 当前库存/目标 | 全城不满 −10；公社与地生民意 +3 | 寒潮期间饥饿；止戈与地生民意 −5 |
| 让暖谷共用泵站在季末前完工 | 工程进度 | 根庭关系 +15；水务法案更容易通过 | 根庭关系 −10；果园水量 −10 |
| 护送 80% 巡裔南迁队通过隘口 | 已通过/总数 | 巡裔关系 +15；迁徙安全 +20 | 巡裔关系 −20；边境紧张 +20 |
| 查清锚区信号干扰源 | 证据数/所需 | 泊星者关系 +10；通信 +1 档 | 通信持续抖动；远星民意 −5 |
| 寒潮期间把死亡控制在 20 人以内 | 死亡数 | 全城民意 +5；公社 +3 | 不满 +15；可能触发吞并试探 |

> 食物上限初始 300，要完成 400 的目标，至少要建一座仓库或先扩仓；这是导演任务与城建系统的咬合点。能源上限 400，200 的目标不难，难的是同时留出寒潮消耗——导演任务故意把「囤粮」放在比「囤能」更紧的一侧。

时代任务不是强制的。玩家可以选择不追，但世界会按失败结算；也可以选择用另一种方式达成（例如不建泵站，改用根庭的净水合同），只要进度条件满足。 [季节与长局](07-progression-and-replay.md)

## 节奏

| 周期 | 导演做什么 | 玩家看到什么 |
|---|---|---|
| 每周 | 检查外域状态、玩家行动、边境紧张；最多 1 条新指令 | 使节动向、价格变化、传闻、边境事件 |
| 每季初 | 发布 1 个时代任务；重置压力预算 | 世界局势面板出现新目标 |
| 每季末 | 结算时代任务；寒潮；外域季节行动 | 寒潮预警、迁徙、封渠、停修 |
| 危机时 | 可加 1 条紧急指令（消耗双倍预算） | 紧急广播、使节夜访、道路封锁 |

导演有**压力预算**：每周 3 点。强度 1 耗 1 点，强度 2 耗 2 点，强度 3 耗 3 点；同一阵营连续两周被强度 3 指令，第三周强制冷却。预算防止世界一直处于高压，也迫使导演选择「这一周让谁动」。

**紧急指令**不另设预算池：它消耗双倍点数，可以透支下一周；用过之后下一周不得再下任何指令（强制冷却）。所以一条强度 3 的紧急指令实际代价是「本周 6 点 + 下周空白」，不是免费的戏剧性。

## 玩家怎么感知

玩家看不到指令原文。玩家能感知的是：

- **使节行为**：谁来了、谁没来、谁的要求变了；
- **价格与供给**：粮价、药价、修复报价、能源价格；
- **边境动向**：巡逻、设卡、迁徙、哨塔；
- **传闻**：商队、难民、猎人、泊星者技工的说法；
- **情报**：侦察、渗透、窃取得到的片段；
- **公开时代任务**：全城可见的目标与进度。

玩家可以花力气去「读导演」：如果巡裔与根庭的使节连续两周互访，大概率有人在推两家结盟；如果泊星者的修复报价突然翻倍，可能是在为边境摩擦做准备。读懂了，就能提前布局；读不懂，就会被上一课。 [情报](04-clues-and-npc.md)

## 约束与反傀儡

| 约束 | 原因 |
|---|---|
| 不直接命令人类派系 | 人类政治必须由玩家与 Agent 自己走完 |
| 不伪造证据、不凭空加资源 | 世界事实必须可追溯，否则研究无意义 |
| 不违反阵营红线 | 根庭不会断根，巡裔不会圈禁自己，泊星者不会轻易进地面战争 |
| 不设定结局 | 结果由行动与规则结算，导演只调压力 |
| 每次指令留日志 | 可复盘、可对比、可评估 |
| Agent 可以拒绝 | 拒绝本身是有效数据，不是 bug |

如果一条指令连续被三个 Agent 拒绝，导演应该重新评估：是目标不合理，还是压力不够/过头。拒绝不是失败，是世界的反馈。

## 研究用途

这套系统也是研究装置。控制台可以：

- **A/B 对比**：同一初始世界，一组开导演、一组不开，比较 Agent 行为、联盟结构、城市结局；
- **指令风格对比**：温和引导 vs 高压施压 vs 只给时代任务，观察 Agent 的执行/变通/拒绝比例；
- **链路回放**：从指令到解释到行动到结果，逐条查看；
- **成本核算**：每条指令消耗多少模型调用、多少世界资源、产生多少事件；
- **公平性检查**：导演是否偏袒某一方、是否让某一派系永远拿不到票。

研究控制台不进入玩家界面；玩家只看到世界，不看到实验标签。 [平台与研究](../sources-and-review.md)

## 控制台界面

- 左栏：三个外域的状态卡（关系、紧张、资源、当前目标、红线）。
- 中栏：指令编辑器（目标、姿态、描述、期限、强度、资源、可见性、底线）。
- 右栏：本周压力预算、冷却、历史指令、Agent 解释与执行度。
- 底部：时代任务编辑器与进度预览；世界事件注入。
- 回放：按时间轴看「指令 → 外域行动 → 玩家可见信号 → 结果」。

控制台不是上帝模式。它不能改玩家库存、不能改投票结果、不能替 Agent 说话；它只能设定气候，让世界自己下雨。 [双端权限与运营](../sources-and-review.md)
