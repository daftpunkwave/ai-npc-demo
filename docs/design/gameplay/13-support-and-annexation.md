# 支持与吞并

玩家是这一派的党魁，但这一派不是玩家一个人的。玩家手里的一票，由 8 个支持者代表的信任托着。他们不是数值，也不是随从；他们有岗位、有家人、有记性、有底线，也有自己的打算。玩家可以命令他们做事，但不能命令他们相信。

这一页定义：8 个支持者怎么判断玩家、玩家怎么管理他们、其他派系怎么挖走他们、什么情况下玩家会被吞并、以及失败之后世界怎么继续。

> 数字与默认值以[设定速查表](../world/canon.md)为准；议事流程见[议事会](09-council-and-laws.md)；Agent 的日常行为见[Agent 社会](14-agent-society.md)。

## 一、8 个支持者代表是谁

玩家是党魁，不在 8 人之中。每个派系的 8 人结构相同：**1 名资深支持者（名册第 1 行）+ 7 个岗位负责人**（岗位名各派不同，例如公社是工务/物资/医政，砾火是矿场/侦察/军械）。第 1 行的本职各派不同——公社是行政主管，砾火是守备官，地生是生态医师，止戈是调停员，远星是外联译员。以灰港公社为例：

| 岗位 | 姓名 | 管什么 | 最在意 | 最容易被什么激怒 |
|---|---|---|---|---|
| 行政主管 / 资深支持者 | 闻昭 | 党内路线、议事策略、纪律 | 公社的行政权不被架空 | 绕过行政直接跟其他派系交易 |
| 通信 | 伊诺 | 广播、信件、会面记录 | 消息有出处、不冤枉人 | 把传闻当事实公开 |
| 物资 | 温原 | 公库、配给、运输 | 账实相符、预留不被抢 | 同一批货被答应给两个人 |
| 工务 | 陶安 | 建造、修复、热站 | 工程能完工、材料不浪费 | 为了政治面子赶工 |
| 医政 | 穆枝 | 医院、隔离、疾病 | 病人能躺上床 | 把医院当谈判筹码 |
| 治安 | 陆沉 | 民兵、巡逻、边境 | 出了事有人负责 | 无证据的清洗、让民兵送死 |
| 配给 | 阿禾 | 食堂、民意、收容 | 每个人都能吃上饭 | 把死人只当数字 |
| 档案 | 祁录 | 记录、证据、历史 | 任何话都有出处 | 篡改记录、烧档案 |

闻昭是行政主管，不是“前党魁”，也不是玩家的上级。她支持玩家，但也在看玩家能不能坐稳。其他派系同理：AI 控制时，名册第 1 行是党魁；玩家控制时，玩家取代他，他转为资深支持者，没有“前党魁”的特殊权力。

> **8 个人可以和你博弈，但不争党魁。** 他们能反对、谈条件、公开唱反调、怠工、请辞、倒戈、离开；他们不能召开“内部信任表决”，不能罢免玩家，也不能自己坐上党魁的位置。玩家的党魁身份只由两件事结束：被其他派系吞并/政变，或自己死亡/退隐。这样保留了“自己人会反对”的博弈，不引入“内部争权”的第二套政治。

岗位不是固定的：玩家可以换人，但换人会让原岗位的支持者与相关人群不满。每个岗位下面还有 3–8 个具名班组，由规则模拟；他们不是 Agent，但会死、会病、会抱怨。

## 二、支持不是好感

玩家看不到「支持度 67」这样的数字。玩家看到的是五档态势，以及一条理由。

| 态势 | 含义 | 玩家能看到 | 常见原因 |
|---|---|---|---|
| 坚定 | 愿意为你承担风险 | 「他站你这边」 | 你兑现了承诺；你护住了他的人；你和他信同一件事 |
| 观望 | 还没决定，看你接下来做什么 | 「他还在看」 | 你刚上任；你还没碰到他的利益；他在等别人先动 |
| 动摇 | 开始考虑别的选项 | 「他最近和砾火的人走得很近」 | 你忽视了他的请求；对手给了更好的条件；城市在变糟 |
| 离心 | 已经在为自己找后路 | 「他把家属送去了外环」 | 你公开羞辱他；他的班组死了人；他觉得你保不住这一派 |
| 敌对 | 主动反对你，可能已经答应别人 | 「他在公开场合质疑你的投票」 | 你驱逐了他的人；你违背了本派基石；他认为你必输 |

态势不是线性分数，而是**判断的档位**。同一个人可以从「坚定」直接掉到「动摇」，也可以在一次关键事件后回到「坚定」。判断由 AI 完成，输入是结构化的决策简报，输出必须带理由与「什么会改变我的决定」。

### 判断的六个输入

| 输入 | 说明 | 玩家能怎么影响 |
|---|---|---|
| 信念契合 | 玩家的投票、法案、公开表态是否符合他的底线 | 改法案文本、公开解释、承认错误 |
| 利益 | 他的岗位、预算、班组、家人、晋升 | 给资源、给职位、给保护 |
| 关系 | 玩家和他共同经历过什么；是否兑现过承诺 | 履约、道歉、共同项目、记住他的名字 |
| 恐惧/压力 | 城市是否安全；他的班组是否在死人；外域是否逼近 | 修防御、疏散、抢修、公开伤亡名单 |
| 外部诱惑 | 其他派系给了他什么条件 | 加价、揭穿对手、给他对手给不了的东西 |
| 希望 | 他是否相信这一派还有未来 | 通过法案、建成东西、守住寒潮、赢得表决 |

**没有单一数值阈值。** 一个「利益」很高但「信念」被违背的人，可能仍然是「离心」；一个「利益」一般但「关系」很深的人，可能是「坚定」。AI 在决策简报里权衡六项，而不是做加减法。

### 玩家怎么知道自己在哪

| 渠道 | 能看到 | 可靠性 |
|---|---|---|
| 人物册 | 当前态势 + 一条理由 + 最近一次变化 | 高；但理由可能是他愿意说出口的那部分 |
| 本周账本 | 本周谁的态度变了、因为哪件事 | 高；只记公开或玩家亲历的事 |
| 直接对话 | 他愿意说的、不愿意说的、撒谎的 | 中；取决于关系与秘密 |
| 会面痕迹 | 他和谁见过面、何时、何地 | 高；但不知道内容 |
| 第三方 | 别人转述 | 低；有动机 |
| 行为 | 怠工、迟到、公开反对、请辞 | 高；但可能被解释成别的原因 |

## 三、日常管理

8 个人不是每周只在表决时出现。他们每天有工作、有请求、有情绪。玩家的时间有限，所以系统用**请愿队列**控制信息量。

### 请愿队列

- 每日最多 2–3 个请愿上桌；按紧迫度、关系、事件筛选。
- 其余进入「今日简报」，一行一条，玩家可以点开，但不强制回应。
- 紧急事件（死人、袭击、罢工、请辞、通敌）可以插队。
- 玩家不回应请愿，不会立刻惩罚；但连续忽视同一个人 3 次，他会 −1 档。

### 请愿的类型

| 类型 | 例子 | 玩家可以怎么回 |
|---|---|---|
| 要资源 | 「温室缺 20 材料，给我，我本周能产出 18 食物/日」 | 给、拒绝、给一部分、换条件 |
| 要人 | 「我的班组病了 4 个，从阿禾那里调 2 个人」 | 调、不调、让双方自己谈 |
| 要授权 | 「让我签这批运输，不然赶不上寒潮」 | 授权、收回、派人监督 |
| 要说法 | 「为什么把哨塔材料挪去修医院？」 | 解释、承认、反击、沉默 |
| 要保护 | 「砾火的人在我家门口站着」 | 派人、报警、公开、私下解决 |
| 要离职 | 「我想去外环，或者去砾火」 | 挽留、放行、驱逐、加价 |
| 告状 | 「温原把同一批货答应了两个人」 | 调查、相信、压下去、公开 |
| 表白/闲聊 | 「我女儿会走路了」「你上次说的话我记着」 | 回应、记住、忽略 |

### 承诺与兑现

玩家对支持者的承诺也进入账本，但和对外承诺不同：

- **对象**是具体的人，不是派系；
- **内容**可以是资源、职位、保护、公开支持、参加葬礼、记住一个名字；
- **截止**通常更短（1–7 日）；
- **违约**的后果更个人化：该支持者 −1 到 −2 档，且会把这件事告诉别人。

玩家可以改约，但改约会被记一笔；同一个人被改约两次，会开始怀疑玩家。

### 升职与换岗

- 玩家可以给支持者升职（例如让温原兼管运输），提升其能力与利益，但会增加其过载风险。
- 换岗需要理由；被换下的人会 −1 档，接任者需要时间熟悉（前 3 日执行度 −20）。
- 玩家不能随意创造新岗位；岗位由派系结构决定，扩编需要预算案（3 票）。

## 四、反对与博弈

8 个支持者不是橡皮图章。他们可以反对玩家的决策，而且反对是有用的——但反对的方式是**博弈**，不是**争党魁**。

| 反对方式 | 玩家看到 | 玩家能做什么 | 代价 |
|---|---|---|---|
| 公开反对 | 在议事会/简报里唱反调 | 公开辩论、拿证据、私下谈 | 玩家的拉票能力下降 |
| 私下谈条件 | 请愿、会面、递话 | 给资源、给职位、给保护、改条款 | 玩家欠人情/让渡利益 |
| 怠工 | 执行度下降、工期拖延 | 换人、加钱、亲自盯 | 岗位产出下降 |
| 请辞 | 递上辞呈/请假 | 挽留、加价、放行 | 岗位空缺，补位期 −30% |
| 倒戈 | 在关键表决前转向对手 | 最后谈判、揭露、驱逐、找庇护 | 情报/执行/支持流失（不是改票） |
| 离开 | 带走班组/关系/秘密 | 追回、放行、保护性驱逐 | 本派合法性下降 |

**他们不会做的事：**

- 不会召开“内部信任表决”；
- 不会罢免玩家；
- 不会自己坐上党魁的位置；
- 不会为了党魁之位拉帮结派。

玩家的党魁身份只由两件事结束：被其他派系吞并/政变，或自己死亡/退隐。这样保留了“自己人会反对”的博弈，不引入“内部争权”的第二套政治。

### 一个博弈的例子

玩家要投《工业优先法》，砾火的霍岩支持（矿场受益），但公社的陶安反对（工程材料被抢）。陶安不会说“我要当党魁”；他会说：

> 「你要投工业优先，可以。先把医院屋顶的料给我，再把回收场的重建排进本周。否则我签不了。」

玩家可以：

- 答应他，改工程顺序（让砾火不满）；
- 拒绝，让他怠工（工业优先执行度下降）；
- 换人（陶安的支持者 −1 档，工程更慢）；
- 公开辩论（可能说服他，也可能让他公开反对）。

这就是博弈：不是谁当党魁，是**谁为这笔账负责**。

## 五、会面痕迹与怀疑

玩家知道本派 Agent 和其他人见过面，但不知道谈了什么。这是本作最重要的信息不对称，也是「像活人」的核心。

### 会面怎么被记录

| 场所 | 记录方式 | 玩家能看到 |
|---|---|---|
| 议事厅、广场、集市 | 公开场合，人人可见 | 谁和谁在何时同处一处 |
| 酒馆、食堂、医院走廊 | 半公开，目击者多 | 会面事实 + 可能的目击者 |
| 仓库后巷、住宅、党部内室 | 私下 | 只有被监视、被举报、或被巡逻撞见时才记录 |
| 城外、道路、外域节点 | 只有同行者、哨塔、商队知道 | 可能完全不可见 |

记录的最小单位是「会面痕迹」：**谁、和谁、何时、何地、大约多久**。没有内容，没有录音，没有摘要。玩家可以：

| 行动 | 需要 | 效果 | 风险 |
|---|---|---|---|
| 直接问 | 能接触 | 对方可能回答、回避、撒谎、反问 | 问得太频繁，关系 −1 |
| 问第三方 | 有目击者 | 得到转述，可能失真 | 被当事人知道后 −1 档 |
| 监视 | 治安岗位支持、1 名班组、时间 | 得到更详细的会面记录（仍无内容） | 被发现后 −2 档；可能违反本派规矩 |
| 搜查 | 治安支持、理由、证据门槛 | 找到信件、礼物、契约、钱 | 搜错人 −2 档；其他支持者 −1 档 |
| 调记录 | 档案/通信支持 | 查 relay 记录、出入记录、物资领用 | 可能被对方发现你在查 |
| 设局 | 时间、资源、可信的诱饵 | 让对手暴露 | 失败会打草惊蛇 |

### 对方会不会说实话

由 AI 判断，输入：

- 他对玩家的态势（坚定的人更可能坦白）；
- 他有没有把柄在玩家手里；
- 他是否在保护别人；
- 他是否已经答应对手；
- 他是否相信玩家会报复；
- 他是否觉得这件事说出来会伤害玩家。

可能的回应：

- **坦白**：「见了。他问我愿不愿意去砾火，我没答应。」
- **部分坦白**：「见了，谈的是转运单。别的我不能说。」
- **回避**：「就是工作。」
- **撒谎**：「我没见过他。」（玩家可以用会面记录、目击者、物资流水反证）
- **反击**：「你是在审我？我跟你干了多久？」
- **沉默**：不回答，但态度变冷。

**没有「读心术」按钮。** 玩家只能通过交叉验证、证据、关系和试探来判断。研究控制台可以看到完整对话，但玩家界面永远不显示内容。

### 怀疑的代价

怀疑本身会伤害关系。玩家每公开怀疑一个人一次，该支持者 −1 档；如果怀疑错了且没有道歉，−2 档。玩家可以选择**私下问**（伤害小）、**公开质询**（伤害大，但能震慑其他人）、**监视**（可能被发现）、**驱逐**（不可逆）。

## 六、驱逐

玩家可以驱逐本派 Agent。驱逐不是「删除」，而是「把一个人从这一派里赶出去」。

### 驱逐的理由

| 理由 | 需要什么 | 支持者反应 |
|---|---|---|
| 通敌 | 会面记录 + 物证/人证 | 多数人理解；被驱逐者的亲信 −2 档 |
| 泄密 | 证据 + 受害方 | 多数人支持；如果证据不足，其他支持者 −1 档 |
| 抗命 | 两次以上公开拒绝 + 记录 | 一半支持，一半觉得你容不下异见 |
| 腐败 | 账目 + 审计 | 多数人支持；如果他也分过好处，会不安 |
| 政治清洗 | 不需要证据，只需要理由 | 所有人 −1 到 −2 档；支持者加速离心/离开 |
| 保护性驱逐 | 你相信他会被人害，或你想保他一条命 | 他不一定领情；其他人觉得你在流放他 |

### 驱逐的流程

1. **当面宣布**（或书面）。玩家必须给出理由；理由会被记录。
2. **收回权限**：岗位、库存、队伍、档案、住处。
3. **选择去处**：留在城里（成为自由人）、去外环、出城、交给对手（如果你确定他通敌）。
4. **补位**：3–7 日内由一名班组头目或外部人物接任；新人有自己的性格与忠诚，初始态势「观望」，且可能与被驱逐者有关系。

### 驱逐的后果

- **被驱逐者**带走自己的记忆、关系、秘密与一部分支持者。
- 他可能：投靠其他派系（成为该派系的**顾问**，不增加该派 Agent 数，也不增加票数；只给该派提供情报，并在其下一次拉票时给 **+1 次游说加值**）、成为证人、加入外域、或消失在边环。
- 其他 7 人根据理由与关系重新判断玩家；如果他们认为你做得对，可能 +1 档；如果他们认为你过河拆桥，−1 档。
- 被驱逐者的班组可能罢工、怠工、或要求调岗。
- 如果被驱逐者在 8 人中威望极高（例如行政主管），会加速**支持崩解**：其他支持者 −1 档，对手更容易挖角/政变；不会触发正式的内部信任表决。

### 驱逐不是万能

驱逐能解决「眼前这个人」，不能解决「他为什么走」。如果玩家连续驱逐 3 个人，剩下的人会开始想：「下一个会不会是我？」所有支持者 −1 档，且对手的挖角成功率上升。

## 七、支持崩解

玩家最大的对手不一定是其他派系，可能是自己人。但**自己人不会开一场会把你投票赶下台**——他们只是不再替你干活、不再替你说话、不再替你挡刀。当这种「不再」足够多，本派就失去合法性，外面的派系才会动手。

### 崩解的阈值

- **按 8 个席位计算，不按在岗人数计算。** 死亡、请辞、离开、驱逐造成的空缺，在崩解判定里一律视为「无支持」（等同于离心）。
- **≥5 个席位处于「离心 / 敌对 / 空缺」**，即触发条件的一半；
- 且本派没有外部庇护；
- 且至少一个其他派系认为「现在可以动」。

三个条件同时满足，进入**支持崩解**状态。它不是一次表决，是一个持续 3–7 天的政治危机。

> 例：3 人离开（空缺）+ 2 人敌对 = 5，已经满足人数条件；此时即使剩下 3 人「坚定」，本派也已经失去合法性——因为替你干活的人只剩 3 个。反过来，5 人空缺但无人敌对，也照样触发：空椅子本身就是信号。
>
> **补位的意义**：新人在 3–7 日内到岗，空缺消失，态势为「观望」。所以补位不是「恢复支持」，只是把「空缺」换成「观望」，让玩家有机会重新争取。空缺 **=4** 时，本派立即进入「失灵」阶段（执行度 30），但还不算崩解；再有一人离心/敌对才触发。空缺 **≥5** 则直接触发崩解——椅子空了一半，已经不需要再有人反对。

### 补位与叠加

- 一次只补 1 人，按岗位优先级：资深支持者（名册第 1 行）→ 物资 → 工务 → 医政 → 治安 → 配给 → 通信 → 档案。
- 多人同时空缺时串行补位，每人 3–7 日；不并行，避免「一周换半支队」。
- 补位期间的执行度 −30% **不叠加**：多个空缺时取最差岗位的 −30%，不按人数累乘。
- 空缺 ≥4 进入「失灵」后，执行度固定为 30，**不再叠加**补位 −30%；失灵是状态，不是乘数。

### 崩解时会发生什么

| 阶段 | 表现 | 玩家能做什么 |
|---|---|---|
| 1. 失灵 | 岗位执行度掉到 30 以下；请愿没人处理；民兵迟到；公库对不上账 | 换人、加钱、道歉、兑现承诺、亲自盯 |
| 2. 空转 | 2–3 个岗位无人负责；街头开始传「这一派要散了」；对手公开报价 | 找庇护、做最后一笔交易、公开承认问题 |
| 3. 倒戈 | 支持者公开转向对手；关键设施被对手的人接管 | 驱逐挑头者、动员剩余的人、请求外域/其他派庇护 |
| 4. 吞并/政变 | 对手提出 4/5 吸收案，或支持政变 | 最后辩论、接受结局、流亡 |

### 玩家不是被投票赶下台

- 8 个支持者没有「不信任投票」这个工具；他们只能用脚投票：怠工、请辞、倒戈、离开。
- 玩家不会因为「5 票不信任」立刻输；玩家是因为**没有人再执行你的决定**而输。
- 对手也不会自动赢；对手要判断值不值得吞、吞了能不能消化、其他派系会不会干涉。
- 这让失败更像政治，而不是会议室里的一次点数。

### 崩解与吞并的区别

| 项 | 支持崩解 | 外部吞并 |
|---|---|---|
| 谁造成 | 本派支持者不再支持 | 其他派系动手 |
| 形式 | 怠工、请辞、倒戈、离开 | 4/5 吸收案，或政变 |
| 玩家能否挽回 | 能；兑现、换人、找庇护、公开承认 | 能；拉票、交易、揭露、反提案、庇护 |
| 结果 | 本派失去合法性 | 本派被另一派接管 |
| 玩家能否继续 | 可以开遗产局 | 可以开遗产局 |

### 崩解的迹象

- 连续 3 天有岗位执行度 <40；
- 2 个以上支持者同时请辞/请假；
- 街头出现「某某要走了」的传闻；
- 对手开始公开替你的支持者说话；
- 你的民兵/工人开始问「这个月的配给谁签」；
- 有人把家属送出城。

这些迹象不是 UI 上的红色警报，是简报、会面痕迹、食堂的沉默、哨塔的空位。玩家要自己读。

### 玩家最后的牌

| 牌 | 代价 | 效果 |
|---|---|---|
| 公开承认失败 | 声誉 −10，民意支持 −3 | 部分支持者愿意再给一次机会 |
| 兑现一笔大承诺 | 资源/地块/政策 | 1–2 人回到「观望」 |
| 驱逐挑头者 | 支持风险 | 短期震慑，长期加速崩解 |
| 找庇护 | 政策/资源让渡 | 阻止吞并，但成为附庸 |
| 主动流亡 | 失去本派 | 保留性命与部分关系，进入遗产局 |
| 最后抵抗 | 高死亡/高破坏 | 可能保住派系，也可能城毁人亡 |

## 八、外部挖角

其他派系不会等到玩家弱了才动手。它们会持续评估、试探、接触。

### 挖角的目标

对手优先接触以下支持者：

- 态势「动摇/离心」的人；
- 岗位关键的人（物资、工务、治安、通信）；
- 与玩家有旧怨的人；
- 家人安全受威胁的人；
- 相信「这一派迟早要完」的人。

### 对手能给什么

| 诱饵 | 例子 | 玩家能怎么反制 |
|---|---|---|
| 职位 | 「来砾火，给你一个矿场管事」 | 升职、加预算、给独立项目 |
| 保护 | 「你妹妹在外环不安全，搬进我们的院子」 | 派人保护、迁移家属、公开承诺 |
| 资源 | 「这批药给你，不用走公库」 | 给同等资源、查对手资源来源 |
| 理念 | 「公社已经烂了，砾火才是能守住灰港的人」 | 用行动证明本派能守住 |
| 复仇 | 「他驱逐了你的人，你还替他卖命？」 | 道歉、补偿、处理旧怨 |
| 恐惧 | 「白障来了，你觉得他能带你活下来？」 | 展示准备、公开计划、带他一起做 |

### 挖角的迹象

玩家不会收到「XX 正在挖你的人」的通知。玩家能看到：

- 会面痕迹（谁和谁见了面）；
- 支持者突然关心某个议题；
- 请辞、请假、迟到、怠工；
- 公开场合的抱怨或沉默；
- 家属迁移、物资转移；
- 对手在议事会突然替你的支持者说话。

### 挖角的成功

对手不会一次成功。通常需要 2–4 次接触，且满足：

- 目标对玩家至少「动摇」；
- 对手给出的条件比玩家能给的好；
- 目标相信对手能兑现；
- 目标不认为留下会更好。

成功后，该支持者会在一次关键表决前**公开倒戈**（不是改投一票——他本来就没有票；是公开反对、拒绝执行或请辞），或**私下答应对手**（玩家可能直到表决后才发现执行度掉了一半）。

## 九、吞并四阶段

吞并不是一个数值阈值，而是一场政治行动。它分四阶段，每一阶段都有迹象、代价与反制。

### 阶段 1：试探

对手在评估：玩家弱不弱、城市乱不乱、自己吞了会不会撑死、其他派系会不会干涉。

| 玩家能看到 | 对手在算什么 |
|---|---|
| 使节语气变硬、报价变高 | 玩家的资源与支持还剩多少 |
| 公开场合的嘲讽、质询 | 玩家在议事会的盟友是谁 |
| 对手突然关心你的地块/岗位 | 吞并后的利益分配 |
| 对手开始囤粮/扩兵 | 吞并的时机 |

**玩家能做什么：** 修补关系、展示实力（建成一座楼、通过一项法案、守住一次袭击）、找庇护、制造对手的麻烦。

### 阶段 2：挖角

对手开始接触你的 8 人，给出条件。这是最漫长、最隐蔽的阶段。

**玩家能看到：** 会面痕迹、态度变化、请辞、怠工、家属迁移、公开抱怨。

**玩家能做什么：** 问、监视、加价、升职、兑现承诺、处理旧怨、驱逐（高风险）、公开警告对手、找对手的对手结盟。

### 阶段 3：提案

对手在议事会提出「吸收/庇护/托管」案。这是宪制法案，需要 4/5。

| 提案类型 | 内容 | 通过后 |
|---|---|---|
| 吸收 | 你的派系并入对手，8 人按规则并入或离散 | 玩家失去授权，对手获得你的票与地块；**你的印进入封存，吞并者不能用**（多人局：席位转为附庸席，3 人转客卿、5 人离散，见[多人体系](../multiplayer/01-seats-and-clock.md#八被吞并之后)） |
| 庇护 | 对手保护你，但你要让渡一项政策/资源 | 玩家保留授权，但成为附庸 |
| 托管 | 第三方暂管你的派系，直到危机结束 | 玩家暂时失去部分权力，危机后可能恢复 |
| 分割 | 你的地块/岗位被几个派系瓜分 | 玩家保留一个缩小版派系 |

**玩家能做什么：** 拉票（4/5 需要 4 票赞成；玩家自己一票反对，再拉到 1 票反对即可阻止——5 席里 2 票反对就让 4 票赞成不可能达成）、交易、揭露对手的代价、提出反提案、找庇护、动员街头。

### 阶段 4：表决/政变

- 如果提案通过（4/5），玩家失去授权，进入「被吞并」结局。
- 如果提案失败，对手可能转向**政变**：策动 ≥5 名支持者公开倒戈，绕过议事会。
- 政变的条件：≥5 名支持者公开倒戈，且无人庇护，且对手能控制街头/关键设施。
- 玩家在政变前可能收到最后通牒：让位、接受庇护、或流亡。

### 吞并的护栏

| 护栏 | 规则 | 原因 |
|---|---|---|
| 开局保护 | 前 14 天不触发吞并 | 让玩家有时间建立关系 |
| 冷却 | 同一派系两次尝试之间 ≥7 天 | 防止连续追杀 |
| 宪制门槛 | 4/5 | 三派不能合法吞并第四派 |
| 竞争性保护 | 两个派系同时想吞并时，它们互相牵制 | 给玩家操作空间 |
| 风险判断 | 吞并者也要考虑自己的支持、城市分裂、外域趁虚 | 不是「玩家弱就一定吞」 |
| 玩家可参与 | 被吞并的派系在表决中有票 | 不是被动等待 |
| 明确迹象 | 每个阶段都有可观察的信号 | 不是突然死亡 |
| 可逆 | 提案失败后，关系可以修复；政变失败后，对手会受罚 | 不是一次定生死 |

## 十、庇护

庇护是玩家在弱势时的生存选项，也是屈辱的选项。

### 谁能给

- 另一个**人类派系**（3/5 庇护协议，或双方私下协议 + 议事会追认）；
- 一个非人势力（不需要议事会，但需要条约批准 3/5；对方会要求资源、通行、技术或领土）。

**庇护的机制：** 庇护协议通过后 1 季内，任何针对你的吞并提案需要 **5/5**（玩家自己的一票就是否决权；庇护者会公开反对并承担后果）；或者对手只能转向政变。庇护不是免费的，也不是永久的；它把「吞并」变成了「附庸」。

### 代价

| 庇护者 | 常见条件 | 后果 |
|---|---|---|
| 公社 | 让渡水务/配给权；支持公社议程 | 玩家保留党魁身份，但关键投票要顾及公社支持者，否则支持崩解 |
| 砾火 | 让渡边环地块；民兵听砾火调度 | 玩家保留派系，但成为砾火的附庸 |
| 地生 | 停北排水；医院优先收地生病人 | 玩家保留派系，但失去部分水源/医疗自主 |
| 止戈 | 接受收容配额；公开承诺不主动升级 | 玩家保留派系，但军事选项受限 |
| 远星 | 开放锚区道路；技术许可 | 玩家保留派系，但经济受制 |
| 巡裔 | 保证迁徙通道；不建哨所 | 玩家保留派系，但边境防务受限 |
| 根庭 | 保证果园水量；停排水 | 玩家保留派系，但水源受制 |
| 泊星者 | 星图/核心；安全距离入法 | 玩家保留派系，但技术依赖加深 |

### 庇护的代价会累积

庇护不是一次性的。庇护者会在下一次危机中要求更多；如果玩家拒绝，庇护可能撤回，吞并重新开始。玩家可以把庇护变成**真正同盟**（关系 ≥60、共同经历、条约），但这需要时间和兑现。

### 续期与附庸化

庇护默认 1 季。到期后不会自动续，必须重新谈：

| 次 | 条件 | 代价 |
|---|---|---|
| 第 1 次 | 3/5 协议或私下协议 + 追认 | 一项政策/资源让渡 |
| 第 2 次（连续两季） | 庇护者要价 +1 档（多让一项，或同一项加量） | **转为附庸**：本派在宪制表决中必须与庇护者一致；玩家在庇护者 8 人中的「可靠」评价 −1 档 |
| 第 3 次起（附庸续期） | 每次续期再让一项；拒绝即庇护失效 | 当季允许 4/5 吞并 |

- 连续两季接受同一派庇护，自动进入附庸状态；附庸不是失败，但它把「一票」变成了「半票」。
- 玩家可以主动结束庇护，但 1 季内不能再向同一派申请；转向另一派要重新谈，且原庇护者关系 −15。
- 庇护不能与「竞争性保护」叠加：两派同时保护时，只认先签的那一份，另一份视为口头承诺。

这条规则的目的：**庇护是急救，不是免死金牌。** 一个每季都靠庇护活着的党魁，最后会发现自己只是别人的第二张票。

## 十一、失败与遗产局

### 三种失败

| 失败 | 触发 | 结局 | 世界继续吗 |
|---|---|---|---|
| 被吞并（议事会） | 4/5 吸收案通过 | 「被吞并」：玩家成为对手的顾问/流亡者/消失 | 是；城市继续，吞并者掌权 |
| 被吞并（支持崩解） | 8 席中 ≥5 席离心/敌对/空缺，且无庇护；对手政变/接管 | 「被架空/被吞并」：本派失去合法性，玩家保留性命与部分关系 | 是；本派可能被接管，玩家成为自由人 |
| 城市崩溃 | 中继 0 持续 48h，或人口 <200 | 「白障」/「熄炉」：城市死亡或撤离 | 是；残局与难民进入下一局 |

### 编年史

每局结束生成一份**编年史**：

- 存活了多少季；
- 通过/否决了多少法案；
- 建了/毁了多少建筑；
- 死了多少人，名单；
- 谁背叛了你，谁留到了最后；
- 你保护了谁，放弃了谁；
- 城市的最终状态（人口、热覆盖、与外域关系）。

编年史不是分数，是一份可读的账。玩家可以把它带到下一局。

### 遗产局

失败后可以开**遗产局**：

- 同一座城，默认时间跳跃 1 季（可选立即接管或跳 1–4 季）；
- 玩家以**新身份**回到本派（如果本派还在），或成为另一个派系的党魁；
- 世界保留部分关系、承诺、建筑与伤亡记忆；新身份不继承旧身份的记忆与秘密，但会被旧账波及；
- 不继承职位、库存、秘密；
- 上一局的编年史会作为「历史」被 Agent 引用。

遗产局不是读档，是「这座城还记得你」。

## 十二、一个例子：温原的半个钟头

第 3 日傍晚，伊诺在简报里写了一句：「温原在旧仓库后巷见了乔述，约半个钟头。」

玩家有三个选择：

**A. 直接问。**
温原说：「核对一批转运单。远星想买我们的医疗材料，我告诉他得走公库。」他没有说谎，但也没说全：乔述还问了他妹妹在外环的住处，以及「如果公社待不下去，远星有位置」。

**B. 监视。**
玩家让陆沉派一个班组盯两天。第二天，班组看到温原又见了乔述，这次在集市，乔述递给他一个信封。玩家可以搜查，找到一封远星的邀请函和一张外环的房契。温原会承认：「我妹妹的房子被烧了。乔述说远星能给她一个床位。」玩家可以：
- 给温原的妹妹安排医院/住所（资源、穆枝的支持）；
- 公开处理，警告远星（关系 −10，但震慑其他人）；
- 驱逐温原（物资岗位空缺，公库混乱 3 天，其他支持者 −1 档）。

**C. 装作不知道。**
玩家不查，但开始让伊诺盯着温原的账。两周后，如果玩家没有解决温原妹妹的问题，温原会在一次关键表决前「请假」，公库执行度掉到 40，法案效果打七折。玩家这才知道，但已经晚了。

没有哪个选择是「正确」的。玩家要在**信任、控制、资源、时间**之间做取舍。这就是这一派的政治。

## 十三、设计护栏

| 风险 | 护栏 |
|---|---|
| AI 乱吞并 | 14 天保护期、7 天冷却、4/5 门槛、风险判断、竞争性保护 |
| AI 永远不吞并 | 当玩家支持崩、城市危机、玩家孤立时，AI 会提高吞并意愿；每个阶段有迹象 |
| 玩家一头雾水 | 五档态势 + 理由 + 会面痕迹 + 请愿 + 编年史；不用隐藏分数 |
| 玩家被 8 人淹没 | 每日 2–3 个请愿；其余进简报；支持者之间自己解决问题 |
| 驱逐太便宜 | 需要理由与证据；连续驱逐会集体离心；被驱逐者会报复 |
| 驱逐太贵 | 提供「调岗、降职、监视、保护性驱逐」等中间手段 |
| 雪球效应 | 强者也会被制衡：连续主导议程会触发反向联盟；吞并者也要承担风险 |
| 失败太突然 | 四阶段、明确迹象、最后通牒、玩家可在表决中投票 |
| 失败太轻 | 编年史、遗产局、Agent 记住你的选择；不是读档 |
