# 长局与复玩

《炉边议会》没有「通关」。城市会一季一季过下去，议事会一周一周开下去，玩家会升职、失势、被自己人抽走支持，也可能在寒潮里看着自己建起来的街区冻死一半人。政治的胜负不是一次表决，而是你还能不能在下一次表决里坐着。

> 失败与吞并的详细规则见[支持与吞并](13-support-and-annexation.md)；结局见[战役弧](16-campaign-arc.md)；票制见[议事会](09-council-and-laws.md)。

## 三条成长线

| 线 | 怎么长 | 看得见的变化 | 代价 |
|---|---|---|---|
| 个人政治生命 | 兑现承诺、通过法案、赢得信任、处理危机 | 从新党魁到老党魁；8 个支持者从观望到坚定；对手开始认真对待你 | 树敌、欠人情、被审计、被支持者反对 |
| 派系 | 民意支持率、岗位能力、地块、盟友 | 民意支持从 20% 到 30%；8 个支持者的能力提升；更多工人与地块 | 派系立场会绑住你；支持者会要更多 |
| 城市 | 人口、产能、技术、稳定 | 从「活过寒潮」到「向外扩张」；新建筑、新法案、新外域 | 扩张会推高边境紧张与内部矛盾 |

三条线互相牵制：个人威望能推动城建，城建能提高支持，支持能给你更多资源，但扩张会得罪外域与内部反对派。没有一条能单独走到头。

## 民意支持，而不是席位

旧稿用「民意 → 席位」表示政治力量。新稿用**支持**：

- 每个派系有一个相对支持度（开局：公社 29%、砾火 22%、地生 20%、止戈 17%、远星 12%）。
- 支持决定该派在街头的动员力、党魁的合法性、被吞并/吞并别人的风险。
- 玩家自己的 8 名支持者代表有**五档态势**：坚定/观望/动摇/离心/敌对。
- 民意支持不是玩家可以直接花的资源；它通过法案、供热、伤亡、承诺、会面、背叛变化。

| 事件 | 民意支持变化 |
|---|---|
| 供暖覆盖 ≥80% | 公社 +2、砾火 +1 |
| 食物保障 ≥7 日 | 公社 +2、地生 +1 |
| 疾病 ≤20 | 地生 +2、止戈 +1 |
| 新收容者安置 | 止戈 +2、地生 +1、砾火 −1 |
| 法案兑现 | 提案派 +1..+3 |
| 承诺违约 | 该派 −3..−5 |
| 寒潮死亡 >20 | 全派 −2..−4，公社额外 −2 |
| 外域条约批准 | 远星 +2；砾火可能 −1 |
| 边境袭扰未回应 | 砾火 +2（要求强硬）、止戈 −1 |

民意支持是相对值，按占比归一化；表里的加减不要求当场合计为零。民意支持低于 5% 的派系不会消失，但会被视为「快倒了」，对手更容易挖角/吞并。

## 玩家自己的 8 个支持者

玩家不是靠「民意」统治本派，是靠 8 个支持者代表。每个人的态势独立变化，不取平均：

| 态势 | 玩家能看到 | 常见原因 |
|---|---|---|
| 坚定 | 「他站你这边」 | 兑现承诺、护住他的人、信同一件事 |
| 观望 | 「他还在看」 | 刚上任、没碰到利益、等别人先动 |
| 动摇 | 「他最近和砾火的人走得很近」 | 忽视请求、对手给更好的条件、城市变糟 |
| 离心 | 「他把家属送去了外环」 | 公开羞辱、班组死人、觉得你保不住 |
| 敌对 | 「他在公开场合质疑你的投票」 | 驱逐他的人、违背基石、认为你必输 |

玩家可以换岗、升职、加预算、给保护、驱逐；不能直接改态势。态势由 AI 判断，带理由、带前兆。

## 职务与权力

新稿没有全城「工务长/医政长/外务使」这类统一职务；每个派系有自己的岗位负责人。玩家能争的城市级职务只有一个：**轮值议长**。为便于阅读，下文用「工务长/医政长」指派系内部岗位负责人，不是全城官职。

| 职务 | 权力 | 怎么拿到 | 怎么失去 |
|---|---|---|---|
| 轮值议长 | 定 3 项议程；召集紧急会议；每周可延后一项表决（不占本派每季 2 次额度） | 轮值；或被 3 票程序动议推上 | 3 票撤换；任期一周 |
| 本派党魁 | 本派 1 票、本派委托、本派地块、本派工人 | 开局选择；或继承 | 支持崩解；被吞并；死亡/退隐 |
| 岗位负责人 | 本岗位的执行权、预算、班组 | 玩家任命/支持者推举 | 玩家换岗；请辞；死亡 |

岗位不是荣誉，是行动位。工务可以把自己的工程排在别人前面，物资可以决定谁先拿到材料，治安可以决定查谁不查谁。玩家可以换人，但每次换人都会得罪一批人。

## 一个季节

> 下表是**一个季节内部的四周节奏**，不是四季的名字；四季（春汛/扩张/囤积/白障）见[战役弧](16-campaign-arc.md)。两者都用「扩张」「囤积」这类词，但一个是季内周次，一个是整季主题。

| 阶段 | 日 | 城市 | 政治 | 外域 |
|---|---|---|---|---|
| 春汛 | 1–7 | 修根网、通水源、补房 | 选轮值议长、定季初议程 | 巡裔北迁、根庭复苏 |
| 扩张 | 8–14 | 扩开采、建工坊、招人 | 用地法案、预算、技术许可 | 泊星者观测、贸易活跃 |
| 囤积 | 15–21 | 储热储粮、抢修、训练民兵 | 配给、动员、条约批准 | 三方要价升高、摩擦增多 |
| 寒潮 | 22–28 | 停机、救人、抢修 | 紧急会议、吞并试探、支持崩解 | 迁徙、封渠、停修、袭扰 |

季节末的寒潮是硬考试：食物、能源、医疗、热级、道路、民兵，六项里至少四项要过线，否则死亡与不满会拖进下一季。寒潮之后，城市带着伤亡、欠账与新的支持态势进入下一季。

## 失败

| 失败 | 触发 | 后果 | 还能继续吗 |
|---|---|---|---|
| 支持崩解 | 8 席中 ≥5 席离心/敌对/空缺，且无庇护 | 本派失去合法性，可能被吞并/政变；玩家保留性命与部分关系 | 能；以新身份继续当前世界 |
| 被吞并 | 4/5 吸收案通过，或 ≥5 人倒戈且无庇护 | 本派被另一派接管，玩家成为顾问/流亡者/消失 | 能；以新身份继续当前世界 |
| 城市崩溃 | 中继 0 持续 48h，或人口 <200 | 大规模死亡/撤离，进入残局 | 能；以幸存者身份开新局/遗产局 |
| 玩家死亡/退隐 | 袭击、疾病、暗杀、主动退隐 | 进入继承/遗产局 | 能；以继承人/新身份继续 |

被吞并或支持崩解不是 Game Over，而是**换一个位置继续**。玩家可以：

- 以本派新人身份重新开始（新党魁，旧世界）；
- 以另一派的新党魁身份继续（跨派遗产局）；
- 以独立身份做说客/顾问（不掌权，但能影响）；
- 接受外域或另一派的邀请，换一个位置（会失去原派信任）。

这是从《十字军之王》借来的「政治生命」：失败不是读档，是下一段故事的起点。但新身份**不继承旧身份的记忆、职位、库存、秘密**；世界记得旧身份做过的事，新身份要自己面对。

## 继承与遗产局

如果玩家角色死亡、退隐或长期失去行动能力，进入继承/遗产局：

1. 选择「重新开始」（新世界/新开局）或「继续当前世界」（遗产局）。
2. 遗产局默认跳 1 季；也可以选立即接管或跳 1–4 季。
3. 玩家以新身份回到本派（如果本派还在），或成为另一派的党魁。
4. 世界保留建筑、伤亡、承诺、关系、编年史；新身份不继承旧身份的记忆与秘密，但会被旧账波及。
5. 上一局的 Agent 可能还在、升职、流放、死亡；死亡 Agent 的补位者是全新 NPC，不继承前任。

继承不是惩罚，是长局的一部分：一座城会记住几代人的账。

## 复玩

| 变量 | 会改变什么 |
|---|---|
| 五个派系开局 | 8 人班子、党魁、首个法案、首个工程、外务渠道全不同 |
| 世界种子 | 矿产、遗址、寒潮强度、外域初始关系略有差异 |
| 导演风格 | 温和引导 / 高压施压 / 只给时代任务；三方行为差异明显 |
| 玩家路线 | 城建优先、议事优先、外务优先、谍报优先；同一周只能做两三件事 |
| 承诺历史 | 上一次违约会让下一次报价变硬；同一开局也能玩出不同联盟 |
| 支持态势 | 同一法案，不同人执行，结果不同；同一个人，不同对待，走向不同 |
| 死亡/补位 | 死去的 Agent 不会被同一个人替代；新人有自己的性格与忠诚 |

推荐复玩顺序：先用公社熟悉议事与支持，再用砾火学防务与袭击，再用地生学水务与根庭，再用止戈学人道与调停，最后用远星学小派如何借票。远星最难，也最能体现「玩家不是全城的主人」。

## 存档与分支

> 本节描述**单人局**。多人局只有服务端权威存档，不提供本地手动存档、分支复制或回滚；研究分支只在运营侧隔离环境运行。

- 自动存档：每周议事前、每次表决后、寒潮前、每次吞并提案前。
- 手动存档：任意暂停时；存档显示世界日期、派系、支持态势、主要欠账。
- 分支：可以从任意存档复制一个分支做实验（换派系、换法案、换导演指令），不影响原世界。
- 研究控制台可以对比分支的 Agent 行为、票数、资源与结局；玩家端只看自己的世界。
