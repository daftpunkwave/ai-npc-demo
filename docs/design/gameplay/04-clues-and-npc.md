# 情报、沟通与 NPC

玩家与角色各有知识边界。城市仪表、政策与议事记录可以公开查阅，条款与库存只在相应权限内显示，私下谈话只有当事人知道。玩家亲眼看到一封传言，只证明传言已经被说过。要让角色改变判断，先让它获得所需的证据，再明确要它重新审视哪件事。

开放世界的情报比序章多两层：一层是**议事与执行的记录**，一层是**外域与导演的动向**。玩家要学会把“我听说”“我查到”“我推断”分开，否则很容易在议事会里用一条传闻去指控一个派系。

## 五种信息

| 类型 | 例子 | 谁能知道 | 能不能当证据 |
|---|---|---|---|
| 事实 | 水闸在 t44 渗漏；某队 t91 完成修复 | 在场者、回执受众、公开读数 | 能，但要能对应到事件 |
| 记录 | 运输延误单、库存流水、投票记录、工程账 | 持有授权的当事人、审计者 | 能，注意来源与完整性 |
| 传闻 | “巡裔袭击了车队”“泊星者要断供” | 听到的人 | 不能，只能作为调查起点 |
| 推断 | “砾火想拖到寒潮再表决” | 玩家自己 | 不能，只能用于试探 |
| 秘密 | 幼体撤离预案、备用路线、真实紧迫性 | 合法持有人 | 不能直接公开；分享要授权 |

## 可调查的证据

| 证据 | 如何获得 | 在什么决定里有用 |
|---|---|---|
| 运输队延误记录 | 侦察战前档案库，具资格的参与方可分享 | 针对同一车队。显示旧堤渗水使其改道 6 小时，无交战痕迹 |
| 战前星图与锚点校准表 | 侦察档案库，或接收持有者授权分享 | 修复交换实际能交付的资料；泊星者最想要 |
| 旧堤闸门渗漏记录 | 侦察旧堤水闸 | 显示渗漏严重并给交通延误提供旁证 |
| 水闸历年分水账 | 公社、地生、温原、谷寻及对应开局持有 | 说明过去三季的分水偏向，支持轮换谈判 |
| 修复交换草案 | 远星、泊星者、乔述、洛及远星开局持有 | 写明交换意向，便于核对接受人、完成条件 |
| 议事投票记录 | 议事会公开记录；可查谁投了什么 | 用于质询倒戈、兑现承诺、揭露交易 |
| 工程账与材料流水 | 工务岗位、公社、审计者 | 查挪用、拖延、虚报；执行度低时常用 |
| 边境巡逻记录 | 砾火、哨塔、侦察队 | 判断袭扰来源、边境紧张是否被人为推高 |

游戏界面显示标题、获得时点、来源与能读到的正文。历史记录与后来确认的事件可以同时存在。 [来源与时间口径](../sources-and-review.md)

### 作者专阅

四条保密线索分别是根庭幼体的撤离预案（根庭代表、青枝、伊诺知情）、巡裔备用路线（巡裔代表、追风）、泊星者的真实紧迫性（泊星者代表、洛）以及止戈的未发布停火措辞（止戈代表、唐箴）。持有者可以受它影响，例如更急于成约或拒谈某条路，只在获准范围内发言。人物册和可分享证据列表只接收玩家有权知道的内容。

## 议事与执行的公开性

| 信息 | 公开程度 | 玩家怎么拿到 |
|---|---|---|
| 议程、法案文本、投票结果 | 全城公开 | 议事面板、广播 |
| 承诺账本 | 当事人 + 议事记录 | 议事面板；对方也会记得 |
| 预算与工程账 | 审计权、工务岗位、公社 | 审计、质询、档案室 |
| 派系内部会议 | 不公开 | 渗透、策反、当事人转述 |
| 私下交易 | 双方 | 只有泄露/侦察/事后文件 |
| 外域使节会谈 | 双方 + 见证人 | 使节报告；对方可能放风 |
| 世界导演指令 | 不公开 | 只能从行为、价格、传闻推断 |

议事会的公开记录是玩家最有力的武器：它不能证明动机，但能证明“谁在什么时候说了什么、投了什么”。质询与审计都建立在公开记录上。 [议事会](09-council-and-laws.md)

## 通信怎么送达

| 渠道 | 同节点 | 中继正常 ≥30 | 降级 1–29 | 中断 0 |
|---|---|---|---|---|
| 玩家与角色双向对话 | 即时 | 即时 | 异地 +2 小时 | 异地发送被拒 |
| 定向信件、证据分享 | 即时 | 异地 +1 小时 | 异地 +3 小时 | 异地发送被拒 |
| 公开广播 | 即时 | 异地 +1 小时 | 异地 +3 小时 | 只到同节点 |
| 开局来信、正式协议、政策、通行、任务与邀请 | 按受众即时 | 按受众即时 | 按受众即时 | 按受众即时 |

送达与回应分别计时。即时送达表示对方可以收到这条话，决定和回复仍需等待。**外域 Agent 按其所驻节点计算**（追风在风隙营地、青枝在苔庭、洛在锚区）；AI 党魁在灰港党部，同节点即时。只有当外域 Agent 离开节点、在途中时才按异地处理。定向给多人时每个收件人按自己的位置计算。中断时，发现有异地收件人就整条拒绝。已受理的投递保留原预计，知识授权被收回时仍取消待送。

开放世界追加两种渠道：**使节**与**商队**。使节走道路，能带文本与口信，路上可能被截；商队走贸易路线，能带货物与小道消息，但慢且容易走漏。中继中断时，使节是唯一能跨外域传话的方式。 [外交](10-diplomacy-and-intrigue.md)

## 一条传闻怎样变成一次决策

1. t44 的渗水事实首先被当时在旧堤水闸、有接收资格的主体知道。玩家留在灰港，要等合法转述或主动侦察。
2. t50 的公共声称把一辆补给车的延误归因于袭击。收件箱标注“听说”、商贩和听到时点。岑雁可以出于风险暂停决定，林芜可以继续救人并要求查证。
3. 侦察获得对应日期与车队的记录。把证据转给正要决策的角色，留出送达时间。显示“已分享”和“已送达”各自的时点。
4. 给角色把传闻、事实和自己的推断分开表达的机会。可以撤回对当次事件的指控，继续要求路况核验、通行许可或过往承诺担保。知道更正的一方可以再经合法渠道传递给其他人。
5. 如果这条传闻是某一方故意散布的，追查来源会进入谍报层：谁买的商贩、谁写的匿名信、谁在议事会前夜放风。 [谍报](10-diplomacy-and-intrigue.md)

## 导演的痕迹

世界导演不会给玩家发任务说明，但会留下痕迹：

| 痕迹 | 可能意味着 |
|---|---|
| 巡裔与根庭使节连续互访 | 有人在推两家结盟；灰港可能被联手压价 |
| 泊星者修复报价突然翻倍 | 边境摩擦前兆，或残轨场被盗采 |
| 根庭突然愿意多卖粮 | 暖谷丰收，或根庭想换水/热 |
| 巡裔先遣队提前到隘口 | 南迁提前；灰港要在一周内决定开不开路 |
| 集市上出现同一批外来货 | 有人在做未经批准的贸易，或导演在注入资源 |

这些痕迹可以被侦察、使节、商队、集市与角色对话交叉验证。玩家不需要知道指令原文，只需要知道“世界在往哪边倾斜”。 [世界导演](12-world-director.md)

## NPC 如何看待同一请求

| 影响 | 玩家能怎样察觉 |
|---|---|
| 个性与职责 | 同为协作对象，苏回先问谁接伤员，唐箴先问谁确认条款，温原先问仓里可用多少 |
| 当前处境 | 没路、受伤、队伍正忙、材料不足时，回应指向具体阻碍。拒绝可以给换路、改期、找其他人等条件 |
| 曾经的关系 | 帮过谁、曾在哪件事上违约、一起完成了什么，可能改变角色对下一次风险的要求 |
| 信念更新 | 有对应反证时会考虑修正看法，传闻和猜测均保留来源与不确定性 |
| 派系位置 | 党魁要考虑支持与党内；岗位负责人要考虑执行；外域角色要考虑族群与季节 |
| 自主行动 | 请求、邀请、协议提案、相关危机或已记住的到期义务可能让角色来信、提议、派遣或还价 |

长程回忆和主动提醒随角色使用的记忆方式变化。世界本身仍按同一套任务与协议事实结账。玩家侧用可披露的原因、选择和实际后果表达差异，人物册用“挺信任我”“正在担心这条路”等线索。 [人物档案](../characters/README.md) · [记忆规则来源](../sources-and-review.md)

## Agent 之间的私下往来

角色会自己找人。岑雁可能在玩家不知道时给追风送一封口信；根庭园护可能直接找地生谈水；两个党魁可能在宴会角落里交换选票。玩家只能通过以下方式知道：

- 当事人主动告诉你（可能有利，也可能是在试探）；
- 第三方转述（来源与动机都要打问号）；
- 侦察/渗透/窃取（有暴露风险）；
- 事后文件（协议、投票记录、库存流水）。

这不是 bug，而是世界的底色：玩家不是唯一会说话的人。 [Agent 行动](11-agent-actions.md)
