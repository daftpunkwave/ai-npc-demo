# 玩家界面与引导

镜头是 Frostpunk 式的 3D 斜俯视：从城市斜上方看下去，能看到屋顶、烟囱、街道与人群，但不贴地行走。玩家可以旋转、缩放、拉近到街区，也可以拉到能看见整个灰港与三条外域道路的高度。所有政治、城建与行动都在这一个视角里发生，面板从边缘展开，不把地图切成独立关卡。

首屏要让玩家看见四件事：今天几号、城哪里在冷、本周议程是什么、自己手里有什么。

## 镜头与 3D 表现

| 项 | 规则 |
|---|---|
| 视角 | 斜俯视，默认俯角约 45°；可上下调整 30°–60°，不做第一人称 |
| 旋转 | 360° 水平旋转；关键建筑与道路有方向标识，避免转晕 |
| 缩放 | 从全城到街区三级；拉近可见人、车、烟、雪，拉远可见热区与边境 |
| 聚焦 | 点事件/人物/建筑，镜头平滑飞过去；双击地面回到上一个焦点 |
| 建造 | 在 3D 地块上放建筑，显示热区、邻接、材料与人力；红/绿提示可建与不可建 |
| 天气 | 雪、雾、白毛风、热浪（炉边）用粒子与光照表达；寒潮时能见度下降，但关键 UI 不遮 |
| 性能 | 远处建筑降细节，人群用实例化；镜头拉远时隐藏室内与小人 |

3D 不是装饰。热区的颜色、屋顶的雪、烟囱的烟、街道上的人流，都是玩家判断城市状态的读数。玩家应该能只靠看画面说出「边环在冷、医院在排队、矿场在冒烟」。 [城与热区](../world/grayharbor.md)

## 主界面

| 区域 | 默认显示 | 点开后 |
|---|---|---|
| 顶部 | 日期/小时、运行状态、中继稳定度、供暖覆盖、食物保障、供水、疾病、不满 | 暂停、速度、存档、设置；点任一仪表进入对应面板 |
| 左侧 | 城市快捷入口：城建、人力、库存 | 建造菜单、地块详情、劳力分配、库存流水 |
| 右侧 | 本周议程、票数预估、承诺账本 | 议事会全屏；法案文本；拉票工具箱 |
| 底部 | 地图模式切换：城/路/外域/热区 | 选择队伍、任务、派遣；时间轴回看 |
| 顶栏下方 | 时代任务进度条 | 任务详情、奖励、失败后果 |
| 右下角 | 通知与收件箱 | 紧急、到期、提议、公共四级筛选 |

## 八个主面板

主界面常驻四块（顶部仪表、左侧城市、右侧议事、底部地图模式），面板层共八个：城市、议事会、外务、人物、情报、自己人、会面痕迹、受损与修复。

### 1. 城市

- 四环地块、热级、建筑等级、工地、人力。
- 热区叠加：按热级着色，边环冷区发蓝，热站覆盖发橙。
- 点地块：归属、建筑、产出、维护、邻接、可建/可升级。
- 建造菜单按类别分组：居住、食物、水、开采、工业、后勤、民生、防御。
- 人力面板：总劳力、已分配、疾病损失、各派占用；拖动分配时实时显示产出变化。

### 2. 议事会

- 五张长桌：每派一张，桌角一枚铜印；党魁座位后方是 8 个旁听席。
- 投票板：赞成/反对/未定三色；两条刻度线——3 票（普通法案）与 4 票（宪制法案）。
- 法案卡：条款、成本、执行机构、默认立场、当前预估票数。
- 拉票面板：每派一个卡片，显示诉求、关系、可用手段（承诺/交易/职位/议程/施压）。
- 承诺账本：对象、内容、截止、状态（待兑现/已兑现/违约/改约）。
- 表决动画：逐派唱名，五个票格一格格亮；第 3 格与第 4 格各有一条刻度线。普通法案停在第 3 格即为通过，宪制法案必须亮到第 4 格；未亮的格子保持铁灰，不显示「第 9 格」这类旧票制刻度。

### 3. 外务

- 四阵营环图：人类在中心，三外域在外圈；连线颜色表示关系，线粗细表示贸易量，红色脉冲表示紧张。
- 每方卡片：关系、声誉、边境紧张、诉求、红线、当前使节。
- 遣使面板：选使节、选队伍、选议题、看路程与风险、预估对方开价。
- 条约草案：条款逐行，标出「需议会批准」；批准进度显示 3 票（普通）/4 票（同盟）。
- 贸易面板：货物、比价、路线、护送、预计到达。

### 4. 人物

- 人物卡：姓名、派系、岗位、公开主张、当前位置、关系、态势（仅本派 8 人）。
- 关系图：信任、债务、承诺、把柄、共同经历。
- 对话：意图按钮（询问/请求/提议/承诺/威胁/揭穿/道歉/告别）+ 自由文本；对方回应显示「基于什么」的线索。
- 人物册只显示玩家有权知道的内容；秘密需要分享或调查。

### 5. 情报

- 收件箱：按来源、时点、类型分组；传闻标「听说」，事实标「已核验」。
- 证据卡：标题、来源、获得时点、可分享对象、关联事件。
- 议事记录：议程、发言、投票、承诺；可按派系/法案筛选。
- 外域动向：使节、巡逻、价格、迁徙、封锁；未知显示为「未观测」。
- 时代任务：进度、期限、奖励、失败后果。

### 6. 自己人

这是新稿最重要的面板。8 个支持者代表，每人一张卡：

| 区域 | 显示 | 点开后 |
|---|---|---|
| 态势 | 坚定/观望/动摇/离心/敌对 + 一条理由 | 最近一次变化、触发事件、玩家做过的相关事 |
| 岗位 | 行政/工务/物资/医政/治安/配给/通信/档案 | 能力、执行度、班组、当前任务 |
| 关系 | 信任/亲近/敬畏/亏欠 | 共同经历、承诺、旧账、把柄 |
| 会面 | 最近和谁见过面 | 会面记录（无内容）、目击者、可询问 |
| 动作 | 交谈、询问、升职、换岗、监视、搜查、驱逐 | 成本、风险、可能的反应 |

面板顶部有一行「本派支持态势」：稳固/尚可/分裂/不稳。它不是平均数，是 8 个支持者里最危险的那几个决定的。

### 7. 会面痕迹

- 地图上的人与人之间会出现细线：谁知道谁见过谁。
- 线有颜色：公开会面（白）、半公开（灰）、私下（暗红，只有被监视/撞见时出现）。
- 点线：谁、和谁、何时、何地、多久；没有内容。
- 可以标记「可疑」；被标记的人会在下一次会面时更容易被监视，但也更容易发现你在盯他。
- 会面痕迹会随时间淡化；重要会面（对手党魁、外域 Agent、深夜、城外）保留更久。

### 8. 受损与修复

- 城图上建筑有三态外观：完好、受损（破口/钉板/断烟）、损毁（墙基/焦黑/清墟堆）。
- 受损叠层：红色斜纹表示受损，黑色表示损毁；点开看材料、工期、优先级。
- 修复队列：玩家可以拖优先级；陶安/沈砾会给出「先修哪个会死更多人」的建议。
- 死亡名单：每次袭击后弹出，可一键进入医院/食堂/哨塔场景；名单会进入编年史。

## 对话与时间

> 本节描述**单人局**。多人局不暂停、不做客户端存档，对话转异步消息，见[多人体系](../multiplayer/01-seats-and-clock.md)。

- 默认 20 秒/tick；对话开始时**自动暂停**，结束对话后恢复。
- 输入框旁有「继续时间」按钮，玩家可以边看条款边让世界慢慢走。
- 读法案、写承诺、查证据不限时；时间只在玩家关闭对话/点继续后推进。
- 如果玩家在对话中收到紧急事件（袭击、寒潮、死亡），会先弹出红色提示，玩家可以选择「立即处理」或「记下，稍后」。
- 语音/字幕：首版以文本为主；广播、警报、死亡名单有文字稿。

## 通知与异常反馈
| 优先级 | 典型事件 | 表达方式 |
|---|---|---|
| 紧急 | 寒潮预警、中继骤降、袭击、任务失败、伤员恶化 | 屏幕边缘红框 + 明确时间与地点 + 一键飞过去 |
| 到期 | 承诺/协议 24 小时内截止 | 按期限合并，显示已完成部分与还差什么 |
| 提议 | 收到协议、条约、角色邀约 | 保留到期与发送者，可晚些处理 |
| 公共 | 广播、议事、传闻、价格变化 | 入收件箱，带来源与类别，可过滤 |

同一个任务先显示「已受理」，然后是「待出发」「在途」「延误至某时」或「已完成」。权限不足时，提示要指明缺队伍授权、路权、库存额度、议案票数中的哪一项。远程中断时，显示可用的本地与正式通知渠道。未收到回话时显示「等待回应」，结束后无对白显示「对方暂未回应」。

## 首次开局的引导

1. **选派系。** 五张牌先说人、8 个支持者、首个工程与外务对象；不急着讲全部规则。
2. **看四张图。** 城图（热区/受损）、路图（通行）、议事图（五张桌子与议程）、人物图（8 人态势）。每张图只教一个动作。
3. **做一件事。** 派一支队伍、修一座楼或见一个人；完成后回到当事人，看对方是否引用这次经历。
4. **第一次日结。** 显示两行最直接的变化：「供热优先，中继 −2，边环热级 +1」；让玩家知道决策如何进入账本。
5. **第一次议事。** 只给一项程序案，让玩家看到 3 票门槛与五张桌子；不要求通过正式法案。
6. **第一次外务。** 一位使节带来一笔小交易；让玩家看到关系、声誉、紧张三条账。
7. **第一周结束。** 用一页「本周账本」总结：建了什么、投了什么、欠了什么、寒潮还差什么。

## 可访问性与设置

- 字号、高对比度、色盲友好（票数不只靠颜色，配数字与图案）。
- 镜头速度、自动旋转开关、晕动症选项（降低俯角变化与粒子）。
- 通知筛选、暂停即暂停一切、自动暂停离线。
- 语音/字幕：首版以文本为主，广播与警报有文字稿。
- 存档：**单人**手动 + 自动（每周/每次表决前）；存档显示世界日期与派系。**多人**只有服务端权威存档，玩家端不提供本地存档与回滚。
- 研究入口不在玩家界面；从服务端控制台进入，玩家只看到世界投影。

## 表现基调

低饱和的灰、蓝、褐，热区用橙与暖白，派系色只用于标识人物、队伍与票块。建筑轮廓要清楚，屋顶形状能区分居住、温室、工坊、矿井与热站。议事厅是唯一暖色室内场景：五张长桌、旧旗、铜印、头顶的煤油灯。外域用三种质感区分：巡裔的皮帐与火堆、根庭的菌光与湿土、泊星者的金属与蓝光。 [美术方向](../sources-and-review.md)
