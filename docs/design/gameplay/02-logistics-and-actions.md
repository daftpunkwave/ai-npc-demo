# 地图、队伍与任务

每支队伍同一时刻只能做一件事。派遣权属于玩家（本派党魁）和持有有效委托的人。选队时同时核对派遣权、队伍能力、可用资产、路线许可和预计完成时刻。邀请个人可以改善结果，还要确认位置、伤势、排班和意愿。 [队伍与资源表](../balance/01-baseline.md)

序章的六节点与九条路只用到前五种任务；进入开放世界后，施工、巡逻、商队、勘探与袭扰会把城外的日常撑起来。两种模式共用同一套路径、风险与授权规则。

## 路径与通行

| 路况 | 谁能上路 |
|---|---|
| 开放 | 合法任务均可使用 |
| 受限 | 队伍属于道路控制方，或**队伍所属派系**持有这条路的有效许可，许可至少覆盖出发 tick |
| 关闭 | 道路停用，许可也不生效 |

所有道路双向。规划先在可通行道路里取基础用时最短的路径，同长时取道路数少的路径，再用固定道路顺序处理并列。运货再按每条路加 1 小时。命令受理和正式出发都要检查路线。队伍已经出发时沿用出发条件，政策变化影响未来出发的任务。要在风险路上开车，可让适格护送队先到端点，在其巡护生效时出发。

寒潮期间所有道路 +2 小时、风险 +1；封锁会让整条路不可用，绕行可能多出半天。入口、控制方与风险见[灰港地图](../world/grayharbor.md)与[数值基线](../balance/01-baseline.md)。

## 从派遣到返岗

1. **规划。** 选任务、队伍、起点与终点、货物或工作对象。比对到达时点、库存可用量、个人委托余额与路权。
2. **受理。** 同时校验能力、占用、位置、运力、授权、可达性和库存。受理后锁队伍、预留资源并扣相应委托余额。若邀请角色，系统把邀请与出发时刻直接发给当事人。
3. **回复。** 受邀人须在出发前接受，受伤或正在另一个任务的人不可参加。人须位于队伍节点或任务工作地点。无邀请默认下个 tick 出发，有邀请默认等 2 tick，可以设置 1–6 tick。
4. **出发。** 根据已接受的实际人选和最新通路重新检查。原路关闭时会尝试合法路线。若无路可走，或本派物资支持者未参加导致超出运力，任务失败，释放预留并归还相应额度。邀请超时按拒绝处理，队伍仍可在前置条件满足时独立执行。
5. **在途与工作。** 显示名义完成时间。遇到抽中的延误，在名义完成时发一次延误通知并给新预计时刻。受伤在结算时公布，影响后续参与或派遣。
6. **结算。** 运输等任务完成才产生相应转移或效果。完工时更新可见任务结果、指标、知识和实际占用，重新按有效授权规划下次行动。

## 十种任务

| 行动 | 玩家要交代的参数 | 在哪里做、如何完成 | 能改变什么 |
|---|---|---|---|
| 运输 | 起点库存、目的库存、货物数量 | 队伍在起点仓，至少一件货，总量 ≤ 运力。按路走，每经过一条路加 1 小时 | 货物入目的仓，队伍与参与者留在目的地。本派物资支持者（公社温原）参加时运力 +5 |
| 护送 | 一条道路、6–24 小时巡护长度（默认 12） | 队伍到可达的最近端点后开始巡护。巡护有效时间内出发且经过该路的任务跳过该路抽样 | 迁徙路护送完成时提高迁徙安全；本派治安/向导支持者（公社陆沉）或追风参加可加成 |
| 救援 | 伤员群体、医疗点、该点医疗库存 | 队伍先到伤员处，再去目标医疗点。按伤员数预留材料，本派医政/救援支持者（公社穆枝；止戈苏回；地生辛夷）参与减 2 小时，最低 1 小时 | 消耗医疗，伤员变为已救援，迁徙安全 +10 |
| 修复 | 中继目标、能源库、供给库 | 带修复能力的队伍赶到灰港，工作 6 小时。材料库在灰港或起步点，泊星队可免供给 | 完成时恢复中继稳定度；普通 +25，泊星队 +40，本派工务支持者 +10；洛参与非泊星队 +15 |
| 侦察 | 目标节点 | 走到目标再观察 2 小时。本派情报/侦察支持者（公社祁录；地生谷寻）或追风参加时每条路 −1 小时，每路至少 1 小时 | 派遣者、参与者与队伍所属派系得到路况、在场者与群体状态，并获可发现证据的知情资格 |
| 施工 | 地块、图纸、材料 | 工程队到地块，按成本工作；有人力时工期 = 成本 ÷ 10 + 2 小时 | 建筑进度；完工后入驻、投产；寒潮 +50% 工期 |
| 巡逻 | 一条道路或一个节点、时长 | 民兵或队伍在指定区域巡逻，遇袭时先接战 | 降低边境紧张/袭扰成功率；发现潜入与走私 |
| 商队 | 起点、终点、货物、买家 | 与运输相同，但终点是外域节点，需贸易协定与对方接货人 | 完成贸易；关系 +1..+3；可能被抽税或抢劫 |
| 勘探 | 目标地块/遗址 | 工程队或侦察队到目标，工作 2–6 小时 | 发现矿脉、水源、旧图纸、遗址入口；部分结果只对派遣方可见 |
| 袭扰 | 目标设施/道路、兵力 | 民兵或外域队伍夜间出动，按兵力与守备结算 | 对方产出下降、道路关闭、关系 −；被认出可能开战 |

> 任务加成按**岗位能力**触发；括号内是公社席的基线角色。其他四席开放时，按该派 8 人岗位映射补齐；没有对应岗位的角色不触发加成，也不另造一个未上场的人。

判断能否受邀时，护送的工作地点为道路端点，救援为伤员所在点，运输为起点，修复为灰港，侦察为目标节点，施工为地块，巡逻为路段，商队为起点，勘探为目标，袭扰为集结点。

## 协同与补给

开放世界里的任务经常要接力：

- **施工 + 运输。** 材料先到工地仓库，工程队再开工；材料不到，工期停。
- **巡逻 + 商队。** 巡逻降低路段被袭概率；商队仍要按自己的路权走。
- **救援 + 护送。** 护送先到位，救援再出发；两个任务占用两支队伍。
- **勘探 + 档案。** 勘探发现遗址入口，档案室才能解锁对应图纸。
- **袭扰 + 外交。** 袭扰能逼对方让步，也会让谈判桌上的价码变硬。

补给线是开放世界的隐形约束：队伍离开灰港越远，返程与补给越长；外域驻队要营地与定期运输；寒潮会把补给线拉长一倍。玩家不能只算「去」，还要算「回」。 [城建](08-city-building.md) · [外交](10-diplomacy-and-intrigue.md)

## 常见失败与取消

| 状态 | 玩家可采取的处理 |
|---|---|
| 派遣被拒 | 查第一条原因，按授权、能力、占用、路权、额度、可用量逐项纠正 |
| 等候出发时取消 | 派遣者或队伍所属派系的党魁可取消，释放预留，退回相应委托余额，作废未答邀请 |
| 运输在途时取消 | 货物回到起点可用库存，队伍仍需等到名义完工时间才从起点恢复接单 |
| 救援、护送、侦察在途时取消 | 停在当前确认节点并释放预留，取消后没有本任务的完工效果 |
| 修复在途或开工后取消 | 未到灰港时释放预留。已开工的费用按已消耗处理，作业取消时没有修复增益 |
| 施工在途取消 | 已用材料不退还，工地保留半成品；下次复工按剩余成本算 |
| 任务已终结 | 完成、失败和取消各有记录。需要继续时可独立派遣下一笔任务 |
| 发生伤病 | 角色 48 小时内不可参任务、仍可交谈。若抽中时无参与角色，队伍完工后休整 24 小时 |

跨任务衔接优先看真实完工点。请医生参加下一次救援时，看角色此刻的位置和活动任务。外派运输后若要继续用原队，先安排能从目的节点接起的合法任务，也可以换队。

## 任务与政治

任务不是中立的技术动作。每一次派遣都会改变某一派的处境：

- 用公库材料修中继，公社要问「谁批的」；
- 派砾火队去护送巡裔，砾火党魁要问「谁担保」；
- 让地生队去救根庭幼体，地生党魁要问「果园的水谁来补」；
- 让远星队出锚区，泊星者要问「许可写了吗」。

玩家可以把任务写成协议、法案附件或承诺，让它在政治上站得住；也可以硬派，承担关系与民意代价。 [协议](03-agreements-and-policy.md) · [议事会](09-council-and-laws.md)
