# Agent 工具目录

游戏里的 Agent 不是「会说话的对话框」。每个 Agent 都有身份、权限、资源、记忆与自己的目标；它能在议事会投票、在工地调人、在边境带路、在私下卖你一条情报。玩家看到的每一句台词背后，都应该有一次可追溯的行动。

这份目录定义 Agent 能做什么、需要什么、留下什么。**行为在 Agent 系统中就是 tool：有 tool 才能做对应的事，没有 tool 就只能说，不能做。** 具体实现由工具与命令网关约束；设计上先保证「每个角色都有丰富行动」，而不是只让五个党魁投票、其他人聊天。

> 15 个上场 Agent 的编制见[设定速查表](../world/canon.md)；支持与吞并见[支持与吞并](13-support-and-annexation.md)；Agent 社会见[Agent 社会](14-agent-society.md)。

## 一、谁在上场

| 类型 | 谁 | 数量 | 工具重心 |
|---|---|---:|---|
| 玩家 | 本派党魁 | 1（不是 Agent） | 全部玩家权限；不能替其他派投票 |
| 本派支持者 | 8 名支持者代表（含行政主管/资深支持者） | 8 | 工作、建议、执行、谈判、反对、请辞、倒戈 |
| 其他四派党魁 | 其余四派的领导者 | 4 | 指挥本派工人、建造、投票、提案、挖角、谍报 |
| 外域 Agent | 追风、青枝、洛（各势力最高决策者） | 3 | 通信、贸易、巡逻、袭击、破坏、迁徙、谈判 |
| 普通工人 | 班组 | 若干 | 无工具；由规则模拟，不调用模型 |
| 世界导演 | 服务端运营 | 1（不进入世界规则） | 战略指令、时代任务、事件注入；不改事实 |

> 本表是**单人局**编制（15 个上场）。多人局中，五个席位各带 8 名 AI 支持者，另有 3 名外域与空席 AI 党魁，合计 43–46 个 AI 身份；但每席每日只有 3 名「活跃支持者」进入推理。见[多人体系](../multiplayer/README.md#四与单人版的十三条差异)。

## 二、行动预算与触发

| 项 | 规则 |
|---|---|
| 每轮行动 | 每个 Agent 每游戏日 1 次主行动 + 1 次社交行动；对话不额外计时，但会暂停游戏 |
| 实际频率 | 多数日子只有 3–5 个关键决策触发模型；其余由规则、简报与低阶决策处理 |
| 触发 | 玩家对话、到期承诺、议事议程、危机、季节事件、其他 Agent 的请求 |
| 不做每帧推理 | 只在触发时决策；世界时钟照常走，Agent 不因玩家没点开就不行动 |
| 权限检查 | 任何行动先查身份、授权、资源、位置、知识；不满足就拒绝或改提替代方案 |
| 留痕 | 行动写入议事录、任务回执、库存流水、关系记录或传闻；部分留痕对玩家不可见 |
| 失败 | 权限不足、资源不足、路线不通时，必须给出拒绝与原因；不能「假装做成」 |

## 四、工具带（Tool Belt）

不是每个 Agent 都有全部工具。工具带由身份、岗位、权限决定：

| Agent | 核心工具 | 不能做 |
|---|---|---|
| 玩家（党魁） | 提案、表决、辩论、承诺、交易、派遣、建造、询问、监视、搜查、驱逐、任命 | 替其他派投票；直接改其他派政策 |
| 行政主管/资深支持者 | 建议、游说、承诺、质询、审计、内部协调、反对、请辞 | 代替玩家投票；擅自调动玩家队伍 |
| 工务/物资/医政/治安/配给/通信/档案 | 本岗位工作、执行、报告、请愿、反对、怠工、请辞 | 越权调动其他岗位；私自对外签约 |
| 其他四派党魁 | 提案、表决、辩论、游说、承诺、交易、派遣、建造、挖角、谍报、宣战/停战（4 票） | 进入玩家地块；直接指挥玩家工人 |
| 外域 Agent（最高决策者） | 通信、贸易、巡逻、袭击、破坏、迁徙、谈判、封锁 | 建造人类建筑；直接投票 |
| 普通工人 | 无（规则模拟） | 一切 Agent 行为 |

### 工具绑定与权限

- 工具不是「会说话就能用」；绑定由岗位、授权、位置、资源、知识共同决定。
- 玩家可以授予临时权限（如「这次运输你签」），但会留下授权记录；越权会被审计。
- 外域 Agent 的工具受红线限制：青枝不能「断根」自己，追风不能「圈禁」自己，洛不能「逆向军用技术」。
- 世界导演不占用 Agent 工具；它只通过导演指令与事件注入改变压力。

## 五、可见性与留痕

| 行动 | 玩家能看到 | 玩家看不到 |
|---|---|---|
| 公开表决 | 谁投了什么 | 对方为什么投 |
| 私下会面 | 谁和谁、何时、何地、多久 | 内容 |
| 交易 | 库存流水、协议文本 | 私下口头承诺 |
| 挖角 | 会面痕迹、态度变化、请辞 | 对方给了什么条件 |
| 监视 | 更详细的会面记录 | 仍然没有内容 |
| 搜查 | 信件/礼物/契约/钱 | 目标的心理 |
| 袭击 | 谁打的、损失、死亡名单 | 谁授权的（如果是可否认行动） |
| 破坏 | 损失、可能的痕迹 | 具体执行者 |

**没有全知视角。** 玩家只能通过对话、证据、会面痕迹、行为、第三方转述推断；研究控制台可以看到完整链路，但玩家界面永远不显示。

## 六、一个法案如何被 Agent 推着走

《轮换供水法》不是玩家一个人写出来的。它通常是这样走的：

1. 地生的林芜先在议事会提「果园水量连续两季偏低」，把问题变成公开事实。
2. 公社的闻昭要求看水闸账，谷寻提供实测；伊诺把账目公开，街头开始偏向轮换。
3. 砾火的岑雁反对，提出「矿场用水不能减」；霍岩在私下说「如果护送能保证，矿车可以晚半天」。
4. 止戈的唐箴要求把医院写进豁免；苏回要求明确「停水时谁先送医院」。
5. 远星的乔述不表态，等玩家拿锚区道路许可来换。
6. 玩家把修改条款写成文本，分别给四派看；每一派都在文本里加了一句自己的话。
7. 表决日，公社、地生、止戈投赞成，砾火反对，远星弃权。3 比 1，通过。
8. 生效后，公社的温原与陶安执行；砾火的矿场拖延了两天，执行度 72%。

这一周里，玩家做的事是「把别人的行动接起来」，不是「说服所有人」。

## 七、三个 Agent 的一周

| 日 | 闻昭（公社行政主管） | 岑雁（砾火党魁） | 洛（泊星者） |
|---|---|---|---|
| 一 | 定本周议程；把《轮换供水法》排在第一项 | 巡隘口，记录雪线与车辙 | 修观测塔的结霜镜片 |
| 二 | 审泵房预算；要求陶安先出材料清单 | 训练守备队；拒绝一次没有担保的夜间通行 | 与乔述校对「完成」与「验收」两个词 |
| 三 | 见根庭使节；用粮价换水务让步 | 与追风谈南迁会合点；不交备用路线 | 向泊星议会报修复价；被压价 |
| 四 | 压砾火的矿场工程，要求先保住宅热站 | 在议事会质询矿场用水；引用去年枯水账 | 拒绝人类商队的残轨场盗采许可 |
| 五 | 拉票；用预算支持换远星的赞成 | 处理一次边境袭扰；放走被抓的巡裔少年 | 向远星放风：白障可能提前 |
| 六 | 准备执行令；安排温原与陶安 | 给玩家回信：可以谈，但要先看到护送 | 观测白障；把修复队排到待命 |
| 日 | 看日结；把执行拖延记进下周议程 | 参加春祭；听长老会抱怨灰港哨所 | 向议会申请一次外出修复许可 |

三个人的一周没有一条是「等玩家来接任务」。玩家只是碰巧在他们的行动之间插了一脚；插得进去，是因为玩家手里有他们需要的东西。

| 有台词没行为 | 每个行为必须对应工具与规则结果；不能「假装做成」 |
| 工具万能 | 工具受权限、资源、位置、知识限制；越权有记录 |
| Agent 全知 | 只知道自己看见/听见/被合法告知的事 |
| 玩家读心 | 会面只有痕迹，没有内容；询问可能被拒绝/撒谎 |
| 行动太多 | 每 Agent 每日 1 主 + 1 社交；其余由规则与简报处理 |
| 失败被掩盖 | 权限不足/资源不足/路线不通必须给原因码与替代方案 |
| 外域像任务发放器 | 外域有红线、季节、内部政治；可以拒绝、拖延、加价 |
| 世界导演改事实 | 导演只改意图与压力；结果由规则与 Agent 决定 |
