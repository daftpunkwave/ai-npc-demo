# 协商、协议与政策

玩家通过谈话发现条件，通过提案明确当事人和期限，通过任务、法案或政策事实兑现条款。岑雁说「可以谈」意味着有一种可接受的方案。受邀人需要在出发前接受才能参加。无人受邀时可由队伍独立执行。队伍实际完成后才形成行动结果。

开放世界比序章多三种约束：**协议**是当事人之间的可执行合同，**承诺**是写进议事录的政治欠账，**法案**是全城适用的规则。三者都会留下记录，但违约的代价不同。

## 四种约束

| 约束 | 谁和谁 | 怎么成立 | 谁执行 | 违约代价 |
|---|---|---|---|---|
| 协议 | 两个或多个当事人 | 提案 + 逐一接受 | 世界规则按条款核验 | 协议状态变 breached；关系、声誉、后续报价 |
| 承诺 | 党魁/岗位负责人/角色之间 | 写进议事录，有对象、内容、截止、见证人 | 议事会记录 + Agent 记忆 | 信任 −15、民意支持 −5、下次要价 +1 |
| 法案 | 全城 | 议事会 3 票（普通）/4 票（宪制）通过 | 本派岗位负责人执行 | 执行度下降；可被质询/审计/修法 |
| 条约 | 灰港与外域 | 外务岗位谈成 + 议事会 3 票批准（同盟 4 票） | 双方政府 | 关系 −15..−30、声誉 −10..−30、可能开战 |

协议管「这件事做没做」，承诺管「你说话算不算数」，法案管「这座城市按什么规则运转」，条约管「两个阵营之间的边界」。玩家经常要用一种约束去补另一种的漏洞：例如先签协议，再把协议写成法案附件，最后用承诺换第三方的票。

## 三类授权

| 问题 | 谁能回答 | 实际凭证 |
|---|---|---|
| **我能派谁、花多少** | 队伍和库存归属的派系，或已经授权的职务角色与玩家 | 委托列出队伍、库存点、各资源剩余额度和截止 |
| **某队能走哪个受限路口** | 道路控制方党魁 | 通行许可列道路、被许可派系、有效至何时。关闭道路对所有队伍停用 |
| **我能向谁交付一份资料** | 该证据的合法持有人 | 通过分享将指定证据交给指定受众，到达后才能据此知情 |

玩家不能替其他派系改政策。有权改变水闸分配的是公社，三条受控道路分别由砾火与泊星者决定。法案可以把某项政策固定下来，但执行仍要人。 [议事会](09-council-and-laws.md)

## 从口头谈到有效协议

1. **把意向说清。** 索取什么、对方顾虑什么、谁有权限。口头嘱托可能被角色记住，还可以把它提交成正式条款。
2. **提出版本。** 至少两名当事人，提出者算已接受这版。义务人必须属于当事人。资源承诺须在承担者权限和剩余额度内。截止在未来且不超过当前 tick + 168。未另列有效期时，提案经过 24 小时未生效则过期。
3. **逐一确认。** 另一方可接受、拒绝或还价。两方协议只要对方接受一次即可生效。多人协议要等其余各方都接受。提案阶段不预留队伍或物资。
4. **重提与补偿。** 待定提案收到还价即被替代。还价方提出并接受新版，其余人重新确认。已签约后需要另外提出与确认合法安排，历史中可查到原约后果和新约。
5. **对照完成事实。** 按义务人、实际事件、数量与时间核对。截止 tick 当时发生的有效完工或合法分享仍可履约，下一 tick 查账，不延长实际履约期。任何条款违约可给协议记违约结果，其他条款仍逐一结算。
6. **留到下一次请求。** 当事人可引用真实履约或违约。未到期或正在路上的任务需要继续盯到最终回执。 [记忆与关系](04-clues-and-npc.md)

## 八类可签条款

| 条款 | 生效后做到什么 | 履约依据与失约条件 |
|---|---|---|
| 交付资源 | 写资源、量、起止仓、截止 | 义务人派遣或其派系队伍完成对应运输，累计量达到约定，截止后仍不足则违约 |
| 护送道路 | 写道、截止 | 义务方完成这条路的护送才结算，只有开始巡护仍待履约 |
| 救援群体 | 写群体、截止 | 义务方完成该群体救援时结算。签约对象须仍有待救人员 |
| 维修中继 | 写截止 | 义务方完成一次中继维修，按任务结果履约 |
| 分享证据 | 写证据、收件人、截止 | 义务人持有资料并按规定提交合法分享，分享受众包含约定对象 |
| 授予通行 | 写道、获准派系、截止 | 控制方在生效时给许可。有效期内关闭该路可能构成违约 |
| 保持分水 | 写目标政策、截止 | 公社在生效时设定分水。有效期内改成其他值可能构成违约 |
| 资源或队伍委托 | 写受托人、队伍与可动用库存和余额、截止 | 资产所属方在生效时发有效委托。出任务时再核对实际库存和余额 |

开放世界追加四类政治条款，它们不进世界合同，而进议事录：

| 条款 | 写法 | 兑现 | 违约 |
|---|---|---|---|
| 投票承诺 | 「X 法案表决时投赞成」 | 表决记录 | 信任 −15，下次交易要价 +1 |
| 法案支持 | 「在议事会为某案附议/辩论/拉票」 | 议事记录 | 信任 −10，民意 −3 |
| 贸易交付 | 「本周向某方交付 N 货物」 | 商队回执 | 关系 −10，声誉 −5 |
| 停战保持 | 「N 周内不袭击某方」 | 事件记录 | 关系 −25，声誉 −15，可能重启战争 |

通行许可、分水和委托作为即时条款，在协议生效时执行并记履约。打开一条道路是调整政策，授予许可是在受限状态下让指定派系走这条路。到期后仍以当下路况和分水设置为准，许可与委托分别查有效期。承诺期内提前关路或改分水可以触发违约。

## 政策

政策是城市的长期设置，只有对应党魁或法案授权的执行者能改。玩家通常只能去说服、交易或推动法案。

| 政策 | 谁能设 | 取值 | 常见来源 |
|---|---|---|---|
| 水闸分配 | 公社党魁 | 灰港优先 / 轮换 / 果园优先 | 法案、协议条款 |
| 道路状态 | 道路控制方 | 开放 / 受限 / 关闭 | 党魁决定、动员、条约 |
| 中继功率 | 工务岗位 / 公社 | 通信优先 / 均衡 / 供热优先 | 工务岗位每日决定、法案 |
| 配给标准 | 公社 / 配给岗位 | 足额 / 定量 / 紧缩 | 《口粮定量法》 |
| 用地规则 | 议事会 | 公地优先 / 协商补偿 / 派系自治 | 《用地扩张法》《派系自治法》 |
| 边境状态 | 议事会 / 治安岗位 | 开放 / 筛查 / 封锁 | 《收容配额法》《边境封锁法》 |
| 关税 | 议事会 | 0–15% | 《贸易开放法》 |
| 民兵征召 | 治安岗位 | 无 / 限额 / 全面 | 《动员授权法》 |

政策变化是公开事实，所有主体立即获知；但政策执行仍要人。公社可以设轮换，配给席可以拖两天；砾火可以开路边检，哨兵可以多问一句。玩家要盯的不是「政策写了什么」，而是「今天实际怎么执行」。 [执行度](09-council-and-laws.md)

## 三种能演出来的谈判

- **护林与通电。** 玩家用历年分水账说明优先灰港对果园的代价，请公社签轮换。公社担心通信，在讨论中要求给出维修的队伍、材料或对手方。轮换与修复在两个时点分别落实，看日结和实际作业是否如期。
- **星图与维修。** 确保至少一方发现并持有星图。请乔述核对「星图与校准表」指同一份证据。玩家承担限期分享，泊星者承担限期修复，洛可被列为约定接收者。通行若需要单列，写清获准的派系和道路。
- **局部停火与救人。** 唐箴可以把长篇停火愿景收束成「砾火保证某派在这一段通行、止戈在某时前完成救援」。本派救援支持者按合法派遣及时出发，双方保持原有立场也能救同一批人。

玩家退出一场讨价还价时，应能从面板上看到行动仍可行的部分。例如通行条件尚未谈成，可以先发出同节点沟通、核实备用公开路径或找已具备通行的队伍。 [派系筹码](../factions/README.md) · [玩家实例](../playthrough.md)
