# 袭击、死亡与修复

灰港不是安全的。城外三个阵营会为了路、水、粮、技术或一句冒犯动手；城里也有人会借外域的手除掉对手。袭击不是背景事件，它会把玩家建起来的东西烧掉，把玩家认识的人杀死，然后让玩家在议事会上解释为什么。

这一页定义：谁袭击、怎么打、死伤怎么算、建筑怎么坏、怎么修、政治上怎么追责。

> 数值与建筑三态见[设定速查表](../world/canon.md)；城建见[城建与供热](08-city-building.md)；外域关系见[外交与谍报](10-diplomacy-and-intrigue.md)。

## 一、谁会袭击

| 袭击者 | 什么时候 | 打什么 | 风格 |
|---|---|---|---|
| 巡裔 | 边境紧张 >60、牧道被封锁、向导被扣 | 边环建筑、落单车队、孤立哨所 | 夜间、快速、打了就走；留箭/皮绳/脚印 |
| 根庭 | 水源被断、深根井被抽、幼体受威胁 | 水站、温室、边环地基、道路 | 菌雾、顶裂地基、污染水源；很少见血 |
| 泊星者 | 锚区被侵入、技术被逆向、条约被撕 | 水站、热站、通信塔、中继附属 | 精准打击、定向干扰、断供；不占地面 |
| 人类派系（可否认） | 玩家/对手在谍报中授权 | 对手的仓库、工地、车队 | 用外域代理人、匿名信、黑市货；被抓会变成丑闻 |
| 世界导演事件 | 白障、迁徙、封锁、危机 | 由事件决定 | 不是“导演想让你输”，是压力测试 |

## 二、袭击怎么发生

### 1. 预警

| 预警来源 | 提前量 | 可靠性 |
|---|---|---|
| 哨塔 | 6–12 小时 | 高；但哨塔可能被先打掉 |
| 巡逻队 | 2–6 小时 | 中；取决于路线 |
| 追风/青枝/洛的提醒 | 6–24 小时 | 高；但他们可能要求回报 |
| 侦察队 | 12–24 小时 | 高；需要队伍与路权 |
| 传闻/商队 | 1–3 日 | 低；可能是假的 |
| 无预警 | 0 | 伤亡 +50%，建筑损毁概率 +30% |

玩家可以在袭击前做：撤人、加固、调民兵、修哨塔、转移物资、找对方谈判、先发制人。

### 2. 目标选择

袭击者按以下优先级选目标：

1. 无防御、低热级、靠近外域的边环/外环建筑；
2. 最近被玩家用来压制对方的设施（矿场、哨塔、水站）；
3. 有象征意义的目标（医院、广播站、议事厅外围）；
4. 车队/巡逻队/落单的人。

玩家可以通过**防御布局**改变目标选择：把哨塔、防风墙、训练场放在边环，把医院、温室放在内环，让袭击者“打不到值钱的东西”；或者故意留一个诱饵，引对方来打，再埋伏。

### 3. 结算

一次袭击分三步：

| 步骤 | 掷什么 | 结果 |
|---|---|---|
| 突破 | 袭击兵力 × 隐蔽 × 玩家防御 | 成功/被挡/部分突破 |
| 破坏 | 目标建筑 HP、袭击强度、防御 | 完好/受损/损毁 |
| 伤亡 | 在场人数、预警、疏散、医疗 | 工人死亡 0–8；Agent 受伤/死亡 |

简化公式（设计基线，不是最终数值）：

```text
突破力 = 袭击兵力 × 隐蔽系数 × (1 − 防御系数)
防御系数 = 哨塔 0.15 + 防风墙 0.10 + 民兵巡逻 0.15 + 训练场 0.10（上限 0.45）
建筑结果 = 突破力 > 建筑HP × 0.6 → 损毁；> 建筑HP × 0.3 → 受损；否则完好
死亡 = floor(突破力 × 0.1 × (1 − 预警系数) × (1 − 疏散系数))
```

- **预警系数**：有预警 0.5，无预警 0。
- **疏散系数**：有疏散演练 0.3，临时撤离 0.15，无 0。
- **Agent 伤亡**：如果 Agent 在场，先按 30% 概率受伤（48h），再按 10% 概率死亡（永久）。玩家可以命令 Agent 不上一线，但会降低现场指挥效果。
- **永久死亡与补位**：死者永久退出。岗位在 3–7 日内由另一名人物接任，补位期间岗位执行度 −30%。玩家派从班组头目或外部人物补位，AI 派系也可启用本派未上场的名册成员。接任者始终使用自己的身份、性格、记忆、关系与立场。候选来源见 [roster.md — 开局名册与替补](../characters/roster.md)。
- **玩家死亡**：玩家不是 Agent，但如果亲自上一线/遇袭/染病，也可能死亡或重伤；死亡进入继承/遗产局，见[长局与复玩](07-progression-and-replay.md)。

### 4. 死亡名单

每次袭击生成一份**具名死亡名单**：

- 姓名、岗位、班组、年龄（可选）、家属；
- 死亡地点与原因；
- 谁在场、谁没能救；
- 谁负责该区域的防御。

名单进入简报、医院记录、阿禾的食堂账、编年史。玩家不能压名单；压了会被伊诺/穆枝/阿禾公开。

## 三、建筑三态

| 状态 | 外观 | 产出 | 热需 | 修复 |
|---|---|---|---:|---|
| 完好 | 屋顶完整、烟/灯正常 | 100% | 正常 | — |
| 受损 | 屋顶破口、窗户钉板、烟断续 | 50% | +1 | 材料 = 建造成本 ×30%；工期 = 成本 ÷10 +2h |
| 损毁 | 墙基/焦黑框架、冒烟/积雪 | 0% | — | 先清墟（材料 ×20%，2h），再按 ×70% 重建；住宅损毁会死伤住户 |

- 受损建筑可以继续用，但热需 +1；寒潮时可能直接停机。
- 损毁住宅会让住户无家可归；无家可归 >40 时疾病 +5/日。
- 损毁医院/水站/热站会触发二级危机（疾病、断水、冻伤）。
- 修复期间产出减半；修复优先权是政治决定。

## 四、修复

### 修复流程

1. **评估**：陶安/沈砾/工程队评估结构，给出材料、工期、风险。
2. **备料**：从公库/派系仓出材料；材料不够可以拆别的建筑（退回 50%）或向外域买。
3. **派队**：工程队 + 班组；如果边环不安全，需要民兵护送。
4. **施工**：按工期推进；寒潮 +50%；袭击可能打断。
5. **验收**：陶安/沈砾签字；虚报完工会被记录。

### 修复的优先级

玩家不可能同时修所有东西。常见取舍：

| 优先修 | 理由 | 代价 |
|---|---|---|
| 住宅 | 冻死/生病会掉支持 | 材料和工时挤占生产 |
| 医院 | 疾病扩散 | 需要穆枝/辛夷的人手 |
| 水站/热站 | 断水/断热会连锁 | 需要能源与工程队 |
| 哨塔 | 防止下一次袭击 | 不直接产出，砾火民意支持 + |
| 矿场/工坊 | 恢复产出 | 工人可能还在伤亡名单上 |

修复承诺会进入账本；玩家答应“本周修好”但没修，支持者会记。

## 五、防御

| 防御 | 效果 | 成本 | 谁支持 |
|---|---|---|---|
| 哨塔 | 预警 +6–12h；边境紧张 −2/周 | 15 材料、4 人力 | 砾火、白露 |
| 防风墙 | 相邻边环热级 +1；降低袭击破坏 10% | 20 材料 | 公社、砾火 |
| 训练场 | 民兵 +10；守城 +10% | 25 材料、10 人力 | 砾火、荆离 |
| 民兵巡逻 | 降低袭击成功率 15%；发现潜入 | 人力、供给 | 砾火、陆沉 |
| 疏散演练 | 死亡 −30% | 时间、广播 | 止戈、阿禾 |
| 医院/医务所 | 伤员存活 + | 医疗、人力 | 地生、穆枝 |
| 外交/条约 | 降低紧张、提前预警 | 资源、承诺 | 远星、乔述 |
| 庇护 | 对方出手保护 | 政策/资源让渡 | 任何一派 |

防御不是万能的：玩家可以把边环变成堡垒，但会挤占生产；也可以放弃边环，把人和资源撤到内环，但会失去边环的支持者与地块。

## 六、政治后果

袭击之后，议事会不会安静。

| 后果 | 触发 | 玩家要做什么 |
|---|---|---|
| 追责 | 死亡名单公开 | 解释防御为什么不够、谁负责、怎么改 |
| 支持者态势 | 死者家属/班组 | 阿禾/陆沉/相关支持者 −1 档；安抚或补偿 |
| 法案 | 砾火要求扩民兵；止戈要求人道通道；公社要求审计 | 拉票、交易、否决 |
| 外域关系 | 玩家报复/不报复 | 关系、紧张、声誉变化 |
| 吞并试探 | 对手看到玩家弱 | 修补、展示实力、找庇护 |
| 编年史 | 死亡与修复 | 进入结局与遗产局 |

**袭击不是惩罚，是压力测试。** 它测试玩家的防御、资源、政治联盟与人心。玩家可以输掉一次袭击，但不能输掉对死亡的解释。

## 七、一个例子：边环回收场之夜

第 4 日夜里，巡裔的一支小队摸到边环回收场。哨塔在三天前被调去守矿场，回收场没有预警。

- 突破力：袭击 30 × 隐蔽 1.2 × (1 − 0.1 防风墙) ≈ 32.4
- 建筑 HP 40：32.4 > 24 → 损毁
- 死亡：floor(32.4 × 0.1 × 1 × 1) = 3 人
- 名单：老周（回收场领班，52 岁）、小满（学徒，16 岁）、阿禾手下的少年（14 岁，帮忙搬料）
- Agent：无人在场；陆沉在哨塔，白露在另一段边境。

第二天：

- 阿禾在食堂念了三个名字；队排得很长，没人说话。
- 陶安评估：清墟 2h + 重建 15×70%≈11 材料 + 4h；本周材料已经答应给温室。
- 白露在议事会质问：“哨塔为什么调走？”岑雁要求扩民兵；唐箴要求给边环建避难所；乔述说泊星者可以卖预制件，但要通行许可。
- 玩家可以选择：先修回收场（恢复材料）、先修住宅（防冻死）、先修哨塔（防下一次）、或者什么都不修，先安抚阿禾与死者家属。

没有正确答案。玩家只能决定**这一周先对不起谁**。

## 八、设计护栏

| 风险 | 护栏 |
|---|---|
| 袭击太频繁 | 同一外域两次袭击 ≥5 天；紧张 <60 不袭击；白障期间最多 1 次 |
| 死亡太随机 | 有预警、防御、疏散、医疗四条减伤路径；玩家可以准备 |
| 死亡太轻 | 具名名单、家属、葬礼、支持变化、编年史 |
| 修复太简单 | 材料、工期、工程队、二次袭击、优先级取舍 |
| 修复太挫败 | 受损可继续用；拆东墙补西墙；外域买材料；泊星者修复合同 |
| 玩家被追责到无法玩 | 追责是政治事件，不是自动失败；玩家可以解释、补偿、改革 |
| 袭击只针对玩家 | 其他派系也会被袭击；玩家可以看他们的损失与反应 |
| 袭击只是数值 | 每次袭击有场景、有名字、有后果；不是“-20 材料” |
