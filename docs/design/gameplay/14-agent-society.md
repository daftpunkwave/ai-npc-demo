# Agent 社会

15 个 Agent 不是 15 个对话框。他们有工作、有日程、有想见的人、有不想见的人；他们会在玩家不在场时见面、交易、争吵、结盟、撒谎。玩家看到的不是“NPC 状态”，而是一座城里 15 个人各自的生活。

这一页定义：他们每天怎么过、怎么见面、怎么记、怎么变、怎么背叛，以及玩家能看见什么、不能看见什么。

> 工具与权限见[Agent 工具目录](11-agent-actions.md)；支持态势与吞并见[支持与吞并](13-support-and-annexation.md)；隐私与证据见[情报、沟通与 NPC](04-clues-and-npc.md)。

## 一、一天怎么过

| 时段 | 大多数 Agent 在做什么 | 玩家能看到什么 |
|---|---|---|
| 06–09 | 起床、吃饭、查看夜间消息/读数 | 简报：谁病了、谁迟到了、谁连夜出了城 |
| 09–12 | 主职工作：工地、医院、库房、议事厅、边境 | 建筑产出、队伍动向、公开场合的会面 |
| 12–14 | 午饭；半公开社交 | 食堂/集市里的会面痕迹；谁和谁坐一桌 |
| 14–18 | 主职工作；处理请愿、谈判、巡查 | 任务回执、会面痕迹、公开争论 |
| 18–21 | 私人时间；私下会面、喝酒、回家 | 只有被监视/被撞见/被举报的会面 |
| 21–06 | 休息；夜间事件（袭击、火灾、急病） | 紧急通知；夜间巡逻记录 |

- **主行动**：每 Agent 每日 1 次，用于工作、谈判、建造、调查、袭击等。
- **社交行动**：每 Agent 每日 1 次，用于见人、吃饭、传话、试探。
- **例行工作**：不调用模型，由规则结算（产出、维护、巡逻、治疗）。
- **请愿/事件**：每日最多 2–3 个上桌；其余进简报。
- **夜间**：只有紧急事件唤醒 Agent；不做每帧推理。

## 二、会面

会面是 Agent 社会的核心。两个人见面，可能交换信息、交易、结盟、挖角、威胁、安慰、撒谎。

### 会面的可见性

| 类型 | 地点 | 谁能知道 | 玩家能看到 |
|---|---|---|---|
| 公开 | 议事厅、广场、集市、食堂 | 所有人 | 谁和谁在何时同处一处；公开交谈内容 |
| 半公开 | 酒馆、医院走廊、工坊门口 | 附近的人、目击者 | 会面事实；可能有片段 |
| 私下 | 仓库后巷、住宅、党部内室、城外 | 只有当事人 | 只有被监视/被撞见/被举报时才知道 |
| 秘密 | 城外节点、旧隧道、夜间 | 只有当事人与极少数人 | 几乎不可见；只能通过行为、物资、传闻推断 |

**会面痕迹**的最小单位：谁、和谁、何时、何地、大约多久。没有内容，没有录音，没有摘要。玩家可以看到“温原和乔述在旧仓库后巷待了半个钟头”，但不知道他们说了什么。

### 会面能做什么

| 目的 | 例子 | 可能的结果 |
|---|---|---|
| 交换信息 | “砾火在调兵”“医院缺药” | 双方知识变化；可能泄露给第三方 |
| 交易 | 资源、通行、情报、选票 | 协议/承诺/私下交易；可能违约 |
| 结盟 | “我们一起推这项法案” | 共同投票/共同行动；可能被对方出卖 |
| 挖角 | “来我们这边，给你一个岗位” | 目标支持态势变化；可能倒戈 |
| 威胁 | “你妹妹在外环不安全” | 目标让步/反弹/报复 |
| 安慰 | “你做得够了” | 关系改善；压力下降 |
| 试探 | “如果我不投这一票呢？” | 透露底牌/装傻/反试探 |
| 撒谎 | “我没见过他” | 需要反证；可能被拆穿 |

### 会面怎么被判定

会面不是玩家点“交谈”才发生。Agent 会在以下情况主动约人：

- 有求于人（资源、保护、情报、票）；
- 有人欠他人情；
- 有共同利益/共同敌人；
- 有秘密要分享/隐瞒；
- 有情绪要发泄/安慰；
- 对手来挖角；
- 到期承诺要谈。

系统每天为每个 Agent 生成**社交意图**，按优先级合并；只有涉及玩家或关键事件时才调用模型。玩家不在场时，会面由规则 + 轻量决策完成，结果写入记忆与关系账本。

## 三、对话与隐私

### 玩家能问什么

玩家可以直接问任何 Agent 任何问题。对方是否回答、回答多少、是否撒谎，由以下因素决定：

| 因素 | 影响 |
|---|---|
| 对玩家的态势 | 坚定的人更可能坦白；离心的人更可能回避/撒谎 |
| 是否有把柄在玩家手里 | 有把柄更可能配合，但也会记仇 |
| 是否在保护别人 | 可能替人隐瞒 |
| 是否已经答应对手 | 可能撒谎/拖延 |
| 是否相信玩家会报复 | 不信则更敢说 |
| 是否觉得真相会伤害玩家 | 可能选择不说 |
| 问题的敏感度 | 涉及秘密/底线时，回答更可能模糊/拒绝 |

### 五种回应

| 回应 | 例子 | 玩家能做什么 |
|---|---|---|
| 坦白 | “见了。他问我愿不愿意去砾火，我没答应。” | 继续问细节、看行为是否一致 |
| 部分坦白 | “见了，谈的是转运单。别的我不能说。” | 接受边界，或施压（关系 −1） |
| 回避 | “就是工作。” | 换角度问、问第三方、监视 |
| 撒谎 | “我没见过他。” | 用会面记录/目击者/物资流水反证；拆穿后关系 −2，但可能得到真话 |
| 反击 | “你是在审我？” | 道歉、解释、或强硬（关系 −1 到 −2） |

**没有读心术。** 玩家不能看到对方的内心独白、记忆全文或精确支持分数。研究控制台可以；玩家界面永远不显示。

### 第三方与证据

玩家可以通过以下方式交叉验证：

- 问目击者（可能失真、有动机）；
- 调会面记录（议事厅、哨塔、 relay 日志）；
- 查物资/库存流水（谁领了什么、送到哪）；
- 查通信记录（谁在何时发信、收信）；
- 监视（治安支持 + 班组 + 时间）；
- 搜查（需要理由与证据门槛）；
- 设局（用诱饵让对手暴露）。

每一条证据都有来源、时点、可分享对象；玩家不能拿一条传闻当证据，也不能把秘密直接公开。

## 四、记忆

Agent 的记忆不是聊天记录，是**带来源、带情绪、带偏差的账**。

### 记什么

| 类型 | 例子 | 影响 |
|---|---|---|
| 事实 | “他在 t44 送来了 8 点供给” | 信任/债务 |
| 情绪 | “他在会上让我下不来台” | 亲近/戒备 |
| 承诺 | “他答应本周修哨塔” | 到期提醒/违约判断 |
| 秘密 | “他妹妹在砾火手里” | 筹码/保护 |
| 传闻 | “听说他拿了泊星者的钱” | 需要反证；可能误判 |
| 共同经历 | “我们一起在雾夜救过人” | 关系加深；很难被一次交易抹掉 |

### 怎么记

- **有来源**：谁说的、什么时候、在不在场。
- **有偏差**：人会记错、记仇、记恩；记忆维护策略不同，细节不同。
- **有半衰期**：小事会淡，大事不会；背叛比恩情记得久。
- **不能伪造**：世界事实以事件与回执为准；Agent 可以记错，但不能把没发生的事当成事实。

### 遗忘与更新

- 日常小事 7–14 日淡化；
- 承诺/违约/伤亡/背叛长期保留；
- 新证据可以修正旧判断，但不能删除旧记录；
- 关系改善需要多次兑现，关系恶化只需要一次背叛。

## 五、性格

每个 Agent 有一套稳定的性格参数，决定他怎么说话、怎么判断、怎么反应：

| 维度 | 低 | 高 | 例子 |
|---|---|---|---|
| 谨慎 | 先做再说 | 先算再做 | 岑雁高，周野低 |
| 共情 | 看规则 | 看人 | 穆枝高，简宁低 |
| 程序 | 结果重要 | 过程重要 | 唐箴高，霍岩低 |
| 冒险 | 稳 | 赌 | 洛中高，温原低 |
| 表达 | 少说 | 多说 | 陆沉低，阿禾高 |
| 信任 | 先疑 | 先信 | 林芜中高，岑雁低 |
| 记仇 | 忘得快 | 记得久 | 祁录高，阿禾低 |

性格不是标签，是**倾向**。同一个人在不同情境下会做出不同选择；性格只决定他更可能怎么选，不决定他一定怎么选。

### 底线

每个 Agent 有 1–2 条底线，碰了就翻脸，不能用交易绕过：

- 穆枝：医院不能当筹码；
- 温原：同一批货不能答应给两个人；
- 陆沉：不能让民兵背无证据的锅；
- 阿禾：不能把死人只当数字；
- 陶安：不能为政治面子赶工；
- 祁录：不能篡改记录；
- 岑雁：不能拿守备队的命换政治；
- 林芜：医院不能当筹码，伤员不能作价；
- 唐箴：不能把伤员当筹码，也不能在没有接收人的情况下宣布停火；
- 乔述：不能拿译义玩文字游戏；
- 追风：不能把备用路线交给外人；
- 青枝：不能拿幼体冒险；
- 洛：不能逆向军用技术。

底线不是写在人物卡上的数值；玩家要通过对话、行为和后果推断。碰底线的反应通常是：拒绝执行、公开反对、关系骤降、甚至倒戈。

## 六、关系

关系不是一条好感度，是四本账：

| 账 | 含义 | 怎么变 |
|---|---|---|
| 信任 | 你说的话可不可信 | 履约、坦白、共同经历；违约、撒谎 |
| 亲近 | 你这个人可不可亲 | 安慰、吃饭、记住名字；羞辱、冷漠 |
| 敬畏 | 你有没有能力/手段 | 通过法案、守住袭击、惩罚对手；失败、软弱 |
| 亏欠 | 谁欠谁 | 援助、交易、承诺；赖账、背叛 |

四本账可以不同步：一个 Agent 可能很信任你，但不亲近你；可能敬畏你，但想离开你。玩家看到的“态势”是这四本账 + 信念 + 利益的综合判断，不是简单相加。

### 关系的影响

- 信任高：更可能坦白、接受邀请、替你说话；
- 亲近高：更可能在你困难时留下、提醒你、替你挡一次；
- 敬畏高：更可能执行命令、不敢撒谎；
- 亏欠高：更可能帮你一次，但会要求还。

## 七、背叛

背叛不是随机事件，是**压力 + 机会 + 理由**的结果。

### 为什么会背叛

| 原因 | 例子 | 前兆 |
|---|---|---|
| 利益 | 对手给了更好的岗位/资源 | 会面、请辞、抱怨 |
| 信念 | 你违背了他的底线 | 公开反对、拒绝执行 |
| 恐惧 | 他觉得这一派要完 | 转移家属、囤积物资 |
| 怨恨 | 你羞辱/忽视/牺牲了他的人 | 怠工、迟到、冷嘲 |
| 保护 | 他想保护家人/朋友 | 私下接触对手、询问退路 |
| 绝望 | 城市要毁了，他只想活 | 消失、偷渡、投靠外域 |

### 怎么背叛

- **消极**：怠工、迟到、请假、执行打七折；
- **泄露**：把你的计划/秘密告诉对手；
- **倒戈**：在关键表决前公开反对/投靠对手；
- **政变**：联合 ≥5 人倒戈，控制关键设施（极端）；
- **破坏**：毁掉关键物资/建筑/证据（极端）。

### 背叛的迹象

- 会面痕迹（和对手）；
- 态度变化（从坚定到动摇）；
- 行为异常（迟到、请假、工作拖延）；
- 物资/家属转移；
- 公开言论（抱怨、质疑、替对手说话）；
- 其他 Agent 的转述（可能有动机）。

### 背叛的后果

- 背叛者带走记忆、关系、秘密与一部分支持者；
- 被背叛者（玩家/其他 Agent）会记很久；
- 城市会付出代价（票、岗位、情报、建筑）；
- 背叛者不一定赢：对手可能用完就丢，外域可能不信任他。

## 八、Agent 之间的政治

Agent 不是只跟玩家互动。他们互相之间也会：

- **交换信息**：谁缺什么、谁在谋划什么；
- **交易**：资源、通行、票、保护；
- **结盟**：共同推法案、共同对付某个派系；
- **竞争**：抢地块、抢预算、抢玩家/资深支持者的注意；
- **恋爱/友情/仇恨**：不必是主线，但会影响判断；
- **互相评价**：A 觉得 B 可靠，C 觉得 D 是威胁。

这些互动在玩家不在场时也会发生。玩家只能通过会面痕迹、传闻、行为、事后文件知道一部分。

### 一个例子：三个人的午休

- 阿禾在食堂给陆沉留了饭；陆沉没来，因为他在哨塔。
- 温原和乔述在旧仓库后巷见面；温原想给妹妹找个外环的床位，乔述想买一批医疗材料。
- 穆枝在醫院屋顶浇菜；辛夷在手术室；两人没说话，但穆枝知道辛夷昨晚又没回家。

这三件事同时发生。玩家可能只知道第二件（会面痕迹），也可能从阿禾那里听说第一件，从穆枝那里听说第三件。玩家要根据这些碎片，判断谁在做什么、为什么、会不会影响下一次表决。

## 九、设计护栏

| 风险 | 护栏 |
|---|---|
| Agent 全知 | 每个 Agent 只能知道自己看见/听见/被合法告知的事；不知道就是不知道 |
| Agent 随机背叛 | 背叛必须有压力/机会/理由；有前兆；不是随机数 |
| Agent 只会说台词 | 每个行为必须对应工具与规则结果；不能“假装做成” |
| 玩家被淹没 | 每日 2–3 个请愿；其余进简报；Agent 之间自己解决问题 |
| 玩家读心 | 不显示精确分数/内心独白；只能通过对话、证据、行为推断 |
| 关系变成数值游戏 | 四本账 + 性格 + 底线 + 记忆；不是单一好感度 |
| 背叛太廉价 | 背叛有代价；背叛者不一定赢；被背叛者记得 |
| 死亡太轻 | 死亡有名字、葬礼、空缺、记忆；不是数字 |
