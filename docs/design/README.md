*The Hearth Council*

《炉边议会》是一款 3D 斜俯视的开放世界经营策略游戏（SLG）：**单人长局为主，设计上支持 1–5 人同城共治**。长冬之后，人类只剩少数靠中继炉供暖与通信的聚居地。灰港是其中之一：一座城里住着五个互相不服的派系，城外还有三个各有算盘的非人阵营。玩家不是市长，也不是全人类的主人，而是五派之一的**党魁**——手里一票、身边八个人、一张必须自己凑出来的票数。

长冬之下，三票决定谁先暖。

这一版设计把原来的七日章节扩展成完整游戏：建造、供热、议事、法案、外交、谍报、袭击、修复与开放世界局势都由 Agent 驱动。序章《水闸之前》保留为可玩切片，不再是全部。 [审查报告](REVIEW.md) · [与 Demo 的关系](sources-and-review.md)

## 三条设计承诺

1. **每个人都在算自己的账。** 15 个 Agent 不是任务发放器；他们有自己的工作、记忆、性格、打算和底线。玩家能赢，是因为把别人的利益接了起来，不是因为他们听话。
2. **每一票都要还。** 玩家决定本派那一票，但这一票由 8 个支持者的信任托着。今天投给谁，明天就要向谁解释。
3. **世界不为玩家暂停。** 外域会迁徙、封渠、袭击；其他派系会盖楼、挖角、提案；玩家不在场时，事情也会发生。

## 与旧稿的关系

旧稿是七日单章、五派开局、三非人势力、十二角色、15 席议事会、20 个 Agent、无城建与支持系统。本稿保留全部人物、地点、道路、库存与序章数值，把它们接进更大的循环：

- 标题从《最后的中继》改为《炉边议会》 / *The Hearth Council*；旧名保留为中继网络的旧称。
- 七日章节成为序章与首个实现切片，t168 后不再结束，直接进入开放世界的第一周。
- 人类五派从「五个可选开局」变成「同一座城里的五个派系」，各 1 票、各 8 名支持者代表，共 5 票。
- 议事会从 15 席、10 票改为**五席、3 票普通法案、4 票宪制法案**。
- Agent 从 20 个改为 **15 个上场**：本派 8 名支持者 + 其余四派各 1 名党魁 + 三外域各 1 名最高决策者；名册扩到 40 人，按开局实例化。
- 玩家从「不能决定本派投票的议员」改为**本派党魁**；玩家决定本派一票，身边 8 名支持者代表可以支持、反对、离开，但不能替玩家投票。
- 巡裔、根庭、泊星者从「地图上的三个势力」变成「三个有领地、有诉求、会主动袭击与谈判的外域阵营」。
- 新增城建、供热、法案、支持、吞并、袭击、修复、外交、谍报、世界导演十套系统；旧的任务、协议、通行、证据与通信规则继续有效。
- 表现从 2.5D 等距改为 Frostpunk 式 3D 斜俯视：镜头从城市上方斜看，可旋转与缩放，不做贴地第一人称。
- 新增**多人共治**（1–5 名人类各占一个派系席位，Demo 只留接口）与**资产规定**（28 类建筑 ×3 级、43 名具名角色、4 个群系）两套文档；它们不改变单人规则，只把「以后要接什么」写清楚。
