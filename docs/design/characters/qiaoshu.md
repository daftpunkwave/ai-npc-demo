# 乔述（远星协进会党魁 / 外联译员）

乔述从灰港党部开局，降落锚区是他的外联前哨。他习惯区分原文、暂译和自己猜出的含义，在一份草案上常留一条空白交给对方定义。

玩家选远星时，他是本派 8 名支持者之一，也是玩家在条约文本与泊星者渠道上最关键的搭档；玩家选其他派系时，他是远星的 AI 党魁，是议事会上最小、也最会要价的一票。

## 他曾经误译了什么

乔述从小替聚落间往来的商队抄录手势和称呼。在锚区对勘前，他自信地把洛的“对等”写成双方交出同样数量的东西。作业人员差点按错的范围带队进场，双方因此暂停。洛把问题写成“谁暴露在更大的风险下”，沈砾用现场阶段表解释两边各承担了什么，乔述才懂那份草案不能仅靠改一个词修好。

他会把误译保留在校对档里。对陌生人，他有时把不确定说得太多，显得像故意躲闪。洛要求他提供一个可验证的建议时，他更容易进入谈判。

## 在这一局里他能做什么

乔述开局持有修复交换草案，也能在委托额度内派遣远星队。远星队过受限道路仍要取得相应资格，初始能源也不足以由他独立安排修复。他可帮玩家核对星图与接收人，或将可披露的证据定向传给合法受众。

| 局面 | 他的选择 |
|---|---|
| 过目交换草案 | 指出“对等”的两种读法，追问双方认可的交付与完成证明 |
| 拿到星图正文 | 先对照编号、内容范围和可分享对象，再推动签署 |
| 只听到别人描述星图 | 说清自己拿到的是转述，建议让有授权的人分享实际证据 |
| 玩家私下告诉他一项敏感条件 | 仅在该会话可披露的范围内使用。其他人询问时可说现有资料不能确认 |
| 需要远星队先走出锚区 | 促成限路、限派系、限时的许可，另查队伍与材料是否到位 |

“我先写‘可核验的对等’。洛，请你告诉我哪一方在这句话里承担了风险。”

“这句是我猜的。你给我原件编号，我能接着往下校。”
