# 穆枝

灰港公社医政长，开局在灰港中继站。五十多岁，头发全白，白大褂口袋里总有一把剪子和一小袋糖。她说话干、快，不喜欢别人在病房里谈政治。

## 她为什么不肯关医院的门

穆枝的丈夫死于 2949 年的一场疫病。那场病本来有药，但药被优先给了「更有用的人」——矿工、守备队、行政官。她丈夫是个修鞋匠，排在名单的最后。他死的时候，医院还有三箱药，锁在库房里，等批文。

穆枝没有闹。她只是从那以后做了一件事：医院的门不关。不管有没有批文，不管病人从哪来，只要还有一张床，她就收。

## 她怎么管医院

穆枝的医政席管着：

- 医院、隔离所、医务所的床位与人员；
- 医疗材料分配；
- 疾病监测与隔离令；
- 伤亡名单与家属通知。

她不是不懂政治。她知道药从哪来、钱从哪来、谁在卡她。但她把「病人」放在「立场」前面。玩家可以跟她谈资源、谈交换、谈优先级，但不能跟她谈「这个人值不值得救」。

### 她的暗流

- **那次 triage**：2959 年枯渠，医院同时来了果园幼体和人类伤员。穆枝按「先救能活的」分了药，结果两个人类病人死了。她从不提这件事，但每年枯渠季，她都会多备两箱药，锁在自己的柜子里。
- **与陶安的争执**：医院屋顶漏雨，陶安说要等材料，穆枝说「病人等不了」。两人吵完，陶安会半夜带人来补屋顶，但不告诉她。
- **辛夷**：辛夷是她的学生，也是她最担心的一个人。辛夷做过一次 triage，放弃了一个老人；穆枝知道，但她没有安慰他，只说「你记住他的名字」。

## 她能给玩家什么

| 玩家需要的 | 穆枝能给 | 代价 |
|---|---|---|
| 医疗材料 | 医院库存、菌丝药渠道 | 要先保病人；不能拿药做交易 |
| 疾病控制 | 隔离、筛查、疫苗 | 要给她人手；她不会封门 |
| 伤亡名单 | 真实名单、家属情况 | 她会公开；玩家不能压 |
| 医院支持 | 病床、手术、康复 | 玩家不能逼她挑人 |
| 政治背书 | 在议事会为医疗法案说话 | 玩家要保住医院预算 |

## 她怎么回应玩家

| 局面 | 她可能怎么做 |
|---|---|
| 玩家要拿医疗材料换选票 | 拒绝；但如果玩家能换回更多药，她愿意谈「以药换药」 |
| 玩家要她优先救某个支持者 | 先看伤情；如果伤情不紧急，她拒绝插队 |
| 玩家给她病床、药和人 | 接受；会在公开场合说「这个人给医院办了事」 |
| 玩家在袭击后压伤亡名单 | 当面拒绝；如果玩家坚持，她会把名单交给伊诺 |
| 玩家问她「当年你为什么不闹」 | 她会沉默一会儿，然后说：「我闹了。没人听。」 |
| 玩家承认自己怕死人 | 她会递给玩家一颗糖；这是她少数温柔的时刻 |

## 转折

穆枝的转折是**从「不关门的医院」走到「让医院不再靠她一个人撑着」**。她原本用自己的固执守住底线，后来可能愿意把「不收门」写成法律，把药柜的钥匙交给辛夷，把伤亡名单变成全城的记忆。

玩家能打开这一步的，是让她看到：**她守住的不是一个医院，是一座城对「谁值得活」的回答**。

## 台词

「一座城先看它的病床。」

「你要我挑人，我就先挑你。」

「药不够，我知道。可你不能因为不够，就说有些人不用救。」

「把名字记住。数字会忘，名字不会。」
