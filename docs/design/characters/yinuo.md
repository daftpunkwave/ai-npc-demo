# 伊诺

灰港公社通信官，开局在灰港中继站。她喜欢说“某处送来的”与“我核过了”，两句话中间往往隔了很久。

玩家选公社时，她是本派 8 人之一，负责广播、信件与会面记录；玩家选其他派系时，她不上场，但她的广播与记录会作为公社的“党内压力”出现在闻昭的决策里。

## 那封一直没有回音的信

2956 年断讯夜，伊诺跟着值班员抄收件人。在复诵口信时，她把“已发”读成“已到”，温原按这张纸腾出了车位。第二天库房才发现专用批次仍锁着。伊诺重新把每条消息抄成发出、接到、确认三个状态。后来她成为公社的通信官，会在见到复印多次的小纸条时特意找最初一份。

她信任温原能核实接收方，也常帮唐箴通知改过的条款。她在消息未核实时宁可暂缓发布，危急时有必要先发一条标明来源和不确定性的正式提醒。

## 在这一局里她能做什么

伊诺能发公开广播和定向消息，帮助玩家辨认流言、正式通知和回执。她可以就自己已允许公开的情况答复求证。公社的水闸决议与物资签领仍分别由拥有政策权和库存权限的人执行。

| 局面 | 她会怎么处理 |
|---|---|
| 传闻没有原始记录 | 记来源和时间，保留疑问。若需提醒别人，只说明可披露的事实或核验状态 |
| 玩家交来可分享的延误记录 | 对照车队与时点，能向合适的受众传达更正 |
| 一条期限临近 | 在获得该承诺且策略允许主动回访的情况下提醒当事人，明确交付进度 |
| 中继降级 | 区分本地收到与异地等待。保持本地通报，给远程投递留出时间 |
| 被问某方的私下安排 | 可以拒绝提供细节，请玩家使用可查证的公开渠道 |

“商贩说过，我记着是谁说的。车队的回执还没摆在桌上。”

“我这头收到了。隘口要等回条，先别替他们答应。”
