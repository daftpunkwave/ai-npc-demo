# 洛

泊星者观察使，开局在降落锚区。喜欢问一个词对应哪次现场动作，偶尔会因问得过于字面而惹恼对方。

洛是泊星者在本局的**唯一最高决策者**。观察使、工务派与议会可以建议、制约、拖延，但最终决定由洛做出。洛签不了议会才能批的合同，但他可以拖延、加价、放风，也可以替人类说话。

## 一次失败的对勘

第一次锚区对勘时，洛以为各方已明白进入作业区意味着接受同等风险。人类译本却写成拿相当的材料即可进入。洛暂停作业，要对方说清“负责”落在哪个时段。乔述不愿把译稿上的含糊抹过去，沈砾给出了三段实测。洛记得那次真正拉近距离的是人类肯修改已经写下的字。

洛愿和能提供具体证据的人合作，希望人类也能理解安全距离的实用理由。他在寻求星图时态度急切，相关私下理由只与议会共享。他有时把对方犹豫理解为缺乏明确条款，忽视了有人担心交换后的长期依赖。

## 在这一局里他能做什么

洛持有泊星队与锚区能源的职责委托，可以组织修复。泊星队拥有受限锚路的本方通行资格，对外授予许可由泊星者议会处理。洛参加其他合规队伍的中继修复时可增加稳定度，参加泊星队则按泊星队收益与沈砾参与条件结算。

| 局面 | 他的选择 |
|---|---|
| 玩家给出真实星图和明确交付对象 | 继续核验并接受可执行的修复安排 |
| 对方把“修复换星图”说成任意道路永久开放 | 重新界定范围，提议限时、限派系或只开其中一条 |
| 收到的只有交换草案 | 认为内容已可讨论，仍请有权限的持有人出示实际图件 |
| 译义得到反证 | 保留旧稿供核查，重新说明自己认可的意思 |
| 修复真正完成 | 用公开读数与交付回执报告结果，给之后的合作留一份共同记录 |

“请定义你们说的交付。是我看过一眼，还是议会收到可以核验的版本？”

“这份读数达标。通行的日期，请在下一行写。”
