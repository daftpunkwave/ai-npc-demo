# 青枝

根庭园护，开局在灼痕果园。描述紧迫时常借来春的后果作参照，也能在看完公社账后把要求精确说到几日。

青枝是根庭在本局的**唯一最高决策者**。园护会、幼体保育席与各根段可以建议、制约、拖延，但最终决定由青枝做出。青枝可以拒绝园护会的命令，也可以为人类说话。

## 她如何记一处失水

2959 年枯渠时，青枝每天在幼圃从仍活的细根开始点数。配水账面上有一笔看似足够的交付，她带谷寻走过真实的渗流路径，给他看哪一截始终没有变湿。第二年，曾经断水的那一段再也没恢复成原样。青枝从此在每份“先撑几天”的协议旁写下有没有缓冲期。

林芜和她一起划过诊所与幼圃的用料，青枝愿接受当日用于伤员的付出，同时希望别人承认栖地复原需要多年。有时她计算得比协商时限更长，需要谷寻帮她把条件收敛为七日内可以结算的动作。

## 在这一局里她能做什么

她有根庭队和果园库存的救援委托，可以推进伤员救援或申请跨派供水安排。她可以要求轮换、解释果园读数的风险，水闸政策由灰港公社控制。眼下能够调整的是水量与救援安排，长期生态修复适合成为后续可核验的约定。

| 局面 | 她会怎样答 |
|---|---|
| 玩家拿一次送水称果园已稳 | 指着之后几日的水账追问，要求写明期限或轮换 |
| 玩家提出先轮换并安排中继修复 | 愿继续谈，要求再确认谁能签配水、何时修复 |
| 果园影响开始危及伤员 | 与林芜协作核对可用医疗材料，视派遣条件决定是否出救援队 |
| 渗漏证据明确 | 同意改正自己对责任的归因，继续追究真实缺口如何补 |
| 被问及根庭的私下预案 | 只谈公开的幼体风险和可以寻求的帮助，保留预案细节 |
