# 祁录

灰港公社档案官，开局在灰港中继站的档案室。四十多岁，戴一副修过三次的眼镜，说话喜欢带年份和编号。他能记住二十年前的会议记录，但经常忘记自己有没有吃饭。

## 他为什么守着档案

祁录的父亲是灰港的第一批档案员。老祁录常说：「城会烧，人会死，纸不会。」2964 年的祁录并不完全同意——纸也会烧，也会被撕——但他还是接了父亲的班，因为如果没人记，灰港就不知道自己从哪来。

他整理过 2956 年断讯夜的全部记录，也整理过 2959 年枯渠的水账。他发现两件事对不上：断讯夜的补给出库单缺了一页，建城档案缺了十一页。他没有告诉任何人，因为他不知道谁撕的。

## 他怎么管档案

祁录的档案席管着：

- 议事记录、法案文本、承诺账本；
- 建城档案、旧图纸、星图、战前文件；
- 证据链：谁在什么时候、从哪拿到、能给谁看；
- 广播稿的出处核对（与伊诺合作）。

他不是权力的中心，但他是**记忆的中心**。玩家想查旧账、找旧图纸、证明对手撒谎，都要经过他。他也可以让一份文件「找不到」——但他很少这么做，因为他觉得那是在杀记忆。

### 他的暗流

- **那十一页**：祁录知道建城档案被撕掉的十一页在哪——他把它们藏在自己的住处，没敢看。他怕看了之后，自己就不再是「档案员」，而是「知情者」。
- **与闻昭的关系**：闻昭依赖他的记录补全自己听不见的部分。两人合作多年，但祁录知道闻昭有一件事没告诉他：她当年也在断讯夜的现场。
- **与老砚的联系**：远星的老砚有一张旧地图，上面标着一条通往「第六席」档案室的隧道。祁录不信，但他把地图抄了一份，藏在抽屉里。

## 他能给玩家什么

| 玩家需要的 | 祁录能给 | 代价 |
|---|---|---|
| 旧记录 | 议事录、法案、承诺、水账 | 要给出处；不能断章取义 |
| 证据链 | 谁持有、谁能看、怎么分享 | 要保护来源；不能逼他卖人 |
| 旧图纸 | 建筑、管道、中继、隧道 | 要说明用途；他会问「你要修什么」 |
| 对手的把柄 | 旧承诺、旧投票、旧账 | 他要先确认是真的；不做伪证 |
| 历史判断 | 这件事以前发生过吗、当时怎么处理 | 他会讲很久；玩家要耐心听 |

## 他怎么回应玩家

| 局面 | 他可能怎么做 |
|---|---|
| 玩家要查一份对自己有利的旧账 | 给；但会把不利的部分也一起给 |
| 玩家要他改一份记录 | 拒绝；如果玩家坚持，他会辞职，并把原件交给伊诺 |
| 玩家问他「那十一页是什么」 | 沉默；然后说「你确定你要知道？」 |
| 玩家保护档案室不被征用 | 他会记住；这是信任的起点 |
| 玩家拿一份没有出处的传闻来 | 他会说「这只能当传闻」，然后帮玩家找可核实的来源 |
| 玩家问他「你为什么不看那十一页」 | 他会说：「看了，我就得做点什么。」 |

## 转折

祁录的转折是**从「守着纸」走到「让纸说话」**。他原本把档案当成避难所，后来可能愿意把十一页公开，或者把「第六席」的真相交给玩家，让记忆变成行动。

玩家能打开这一步的，是让他看到：**知道真相不一定让人自由，但不知道一定让人重复**。

## 台词

「没有出处的话，只能当传闻。」

「那十一页不是我撕的。但我知道是谁撕的。」

「你要查旧账？可以。先把新的账写对。」

「纸不会烧？会的。所以我才守着。」
