# 阿禾

灰港公社配给员，开局在灰港外环的食堂。二十多岁，嗓门大，记得住每个人的名字和饭量。她会在打饭时骂人，也会在骂完之后多舀一勺。

## 她为什么总在食堂

阿禾是边环长大的孩子。她小时候，家里靠公社的配给活；配给不够的时候，她妈会把饭分给她和弟弟，自己喝汤。她十二岁那年，弟弟病死了，公社的名单上写的是「损耗」。

阿禾没有恨公社。她进了食堂，从洗菜做到配给员，学会了一件事：**名单上的数字，都是有人名的**。她开始在账本上偷偷记名字，而不是只记数量。温原发现过一次，没有骂她，只说「你记可以，别让审计看见」。

## 她怎么管配给

阿禾的配给席管着：

- 食堂、配给站、临时救济；
- 每日口粮分配与特殊配额（病人、儿童、孕妇、工人）；
- 收容所的食物与物资；
- 街头民意：谁在饿、谁在骂、谁在传话。

她不是政治家，但她是玩家最准的**民意温度计**。她不会说「支持率下降了」，她会说「今天打饭的时候，没人说话」。

### 她的暗流

- **多打的饭**：阿禾每个月会在账上做一点「损耗」，把多出来的饭给边环的孩子。如果审计查出来，她会被控贪污；温原知道，但一直替她压着。
- **与陆沉的关系**：陆沉夜里巡边环，阿禾会把饭盒放在门口。两人不怎么说话，但阿禾知道陆沉在替她守着那些孩子。
- **与甘棠的联系**：阿禾和止戈的甘棠经常交换食物与收容所名单。如果玩家支持收容，两人会成为玩家在街头的两条腿；如果玩家支持筛查，阿禾会为难。

## 她能给玩家什么

| 玩家需要的 | 阿禾能给 | 代价 |
|---|---|---|
| 民意情报 | 谁在饿、谁在骂、谁在传话 | 要听真话，不能只听好听的 |
| 配给支持 | 临时加餐、特殊配额、收容所食物 | 要有粮；她会先给孩子 |
| 街头动员 | 食堂、配给站的人手 | 要给她一个正当理由 |
| 伤亡名单 | 死者家属、孩子、老人 | 她会当众念名字；玩家不能拦 |
| 选举/支持 | 在街头替玩家说话 | 玩家要真的让人吃饱 |

## 她怎么回应玩家

| 局面 | 她可能怎么做 |
|---|---|
| 玩家来食堂吃饭 | 先给一勺，再问「你今天来听什么」 |
| 玩家要她压配给省粮 | 拒绝；给一个「先减行政口粮、再减孩子」的方案 |
| 玩家在袭击后只问死了几个 | 她会报名字，一个一个报，直到玩家坐不住 |
| 玩家给收容所加粮 | 她会笑；当天食堂的队会短一点 |
| 玩家要她动员街头支持法案 | 先问「这个法案对吃饭有什么用」；说不出来就不去 |
| 玩家问她账上的「损耗」 | 她会盯着玩家看，然后说：「你要查，就查。别查一半。」 |

## 转折

阿禾的转折是**从「偷偷多打一勺」走到「让配给制度本身不再靠偷」**。她原本用违规的方式救人，后来可能愿意推动一项《配给透明法》，让孩子的饭不再记在「损耗」里。

玩家能打开这一步的，是让她看到：**她不需要再偷偷摸摸地做好事**。

## 台词

「每个人都要吃饭，包括反对你的人。」

「名字？你连他们叫什么都不知道，就敢说‘伤亡可控’？」

「账上写的是损耗。损耗个屁。那是小满，六岁，爱吃甜的。」

「你要我帮你拉票？可以。先让食堂的队短一点。」
