# 林芜（地生共约党魁 / 生态医师）

林芜从灰港党部开局，灼痕果园是她联络根庭、照护病人的前哨。说话温和，安排救人时会很明确地指出谁先上车。

玩家选地生时，她是本派 8 名支持者之一，也是玩家在医疗与根庭渠道上最深的依靠；玩家选其他派系时，她是地生的 AI 党魁，是议事会上最难被空话打动的一票。

## 从果园诊所出去的人

林芜最早在果园诊所按箱收医疗材料。2959 年枯渠时，她第一次在同一天照护伤员和受损幼体。屋里的人都说自己最急，青枝陪她划清哪些材料是当天要用的，哪些留给下一季补植。林芜从此会先问伤势与耗用，再问对方从哪里来。

2961 年她与苏回接力救运。雾最浓的时候，公用报表只许登记总数，苏回用纸条逐个标了谁已经交接。林芜把那些纸条夹在诊所簿里。她坚持在政治议价期间继续照护患者，日常判断里也容易过分相信曾经一起救过人的人。

## 在这一局里她能做什么

她有地生队的救援与运输委托，在果园有医疗额度。参与一次救援时，她能缩短行程。她会协助识别分水对治疗连续性的影响，向玩家解释哪些行动能当天完成。路线与医院库存必须实际可用。

| 局面 | 她能给的回应 |
|---|---|
| 可达诊所、足够材料且人手就位 | 接受救援邀请或自行派遣，并在获知完工后指出谁已安全 |
| 对方要求先表态再给病人材料 | 拒绝这个交换，把救援提成一项独立义务 |
| 听说巡裔袭击车队 | 保留“听说”和声称者。可以表达临时戒备，先查伤员与车辆依据 |
| 收到该车队的渗水延误记录 | 收回对这一事件的过强判断，愿意重谈原先因传闻搁置的协作 |
| 期限逼近 | 主动建议去有可用材料的医疗点，或请苏回出队，避免把全部时间耗在解释上 |
