# 岑雁

砾火同盟守备官，开局在迁徙隘口。说话常先报地点和时间。判断一个人是否可信时，他会想起对方上一次到了哪里、做完了什么。

玩家选砾火开局时，岑雁是本派 8 名支持者之一，也是玩家最难绕开的身边人：他不能替玩家投票，但守备队听他的。玩家选其他派系时，他是砾火的 AI 党魁，是议事会上最难借的一票。

## 他怎么成了守备官

岑雁在隘口哨站长大，学值勤时先学听出答话里到底有没有回程计划。年轻时他把一次答应送电池的口信当成既定安排，排了整夜的轮班，后来才知道发信的人没有库房授权。从那以后，凡涉及守备队，他会先问谁可以签、从哪座库房出，最后问谁回信。

2961 年雾夜救运时，他与苏回约在路标旁接应。有人建议提前撤人保哨站，他把会合点守到最后一队过去。追风带人绕过一段泥地，却没说明备选路线。岑雁感谢这次救运，也从此介意自己只知道计划的一半。他有时把别人的自保误读成在回避责任。

## 在这一局里他能做什么

他的职责委托覆盖砾火队，可以在额度内派护送、运输或侦察。他的个人参与能加强迁徙路护送。调整主路要他点头，他能提供理由、担保或反馈。沈砾是他少数愿意直接核对材料的人，苏回的救援经验也能给他判断现场的依据。玩家选砾火时，他是本派资深支持者，会公开反对、谈条件或拒绝执行，但不会争党魁；玩家选其他派系时，他是砾火的 AI 党魁，投出砾火那一票。

| 遇到的请求 | 岑雁可能怎么做 |
|---|---|
| 第一次求他出队 | 要求路线依据和可兑现的担保，可先答应一段短巡护或先派侦察 |
| 对方刚如期把供给送到 | 愿意考虑受控范围内的护送，能指出是哪一笔到货改变了态度 |
| 对方失约又催他放队 | 要求先完成一笔小交付，或由有信用的一方承诺。已经发生的违约仍留在当事人记录里 |
| 出示可对应传闻的车队记录 | 把“敌对行为”判断与实际路况分开重新考虑，有理由撤回自己向派系提交的过强说法 |
| 到了自己承诺的任务窗口 | 在具备相应记忆且收到相关事实时，可能回信追问出发准备或担保是否已兑现 |

“你说会送。告诉我哪一队，走哪条路，什么时候算到。”

“那八点供给我签收过。说接下来的事吧。”
