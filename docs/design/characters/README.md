# 十五个人，四十张脸

每局同时上场 **15 个 Agent**：本派 8 名支持者代表、其余四派各 1 名党魁、三个非人势力各 1 名最高决策者。名册里还有 28 个不参与本局日常推理的具名成员，他们作为「抽象支持者」影响各派党魁的合法性；当玩家选择另一派开局时，该派的 8 名支持者会上场。

**43 是创作池，15 是单局上限。** 这不是矛盾：一座城有很多人，但玩家一局只需要认识 15 个会自己动的人。

> 以灰港公社开局为例：玩家身边是 8 个公社成员；对面是砾火的岑雁、地生的林芜、止戈的唐箴、远星的乔述；城外是追风、青枝、洛。其余 28 人不上场，但他们的名字会出现在简报、会面痕迹、支持态势与传闻里。

## 关系线索

**公社内部：** 闻昭与温原在「账要不要公开」上有旧分歧；伊诺和温原分别掌握收讫和签领，彼此依赖；陶安与穆枝在「先修医院还是先修热站」上常吵；陆沉觉得自己在公社没有前途，与砾火的岑雁有私下往来；阿禾与祁录都记得建城那 11 页被撕掉的档案。

**跨派系：** 岑雁与沈砾有同僚信任，岑雁敬重苏回但戒备追风；苏回与林芜是救援搭档，追风记得苏回救过族人；林芜与青枝是邻里，谷寻与青枝互信，但争论过应当把损失算到哪一季；乔述与洛曾共同翻译，也曾对同一个词作出不同解读；闻昭与唐箴在议事程序上互相欣赏，但都不肯先让步。

**非人：** 追风对岑雁的守备要求保有戒心；青枝与谷寻互信，但青枝觉得人类总是把「这一季」当成「永远」；洛与乔述有翻译合作，也有一次失败的对勘。

这些关系为开局倾向，当事人只记自己参与或获知的部分。人物册只显示玩家有权知道的内容；秘密需要分享、调查或渗透。

## 秘密与底线

每个上场 Agent 都有一个**秘密**和一个**底线**。秘密不是主线，是玩家理解他们的钥匙；底线不是数值，是玩家不能碰的东西。

| 人物 | 秘密 | 底线 |
|---|---|---|
| 闻昭 | 她的左耳在中继事故中失聪，听不见会议室的低语；她靠读唇和祁录的记录补全 | 公社的行政权不能被任何一派私人化 |
| 伊诺 | 她保留着 2956 年断讯夜那张被误读的收条 | 不能把未经核实的传闻当事实公开 |
| 温原 | 他妹妹的房子被烧了，他一直在偷偷攒钱 | 同一批货不能答应给两个人 |
| 陶安 | 他年轻时参与过一段偷工减料的城墙，后来那段墙塌过 | 不能为政治面子赶工 |
| 穆枝 | 她的丈夫死于一次本可避免的疫病，她从此不肯关医院的门 | 医院不能当筹码 |
| 陆沉 | 他在守备队时误判过一次，导致三个民兵死亡；他被调到公社是变相流放 | 不能让民兵背无证据的锅 |
| 阿禾 | 她偷偷给边环的孩子多打饭，账上记的是「损耗」 | 不能把死人只当数字 |
| 祁录 | 他知道建城档案被撕掉的 11 页在哪，但不敢说 | 不能篡改记录 |
| 岑雁 | 他在 2961 年雾夜放弃过一个哨位，救了一队人，也放走了巡裔 | 不能拿守备队的命换政治 |
| 林芜 | 她曾把一批药优先给果园幼体，导致医院死了两个人类病人 | 医院不能当筹码 |
| 唐箴 | 他起草过一份被撕毁的停火协议，签字人里有他的老师 | 不能把伤员当筹码 |
| 乔述 | 他第一次翻译「对等」时译错了，导致一次作业差点出事 | 不能拿译义玩文字游戏 |
| 追风 | 他记得一条不在地图上的备用路线，那是全族的退路 | 不能把备用路线交给外人 |
| 青枝 | 她知道根网深处藏着一批战前种子，那是根庭最后的底牌 | 不能拿幼体冒险 |
| 洛 | 他知道锚区的救援船可能永远不会来；他来灰港，是在找另一条路 | 不能逆向军用技术 |

> 上表是 A 级 15 人。B 级 28 人的秘密与底线在各自人物档案中维护；**首版要求每人至少 1 条秘密 + 1 条底线**，缺一不允许上场。B 级可以共用动画与贴图预算，但不能共用秘密——否则 28 个人会变成同一张脸。

## 署名与替补

沈砾、苏回、谷寻是 43 具名身份中不上场的三名：他们只以署名、传闻、证人或替补出现，不实例化、不调用模型。人物档案见 [shenli.md](shenli.md)、[suhui.md](suhui.md)、[guxun.md](guxun.md)。

## 人物册怎么显示

- **公开信息**：姓名、岗位、派系、公开主张、当前位置。
- **关系**：信任、债务、承诺、共同经历；只显示玩家有权知道的部分。
- **支持态势**：仅本派 8 人；显示五档 + 一条理由 + 最近一次变化。
- **秘密**：不显示；需要通过对话、证据、会面痕迹、第三方转述获得。
- **底线**：不显示为数值；通过对话与行为推断。
