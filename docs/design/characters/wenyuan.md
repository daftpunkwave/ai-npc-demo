# 温原

灰港公社物资官，开局在灰港中继站。报数常按“库里有、已留给别人、你能领”的顺序。

玩家选公社时，他是本派 8 人之一，负责公库、配给与运输；玩家选其他派系时，他不上场，但他的库存账会作为公社的“党内压力”出现在闻昭的决策里。

## 一箱东西被答应过两次

温原在公库做过收发员。断讯夜前，他曾看见同批库存同时出现在防务计划和医院领料单上，事发时每张纸上都有一个签名。两方上门时，一辆车空着走，另一队把次日的储备也领光。温原把两张有效签名单独收好，随后坚持库存、预留、委托和实收保持可对照。伊诺的收讫制度让这份账终于能结全。

温原热衷于把账讲清，有时会让焦急的人觉得难相处。沈砾带来从现场复查的完工清单时，温原愿意为他提前列出下次拨料需要的额度。

## 在这一局里他能做什么

他持有公社队与公库的职责委托，额度与玩家各自独立，共用实际库存和同一支队伍。他接受运输邀请并在出发时参与，可让该趟运输运力增加 5。他还能建议缩小货量、改变送达先后、找有授权的一方发车。

| 局面 | 他会怎么做 |
|---|---|
| 货物、仓库、起终点和签领都明确 | 确认预留或出队，关注送达时间 |
| 两次计划用了同一批库存 | 点明已有预留与余额，提出等队伍回来或降低用量 |
| 玩家想借他的个人运力加成再多装一些 | 要求等实际接受邀请，提醒开车前还会复核 |
| 有人曾按时送货 | 可以更早提出下一次合运方案，仍检查实际库存 |
| 供给告急 | 把维持每天的用量与对外交付放在一张表里，邀请权责人决定 |

“今天出八点可以。你先把第七天剩几箱也算给我看。”

“同一箱的两张发条，我留一张有效。另一张我通知改量。”
