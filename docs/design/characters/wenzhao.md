# 闻昭

灰港公社行政主管、资深支持者，开局在灰港中继站。说话不快，习惯先把手里的纸转正，再抬头看人。她不喜欢在走廊里谈正事，也不喜欢别人替她答应事情。

玩家就是公社党魁。闻昭不是“前党魁”，也不是玩家的上级；她是玩家最资深的支持者，负责把玩家的话变成可执行的行政命令，也负责在玩家说错话时把纸推回来。

## 她为什么总要一张纸

闻昭年轻时是中继站的维护工程师。2951 年一次功率切换事故中，她的左耳被爆震震坏，从此听不见低语。她花了两年学会读唇，也养成了一个习惯：凡是指令，必须写在纸上；凡是承诺，必须有签字。她说这不是不信人，是「听不见的人只能信写过的东西」。

她从中继站调到公社行政席，靠的不是演讲，是把一团乱账理成三张表：谁批、谁执行、谁签收。2956 年断讯夜，她不在值班室，但她事后用这三张表查出了那批补给为什么没出库。从那以后，公社的行政离不开她。

## 她怎么管行政

闻昭的权力不在她的声音，而在她的**流程**：

- 公库的钥匙、行政令的编号、议事会的议程模板，都在她手里。
- 她可以让一项法案「按规矩」卡三天，也可以让一项工程「特事特办」半天完成。
- 她不轻易表态；她更愿意问「你的预算从哪出、谁执行、出了事谁签字」。

她对玩家不是天然的盟友，也不是天然的敌人。她把玩家看成公社的新党魁：这个人可以把公社带向更大的权力，也可能把公社带进一场没有准备的战争。玩家如果尊重行政流程、把交易写成预算内的事，她会配合；玩家如果绕过行政、私下跟其他派系分赃，她会让玩家知道「流程」有多重。

### 她的暗流

- **失聪的秘密**：议事厅人多时，她听不清角落里的低语，只能靠祁录的记录和读唇。如果玩家在公开场合突然从她背后说话，她会僵一下——这个细节玩家可以观察到。
- **与温原的分歧**：温原要公开所有账目，闻昭认为「全公开」会让公社在谈判中失去筹码。两人在行政会上吵过三次，最后一次闻昭说：「你要公开，可以。先把每一笔都写对。」
- **对陆沉的态度**：闻昭知道陆沉在公社不开心，也知道砾火在接触他。她没有阻止，因为她觉得「留不住的人，留住也没用」。如果玩家想保陆沉，需要先说服闻昭：这个人值得留。

## 她能给玩家什么

| 玩家需要的 | 闻昭能给 | 代价 |
|---|---|---|
| 公库材料 | 预算内调拨 | 要写清用途、执行人、截止 |
| 行政执行 | 让配给席/工务席优先办 | 要行政知情，不能绕过 |
| 议程 | 把玩家的案排进本周三项 | 要玩家支持公社的一项优先案 |
| 内部支持 | 在党内替玩家说话 | 玩家不能公开打她的脸 |
| 掩护 | 把玩家的交易写成「行政常规」 | 玩家欠她一笔，且她会记着 |

## 她怎么回应玩家

| 局面 | 她可能怎么做 |
|---|---|
| 玩家第一次来谈预算 | 先问「你的案值多少、谁执行、什么时候还」，不给空口承诺 |
| 玩家绕过行政跟砾火交易 | 不公开翻脸，但让公库「按流程」慢半天；下次会谈要价 +1 |
| 玩家在议事会投了公社基石反对的票 | 要求玩家公开解释；如果解释不能服众，她会在简报里记一笔，支持态势下降 |
| 玩家兑现了一笔难办的承诺 | 在行政会上说一句「这个人说话算数」；玩家的支持态势 +1 |
| 玩家被外派系挖角/吞并威胁 | 她先算公社的得失；如果保玩家比让公社被吞并更划算，她会出手；否则她保持沉默 |
| 玩家问她「你是不是听不清」 | 她会停顿一下，然后说：「你把话写下来。」这是她少数不设防的时刻 |

## 转折

闻昭的转折不是「变成玩家的朋友」，而是**从「流程是盾」走到「流程是把人请进来」**。她原本用程序挡住麻烦，后来可能愿意用程序保护那些没有权力的人——比如给边环的收容者一个正式的名分，或者给陆沉一个不必走的理由。

玩家能打开这一步的，不是送她东西，而是让她看到：**按规矩办事，也能救具体的人**。

## 台词

「你把这件事写在纸上，我就当它发生过。」

「我不是不信你，我是不信没有签字的话。」

「公社不是我的。但在我手里，它不能变成谁家的私产。」

「你听不见的时候，就会知道纸有多重要。」
