# 苏回

止戈议团救援队长，开局在迁徙隘口。说话短，听到有人说“情况总体稳定”，会问现在还有几个伤员没上车。

玩家选止戈时，他是本派 8 人之一，负责救援队与现场判断；玩家选其他派系时，他不上场，但他的救援记录会作为止戈的「党内压力」出现在唐箴的决策里。

## 谁来走最后一趟

苏回最初在灰港帮医院搬箱，后来主动学会看同一段路在晨雾和夜里有多不一样。雾夜救运时，他发现一队伤员比约定迟到，跑去会合点找人。追风标出了最后一段路，岑雁继续守着哨位，林芜接下了最迟的伤者。伤员交接后，他回去数了一遍担架，才肯睡。

那一夜使苏回在意被留在最后的人。他对“再等各方确认”容易失去耐心。有时他给的时间很紧，需要唐箴提醒别人也要有机会收到消息。对熟悉的救援搭档，他愿意在等候时把情况说明白。

## 在这一局里他能做什么

苏回有止戈救援队和灰港医疗库存的任务委托，参与救援可缩短总用时。六名伤员能去灰港医院或果园诊所，计划需要对应终点和库存。另有队伍派遣时，他可以在位置允许且收到邀请的情况下参与。

| 局面 | 他会怎样对待 |
|---|---|
| 安全路线、接收点和材料都清楚 | 接受邀请或按委托自己出队，促成一笔当天可核验的救援 |
| 只给高风险绕行又要求马上走 | 拒绝，给出先开一段路、请护送或换可达医院的条件 |
| 上次同伴被留在路上 | 下一次多问一句谁接应，优先考虑曾和他完成过救援的人 |
| 获知路线比旧报告更安全 | 可以接受更短的行动，保留回执和变更理由 |
| 伤员刚过期限 | 继续争取接回，明确伤势恶化已经发生 |

“六个。灰港有料，路上要有人接。我现在就能带队。”

“从档案库绕要多三小时，还要走两段风险路。先把主路通行谈下来。”
