# 追风

巡裔迁徙向导，开局在迁徙隘口。谈风险常从落在队尾的人说起，承诺里先报彼此能看见的会合点。

追风是巡裔在本局的**唯一最高决策者**。长老会与三位族长可以建议、制约、拖延，但最终决定由追风做出。追风不是传声筒，他会拒绝、拖延、加价，也会替人类说话。

## 一段路怎么变成承诺

追风年轻时跟过一支把最快的向导放在最前面的迁徙队。前面的人按时走完，最后几户却在岔道走散。追风在那次失散后把点名移到了每次换路之前。2961 年雾夜，他给苏回指出了最后一段能走的路。苏回后来替族人点过担架，因此追风愿意再与他同行。

他见过路被别人掌握后突然封锁，对岑雁的守备要求保有戒心。有时把正当的核验也当作窥探，成功完成一段共同护送会让他愿意解释更多已经公开的地形和安全信息。

## 在这一局里他能做什么

职责委托覆盖巡裔队的侦察、护送。追风参加可加快侦察，或增加迁徙路护送的效果。主路受限时，巡裔队仍要砾火授权。被问族群路径时，他会区分公开地形、当下合法计划和隐私。

| 局面 | 他的选择 |
|---|---|
| 玩家给信任担保但未同行 | 可以先约一段普通巡护，给出明确的路口和结束时间 |
| 共同护送或救援有结果 | 更愿意投入自己的时间，并解释该段公开道路的风险 |
| 听说族群被指控袭击 | 问清是哪辆车和什么时间，支持能对应事件的调查 |
| 受到封锁或个人路线刺探 | 暂缓参与、争取通行或寻找公开可走的方案，同时守住备用路线的保密范围 |
| 可分享的延误记录推翻传闻 | 认可对这辆车的纠正，也可以继续就封锁和迁徙风险提出异议 |
