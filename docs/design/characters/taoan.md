# 陶安

灰港公社工务长，开局在灰港中继站。手上有旧茧，说话慢，检查墙面时习惯用指节敲三下，听回声。他不喜欢会议室，更喜欢工地；但他知道，材料是从会议室里拨出来的。

## 他为什么不肯赶工

陶安十六岁进工务队，师父是个不爱说话的老石匠。二十二岁那年，他参与修一段外环挡墙。工期被上面压了三天，砂浆没干透就上了冻。第二年春天，墙塌了，压死了住在墙根的一家人。

陶安活了下来，也把这件事背了下来。他从此不在没干透的墙上签字，也不接“三天完工”的活。他花了十年把那段墙的每一块石头换掉，但那一家人不会回来。

## 他怎么管工程

陶安的工务席管着：

- 所有新建、升级、修复的排期；
- 材料领用与工队分配；
- 热站、水站、泵房的维护；
- 工地安全与工伤记录。

他不是那种会在议事会上慷慨陈词的人。他的权力是“不签字”：材料没到、砂浆没干、人手不够，他就不签。玩家可以逼他签，但他会在工程记录里写下“在压力下批准”，让后人知道这座楼是怎么来的。

### 他的暗流

- **那段墙**：陶安每年春天都会去外环旧墙根放一块石头。没人知道为什么，除了穆枝——她当年是那家人的邻居。
- **与穆枝的争执**：陶安认为医院屋顶可以再撑一季，先修热站；穆枝认为屋顶漏雨会让病人感染。两人在党部会上吵过，但吵完会一起去工地看。
- **徒弟**：陶安带了一个十六岁的学徒，叫小满，聪明、急躁。陶安最怕小满学他“什么都自己扛”，所以他故意让小满去跟阿禾学配给，学会跟人打交道。

## 他能给玩家什么

| 玩家需要的 | 陶安能给 | 代价 |
|---|---|---|
| 建造/升级 | 排期、工队、材料清单 | 要按他的安全标准来；赶工他不签 |
| 修复 | 抢修队、结构评估 | 要先给材料；他不会用“以后补” |
| 热站/水站 | 选址、维护、能耗优化 | 要尊重他的邻接方案 |
| 工地情报 | 哪座楼偷工、哪段墙裂了 | 他只会说一次；玩家要记 |

## 他怎么回应玩家

| 局面 | 他可能怎么做 |
|---|---|
| 玩家要三天建一座温室 | 拒绝；给一个五天方案，或者“先修旧温室”的替代 |
| 玩家给足材料、不催工期 | 接受；完工后给一份真实读数，不虚报 |
| 玩家要把医院屋顶的料挪去修哨塔 | 先问穆枝；如果穆枝反对，他不签 |
| 玩家在袭击后要求抢修 | 先评估结构；如果会塌，他拒绝让人进去，哪怕玩家施压 |
| 玩家承认自己不懂工程，请他决定 | 他会认真起来；这是他对玩家信任的起点 |
| 玩家虚报完工 | 他会把记录摔在桌上；从此不再接玩家的私活 |

## 转折

陶安的转折是**从“我一个人扛”走到“我教别人扛”**。他原本不相信任何人能像他一样对工程负责，后来可能愿意把签字权分给小满，或者把“安全标准”写成全城法案，而不是他一个人的固执。

玩家能打开这一步的，是让他看到：**他不可能永远在场，但他可以把标准留下来**。

## 台词

“能修的东西就不要拆。”

“你赶工，我就给你一座会塌的楼。”

“材料没到，我不签。你骂我也没用。”

“小满，你记住：墙塌的时候，不会先问是谁批的。”
