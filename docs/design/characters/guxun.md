# 谷寻

地生共约生态联络、水务，开局在旧堤水闸。带着两本簿子，一本记谁怎么说，一本记实际看到什么。

玩家选地生时，他是本派 8 人之一，负责水账、勘查与根庭渠道；玩家选其他派系时，他不上场，但他的水账与实测会作为地生的「党内压力」出现在林芜的决策里。

## 他留下了哪两个数字

2959 年果园枯渠时，作为地生实习联络员，谷寻替会议把“闸门开了多久”抄作“果园收了多少水”。青枝把他领到幼圃，指出两者之间隔着一道多年未修的导槽。谷寻翻旧账时没有撕掉那一页，而是在旁边写上当时所据的记录。他愿公开承认误判，有时也会因此倾向要求太多证据才给出行动建议。

后来青枝允许他在园护旁边观察供水，才有了二人的互信。他解释数字时以日计，青枝常问来季会怎样。分歧持续存在，两人都能理解对方为何急。

## 在这一局里他能做什么

他初始持有历年分水账，能联系公社和根庭。侦察专长可加快他实际参加的任务。地生队本身只有运输和救援能力，因此初始可行的现场勘查是请砾火或巡裔出适格侦察队，在满足位置与邀请条件时带上他。

| 触发 | 可能决定 |
|---|---|
| 玩家拿历年分水账讨论差额 | 指明过去的配水偏向，要求把当前渗漏当作另一项待查事实 |
| 有到水闸的合法侦察和一份明确邀请 | 在有空、能到场的情况下参加，完成后讨论新记录的范围 |
| 被请去背书未经勘查的说法 | 保留判断，提议把猜测单列，并提供核验所需的地点和证据 |
| 新证据推翻旧估算 | 当面更正，告诉玩家哪项结论随之改变 |
| 公社谈轮换期限 | 用日结读数与过去差额帮双方核算，把幼圃的持续需求留给青枝补充 |

“先记你说的，再记量出来的。两栏都要留。”

“前两季的账我能给你看。今天这处漏了多少，我得再查。”
