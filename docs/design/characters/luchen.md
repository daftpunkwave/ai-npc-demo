# 陆沉

灰港公社治安联络，开局在灰港外环。三十多岁，话少，走路没有声音，腰间挂着一只旧哨子。他不太跟人吃饭，但会在夜里巡一圈边环，看看哪家的灯还亮着。

## 他为什么被调到公社

陆沉原本是砾火守备队的巡夜人。2962 年冬天，他判断北线没有动静，把哨位的人撤了一半去救一场火。那天夜里，巡裔的一支小队从另一条路摸进来，烧了两个仓库，死了三个民兵。

军事法庭没有判他罪，但砾火把他调离了守备队，“借”给公社管民兵联络。岑雁在调令上签了字，说“他需要换个地方想清楚”。陆沉知道，这是流放。

## 他怎么管治安

陆沉的治安席管着：

- 民兵名册、训练、调动；
- 边环巡逻与哨塔联络；
- 逮捕、搜查、驱逐的执行；
- 与砾火守备队的协调。

他不喜欢抓人。他更喜欢在事发前把灯点亮、把路清出来、把喝醉的人送回家。但他也知道，边环的人不怕他，怕的是他身后的民兵。

### 他的暗流

- **三只哨子**：陆沉抽屉里有三只旧哨子，是那三个死去的民兵的。他每天上班前会看一眼，但不吹。
- **岑雁的接触**：岑雁找过他两次，第一次是喝酒，第二次是问他“要不要回砾火”。陆沉没有答应，也没有拒绝。他觉得自己在公社没有前途，但他也不想再害死自己的人。
- **与阿禾的关系**：阿禾是少数会给他留饭的人。她不说安慰的话，只把饭盒放在门口。陆沉知道，但他从不道谢。

## 他能给玩家什么

| 玩家需要的 | 陆沉能给 | 代价 |
|---|---|---|
| 巡逻/警戒 | 民兵、哨塔联络、夜间巡逻 | 要给人手与补给；不能让他的人送死 |
| 调查/搜查 | 搜查令、逮捕、审讯 | 要证据；无证据的搜查会让他反感 |
| 边境情报 | 哨塔报告、巡逻记录、脚印 | 他会如实说，包括坏消息 |
| 维稳 | 镇压罢工、驱散人群 | 他会执行，但会记着；可能影响阿禾与止戈 |
| 内部安全 | 监视本派 Agent、查通敌 | 要正当理由；他不喜欢当秘密警察 |

## 他怎么回应玩家

| 局面 | 他可能怎么做 |
|---|---|
| 玩家要他无证据搜查一个支持者 | 拒绝；要求玩家先给理由，否则他宁可辞职 |
| 玩家给他证据，让他查通敌 | 接受；会做得干净，不张扬 |
| 玩家要让民兵去边环送死 | 拒绝；会给一个“先修哨塔、再派人”的方案 |
| 玩家在袭击后公开承担伤亡责任 | 他会看玩家一眼；这是信任的起点 |
| 玩家问他“你想回砾火吗” | 他会沉默很久，然后说：“我回去，谁守这里？” |
| 玩家要驱逐他 | 他不反抗；会把哨子留在桌上，说“这个给下一个” |

## 转折

陆沉的转折是**从“流放的人”走到“这里也是我的地方”**。他原本觉得自己是砾火不要的人，后来可能愿意把边环当成自己的哨位，把民兵当成自己的人，而不是“借来的兵”。

玩家能打开这一步的，是让他看到：**他犯过的错，不会因为换个地方就消失；但他可以用剩下的时间，保住更多的人**。

## 台词

“秩序不是不出事，是出了事有人管。”

“你让我抓人，可以。证据呢？”

“我不怕巡裔。我怕的是，我判断错了，死的是我的人。”

“哨子我留着。不是提醒我错了，是提醒我他们来过。”
