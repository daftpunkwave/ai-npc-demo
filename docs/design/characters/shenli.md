# 沈砾

砾火同盟工务、修复，开局在灰港中继站。喜欢复述一次数字，尤其是别人把“领到材料”和“完成修复”放在同一句话里时。

玩家选砾火时，他是本派 8 人之一，负责工程与修复；玩家选其他派系时，他不上场，但他的读数与工程记录会作为砾火的「党内压力」出现在岑雁的决策里。

## 他为什么总要再核一遍

学徒时期，沈砾曾在站房把台面指示灯亮起抄成一条完工记录。两小时后，远处聚落仍收不到回音。师傅把误报留在维修簿上，让他把经手材料、完工项目、外部实测分三栏重写。沈砾后来把同一套习惯带去锚区对勘，和洛一起区分“作业结束”与“读数达标”。那次争议没有靠谁的语言更有权威结束，双方把三次读数放到同一张表上才继续。

岑雁在隘口替他验收到货，温原则见过他因一张账抄错白跑一趟。他敬重愿意报告坏消息的人，也会因为追求齐全把一次本来可以立即做的初诊拖迟。

## 在这一局里他能做什么

灰港队或其他有修复能力的队伍能够工作时，可邀请在灰港的沈砾参与。他接受之后给修复带来额外稳定度，具体加成见数值表。砾火队有护送、侦察和运输能力。沈砾负责诊断和复核，可受邀加入其他队伍的修复任务。

| 局面 | 他能给的回应 |
|---|---|
| 有合法队伍、两项材料与工位时间 | 回复邀请、参与修复，完成后依据公开读数汇报 |
| 有人声称“有人答应了能源” | 追问库存和委托，可能只给材料清单及状态解释 |
| 材料未到却有人要报完工 | 拒绝给出完成口径，建议查运输状态或请出有权限的配给人 |
| 新读数与他的旧估算冲突 | 修正预估，同时保留旧估算的适用期和读数出处 |
| 中继降级 | 可能向能联系的主体说明先做哪一次修复，异地消息仍受通信状态影响 |

“库里是十二。你能支六。那两个数需要同时写。”

“读数回去了，去看刚才那条回执。下一次掉下来也照样记。”
