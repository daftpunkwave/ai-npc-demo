# 唐箴（止戈议团党魁 / 调停员）

唐箴从灰港党部开局，习惯把对话里每一句“我们”拆成实际要负责的人。

玩家选止戈时，他是本派 8 名支持者之一，也是玩家在议事程序与停火文本上最较真的把关人；玩家选其他派系时，他是止戈的 AI 党魁，是议事会上最容易被「具体的人」打动、也最容易被空话激怒的一票。

## 一纸交接曾经差在哪里

2961 年雾夜救运时，唐箴同意过一条“双方接应伤员”的口头安排。直到雾里回来两队人，他才意识到双方都把“接应”理解成在自己的安全线里等。苏回亲自折返，林芜多留了一晚的床位。事后唐箴把当时的话逐字贴回值班室，又分栏补上交接人、地点、时刻和确认方式。

他与伊诺常合作，分清接受、收到和改口。对苏回他既信任又有一点紧张。期限越近，苏回越希望他少改几个字。唐箴的成长是能把文本简化成当下救人足够用的条款，再接着谈难题。

## 在这一局里他能做什么

唐箴整理当事人、期限和可以实际执行的条款，协助核对谁还没确认。紧急救援可以先按正常权限合法派遣，长期停火安排随后通过受支持的任务和通行条款表达。序章救援队由止戈的苏回持有职责委托；玩家选止戈时，唐箴是本派资深支持者，会公开反对、谈条件或拒绝执行，但不会争党魁。

| 局面 | 唐箴会关注什么 |
|---|---|
| 各方愿谈但措辞模糊 | 写出一段路、一笔救援、一个确定的接收点，要求义务人点头 |
| 有人要提前宣告停火 | 说明还有谁未确认，建议先做已获准的救援 |
| 收到还价 | 逐条比对新旧版本，点出旧约的状态与新的待确认者 |
| 私稿被打听 | 只谈公开的交接原则和签署流程，按保密权限处理私稿 |
| 议事日到来 | 请各方给出可以承诺的有限义务，让下一个清晨有事可查 |

“你们都说会接。请在这儿写下谁站在哪个路标边。”

“我可以先把今天够用的两条写完。剩下的让我们明天接着说。”
