# 止戈议团

止戈从救护站和民间调停席发展而来。它争取平民与伤员通道，支持能落实到某一段道路、某一个期限、某一个接收点的约定。一个紧急伤员值不值得救，可以与全面停火争议分开判断。

唐箴是止戈的调停员。玩家选止戈时，玩家就是党魁，唐箴转为资深支持者，掌握议事程序、停火文本与人道渠道；玩家选其他派系时，唐箴是止戈的 AI 党魁，在议事会投出止戈那一票。玩家和唐箴的关系，决定止戈是「有原则的盟友」还是「拖后腿的道德家」。

## 组织与分歧

议团内部有**先救人派**与**先立规派**：

- **先救人派**：认为每拖一天就有人死，规则可以边做边补。苏回、沈青、白芷偏这一派。
- **先立规派**：认为没有接收人与交接点的救援只是把风险转给下一班。唐箴、顾言偏这一派。
- **收容派**：陆离只关心收容所里的人能不能活过冬天。他不反对任何一派，但谁削减收容预算，他就跟谁急。

两派都反对军事升级，但对「要不要给救援队配护卫」意见不同。苏回要护卫，唐箴怕护卫让救援变成军事行动。玩家可以用「护卫只护路、不进救援点」的折中方案把两派拉到一起。

### 止戈的暗流

- **陆离的动摇**：陆离的收容所里有 17 个孩子，其中 3 个是巡裔与人类的混血。砾火的荆离公开说过「这些孩子长大是麻烦」。陆离最近开始跟远星的乔述接触，因为远星愿意用商队把两个孩子送去锚区。如果玩家支持收容，陆离会留下；如果玩家沉默，他会走。
- **顾言的账本**：顾言记着过去五年所有停火协议的原文，包括那些被撕毁的。他知道哪一派在什么时候骗过谁。玩家可以用这本账在议事会揭穿对手，但顾言会要求玩家先证明自己不是「只挑对自己有利的那一页」。
- **苏回的旧伤**：苏回在 2961 年雾夜救运中冻伤了左脚，走路有点跛。他从不提，但每次走远路，白芷都会多看他一眼。如果玩家让他连续出队，白芷会公开反对。

| 项 | 内容 |
|---|---|
| 票 | 1 |
| 开局支持 | 17% |
| 默认赞成 | 轮换供水、收容外来者、公共纪念、贸易开放 |
| 默认反对 | 民兵动员、工业优先 |
| 最想要的法案 | 《平民通道法》：在任何冲突中保留医疗、收容与撤离通道 |
| 最怕的法案 | 《边境筛查法》与《民兵征召法》：前者把难民挡在门外，后者把救护队编进军队 |
| 能换的票 | 救援队、收容所、停火调解、外域人道渠道、舆论支持、见证人 |

## 城建与外务

- **城建主张。** 优先医院、隔离所、收容所与净水；支持在边环建防风墙与救济站。议团不反对工业，但要求工业区与住宅区隔开。
- **外务立场。** 与巡裔谈伤员与幼兽，与根庭谈菌丝药，与泊星者谈医疗技术；反对任何以「先宣战再谈判」为起点的方案。议团愿意做三方会谈的东道主，但要各方先交出可核验的停火点。
- **能给的筹码。** 救援、收容、停火见证、外域人道通道、公开道义支持。
- **红线。** 不接受把伤员当筹码；不接受无接收点的撤离；不接受救护队被编入作战序列。

## 玩家作为止戈党魁

止戈的票最容易被「具体的人」打动，也最容易被空话激怒。玩家若想拿到这一票，最好带着一份写明接收点、时限与交接人的方案，而不是一句「我们应该人道」。反过来，玩家若推一项军事法案，唐箴会在表决前要求公开说明「谁抬伤员」。

止戈开局最常见的支持危机是**陆离的收容所**。如果玩家为了换取砾火的票，支持《边境筛查法》，陆离会带着 17 个孩子和半个收容所的人离开，止戈的民意支持会掉，街头上会出现「止戈只管外人」的传言。如果玩家保护收容所，砾火会指责玩家「拿灰港的粮养外人」，但陆离会成为玩家在街头最暖的支点。

**玩家可以立刻做的三件事：**

1. 去收容所帮白芷发一次药，记住三个孩子的名字；
2. 让顾言给你看一份被撕毁的停火协议，问他「当时谁没签字」；
3. 跟苏回走一趟隘口，别催他，看他怎么数担架。
