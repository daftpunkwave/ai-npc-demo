# 砾火同盟

砾火同盟从守备队与巡逻队长出来。它的党部、家属与矿务馆都在灰港外环，隘口是它守的前哨，不是它的城。同盟相信路要通、墙要厚、灰港不求人；但矿场的材料、修墙的能源、守夜的粮食，又样样要求人。

岑雁是砾火的守备官。玩家选砾火时，玩家就是党魁，岑雁转为资深支持者，掌握守备队、隘口与矿场的实际调度；玩家选其他派系时，岑雁是砾火的 AI 党魁，在议事会投出砾火那一票。玩家和岑雁的关系，决定砾火是「能打的盟友」还是「不动的石头」。

## 组织与分歧

同盟内部有**守土派**与**通车派**：

- **守土派**：认为巡裔与泊星者都不可信，牧道必须设永久哨所。白露、荆离偏这一派；岑雁属于这一派，但讲担保。
- **通车派**：认为没有巡裔的向导，矿车冬天出不了北线；没有泊星者的修复，中继撑不过白障。罗盘、沈砾偏这一派。
- **矿场派**：霍岩只关心矿工的口粮、安全和矿井的支护。他不在乎谁当议长，但谁动矿场的预算，他就跟谁急。

岑雁在守土与通车之间摇摆，谁给的保障更实在，票就往哪边偏。玩家可以用「隘口哨塔修复 + 护送担保」换他的赞成，也可以用「矿场材料优先」换他的沉默。

### 砾火的暗流

- **白露的哨塔**：白露守的北线哨塔已经三年没修，冬天靠烧 furniture 取暖。她多次向岑雁申请材料，都被「先保矿场」压下来。如果玩家帮她修哨塔，她会成为玩家在砾火内部最硬的支点；如果玩家也压她，她会在一次袭击后公开质问。
- **罗盘的旧账**：罗盘年轻时是个走私贩，替巡裔带过路，也替泊星者运过核心。岑雁知道，但用他，因为没人比他更懂北线。玩家可以用这笔旧账威胁罗盘，也可以用它换巡裔的信任。
- **铁砧的徒弟**：铁砧最疼的徒弟在一次袭扰中死了，他从此拒绝给「没有掩体」的民兵修枪。玩家如果要扩民兵，先要说服铁砧：枪发下去，人能不能活着回来。

## 城建与外务

- **城建主张。** 优先扩矿、修城墙、建哨塔与训练场；反对把材料花在纪念堂与温室上。同盟的地块多在外环，离炉远、热损高，所以它最支持供热优先与热站建设。
- **外务立场。** 与巡裔谈通行可以，谈驻队不行；与泊星者只做一次性修复合同，不签长期技术许可；与根庭可以做材料换粮，但不接受「为果园停矿」。
- **能给的筹码。** 职业队、矿场材料、隘口路权、哨塔与巡逻、边境情报。
- **红线。** 不交出隘口控制权；不接受没有议事会批准的民兵调动；不接受人类城池由外域驻军保护。

## 玩家作为砾火党魁

砾火开局最像「带兵打仗」，其实最难的是**让人相信你不会把他们送死**。岑雁的每一票都要担保：谁去、多久到、出了事谁负责。霍岩的每一车矿都要口粮：矿场少一班，他就敢在议事会拍桌子。白露的每一座哨塔都要人：你修了塔，就要派人守；不派人，塔就是靶子。

砾火开局最常见的支持危机是**白露的哨塔**。如果玩家连续两周把材料投给温室或医院，白露会在一次袭击后公开质问：「你保的是城，还是你的选票？」岑雁不会立刻翻脸，但会在下一次表决时要求「先修哨塔，再谈法案」。如果玩家处理得好，白露会成为玩家在边境最可靠的眼睛；处理不好，她会带着哨塔的人投向公社或止戈。

**玩家可以立刻做的三件事：**

1. 去矿场跟霍岩吃一顿班中餐，听他讲这一班少了谁；
2. 让沈砾核对哨塔的修复材料，别让岑雁觉得你在空口许诺；
3. 找罗盘问一句「北线最近谁在走」，但别问他的旧账。
