# 泊星者

泊星者来自地外，降落锚区是其在灰港附近可维持的一处落脚点。议会既希望修好与本地社会的往来，也担心技术往来被解读成无条件开放锚区。参与交换的每一方需要清楚资料会给谁、队伍能走哪一条路、什么算完成。

> **最高决策者：洛。** 观察使、工务派与议会可以建议、制约、拖延，但最终决定由洛做出。他签不了议会才能批的合同，但他可以拖延、加价、放风，也可以替人类说话。

## 领地与结构

| 节点 | 用途 | 谁管事 |
|---|---|---|
| 降落锚区 | 半截轨道电梯、议会、主工坊、粮仓 | 观察使管外务，工务派管技术，议会管授权 |
| 观测塔 | 通信、气象、寒潮预警 | 工务派；数据可以卖，也可以用来换人情 |
| 残轨场 | 旧轨道残骸、核心部件、稀有金属 | 工务派与盗采者的灰色地带 |

锚区是灰港附近唯一能看到旧时代工业的地方：半截电梯斜插进云里，工坊的蓝光在雪夜里很显眼，观测塔的扫描像一把慢慢转动的尺。镜头拉近能看到泊星者的外骨骼与人类的棉衣混在一起排队。

## 组织与分歧

**洛是泊星者的最高决策者**；观察使、工务派与议会可以制约、拖延、要求复议，但不能直接罢免他。观察使愿意用有限的修复换星图与承认；工务派愿意多接合同，但要求验收与预付款；议会最怕的是“技术换出去，锚区被围”。洛是工务派的外勤，乔述是人类的译员；两人都相信“先把词说清”，但洛更愿意冒险。

## 诉求与红线

| 项 | 内容 |
|---|---|
| 最急 | 星图与校准数据；残轨场核心不被盗采；锚区安全距离写进灰港法律 |
| 能给 | 高效修复、能源、预制件、加密通信、气象预警、联合观测 |
| 红线 | 闯入锚区核心、逆向军用技术、把泊星者拖进地面战争 |
| 会怎么打 | 不占领；精准打击关键设施、切断通信、扶持代理人、以修复为筹码勒索 |
| 最怕 | 锚区被围、补给线断、地面战争把工坊打掉 |

## 对人类的态度

关系 0 是“可以做生意，但别谈感情”。泊星者不介意人类内部谁执政，只在意合同能不能验收、锚区会不会被闯。玩家若想拿到长期技术许可，先要证明灰港能守住一条法律；若只想救急，一次修复合同就够。

## 战争与和平

泊星者的战争是技术战。边境紧张 > 60 时，通信出现定向干扰、修复报价翻倍、观测数据停供；> 80 时，锚区会切断对灰港的能源与修复，甚至精准打击水站与热站。精准打击会毁掉关键设备、杀死值班工人，但很少伤及住宅；泊星者更愿意让你“冷下来”，而不是让你“死光”。停战不需要道歉，只需要一份新的验收合同与一条被写入法律的安全距离。 [洛](../characters/luo.md) · [远星协进会](alien-accord.md) · [外域](../world/frontier.md) · [袭击与修复](../gameplay/15-raids-and-repair.md)
