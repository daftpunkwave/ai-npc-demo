# 巡裔

巡裔是地球动物谱系的后裔。氏族沿季节迁徙，长老会协调会合点、通行口述约定与族群安全。引路是一种公共责任，也是一种需要靠同行履行才得到认可的信任。

> **最高决策者：追风。** 长老会、三位族长与向导行会可以建议、制约、拖延，但最终决定由追风做出。他不是「巡裔的传声筒」，有自己的判断，也会拒绝长老会的命令。

## 领地与季节

| 节点 | 用途 | 什么时候最热闹 |
|---|---|---|
| 风隙营地 | 三氏族会合、长老会、春祭 | 春末与秋初；迁徙季前定路线 |
| 灰角渡口 | 冰河渡口、畜力集散 | 春汛后与封冻前 |
| 长尾洼地 | 冬季营地、伤兵与幼兽 | 寒潮期间；也是人类送药最容易被接受的地方 |

巡裔不建永久城。风隙营地只有半地下的石屋、畜栏与一块围起来的议事场；地图上看起来像几圈低矮的石墙和火堆，镜头拉近能看到挂在杆上的路线标记与皮囊。

## 组织与分歧

三个氏族各有族长：灰角氏族守渡口，长尾氏族守冬营，断风氏族走北线。长老会由三位族长与向导行会代表组成，负责建议与协调；**追风是最高决策者**，但他若无视某位族长，那位族长可以用「我的族人走不了」拖住执行。

内部有**开放派**与**闭路派**。开放派愿意用向导与护送换粮药，认为人类的路也是路；闭路派认为每一条给人类的路，最后都会变成哨所与墙。追风在两者之间：他愿意为同行者带路，但拒绝把备用路线交出去。

## 诉求与红线

| 项 | 内容 |
|---|---|
| 最急 | 南迁通道不被封锁；伤员与幼兽有药；牧道不被划进城墙 |
| 能给 | 向导、侦察、护送、畜力、地形情报、北线通行 |
| 红线 | 圈禁氏族、扣留向导、在牧道上建永久哨所 |
| 会怎么打 | 不正面攻城；断向导、袭补给、封渡口、把车队引到风险路 |
| 最怕 | 寒潮提前 + 灰港封路，整族被困北线 |

## 对人类的态度

巡裔不把灰港当国家，只把它当「冬天的邻居」。邻居可以借火，也可以在雪夜里抢柴。关系 −15 的意思是：愿意谈，但每一句都要有见证人。玩家若想提高关系，最有效的不是送礼，而是让一支队伍真的按约定的时间出现在会合点。

## 战争与和平

巡裔的战争是「让你走不动」，不是「占你的城」。边境紧张 > 60 时，巡裔会开始收过路费、拒绝带路、在夜里移动路标；> 80 时会袭击落单车队与孤立哨所。袭击会杀死具体的人、烧毁边环建筑，也会留下可追踪的箭、皮绳与脚印。停战不需要条约文本，只需要一次公开的会合点交接与一段时间的互不侵犯；但写成条款更容易被其他两方引用。 [追风](../characters/zhuifeng.md) · [外域](../world/frontier.md) · [袭击与修复](../gameplay/15-raids-and-repair.md)
