# 根庭

根庭是地球植物谱系的后裔。其公共生活围绕生境、幼体和根网维系，议席常用季节来讨论损失。对根庭而言，救活今天的幼圃和让同一片幼圃明年可以继续活下去，是两件都要写进约定的事。

> **最高决策者：青枝。** 园护会、幼体保育席与各根段可以建议、制约、拖延，但最终决定由青枝做出。她可以拒绝园护会的命令，也可以为人类说话。

## 领地与季节

| 节点 | 用途 | 什么时候最敏感 |
|---|---|---|
| 苔庭 | 根网中枢、园护会、粮仓 | 春季根网复苏；任何断根都会传遍整片网 |
| 深根井 | 地热井、幼体保育地 | 冬季供暖；井水下降时园护会封闭井口 |
| 灼痕果园 | 伸向灰港的前哨园圃、诊所 | 全年；灰港取水与北排水的直接受害者 |

根庭的「建筑」是活的：苔庭是一圈圈半埋的根室与菌棚，深根井是一口冒着白汽的竖井，果园的地面下能看见发亮的细根。镜头拉近时，健康的根网是暖色，缺水时变成灰白。

## 组织与分歧

园护会按根段推举，幼体保育席对任何「可能伤及幼体」的提案有强烈否决建议；**青枝是最高决策者**，可以强行推进，但要承担园护会离心。根庭内部有**守根派**与**共生派**：守根派主张封渠、退到暖谷深处，不再与人类做长线交易；共生派认为灰港的废热与材料能让根网扩出去，值得用粮药换。青枝在共生派一侧，但她不会拿幼体冒险。

## 诉求与红线

| 项 | 内容 |
|---|---|
| 最急 | 果园与深根井的水量稳定；灰港停止北排水；幼体有热 |
| 能给 | 食物、菌丝药、净水、生物材料、根网情报 |
| 红线 | 断根、抽干深根井、把幼体当作物 |
| 会怎么打 | 不远征；封渠、让根网吸水、放菌雾、拒绝供粮，必要时让整片果园枯死 |
| 最怕 | 连续两季缺水，幼体整批死，根网退回暖谷深处 |

## 对人类的态度

根庭的关系 +10 不是友好，而是「还可以谈」。它记得灰港每一次少给的水，也记得每一次送来的药。跟根庭签协议，最忌讳写「视情况补足」；园护会会问：视谁的情况、补多少、什么时候、谁来看根。

## 战争与和平

根庭的战争是生态战。边境紧张 > 60 时，果园产量下降、菌雾飘进灰港外环、水站取水变浑；> 80 时，根庭会封闭暖谷，让灰港的粮食进口断掉，也会让根网顶裂边环的地基、毁掉水站与温室。根庭的袭击很少见血，但会让建筑受损、供水污染、疾病上升；被菌雾伤到的人会留下慢性咳嗽。停战通常要「停北排水 + 补一季水 + 允许园护进灰港检查水管」三件事同时落地。 [青枝](../characters/qingzhi.md) · [外域](../world/frontier.md) · [袭击与修复](../gameplay/15-raids-and-repair.md)
