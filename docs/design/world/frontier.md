# 外域与中立遗址

灰港之外不是空地图。三片外域各有自己的季节、补给线与政治，玩家不进入它们的日常，只会在边境、会合点与谈判桌上碰到它们。每一片外域都有自己的“不能退”：巡裔不能退掉迁徙通道，根庭不能退掉幼体与根网，泊星者不能退掉锚区安全距离。理解这三条红线，比记住它们有多少兵更重要。

## 风隙牧道 · 巡裔

巡裔不建城。三个氏族沿风隙牧道转圈：灰角氏族守渡口与畜群，长尾氏族守冬季营地与伤兵，断风氏族走最远的北线、也最不信人类。长老会由三位族长与随行向导组成，每年春祭重订路线；**追风是最高决策者**，但他若绕过长老会，会失去族内支持，路线执行也会被拖慢。

| 项 | 内容 |
|---|---|
| 领地 | 风隙营地（会合点）、灰角渡口（畜力与渡河）、长尾洼地（冬营与幼兽） |
| 人口 | 约 700，分散在三氏族与十几条移动队 |
| 经济 | 畜力、皮张、肉干、向导、侦察；缺药、缺金属工具、缺稳定的粮 |
| 政治 | 长老会 + 向导行会；族长不能独断路线，向导可以拒绝带路 |
| 诉求 | ① 南迁通道不被封锁 ② 灰港不把牧道划进城墙 ③ 伤员与幼兽得到药 |
| 红线 | 圈禁氏族、扣留向导、在牧道上建永久哨所 |
| 能谈 | 过境许可、联合护送、畜力租赁、侦察交换、伤员救治、春祭观礼 |
| 会怎么打 | 不正面攻城；断向导、袭补给、封渡口、把人类车队引到风险路 |
| 最怕 | 寒潮提前 + 灰港封路，整族被困在北线 |

巡裔的承诺靠见证人。口头协议要有第三人在场，或者写成带会合点的路线条款；违约不需要法庭，下一次没人给你带路就够了。 [追风](../characters/zhuifeng.md)

## 暖谷根庭 · 根庭

暖谷的地热让根网活过了长冬。根庭不是一片森林，而是一张会记账的网：哪段根在供水、哪段在储糖、哪段幼体在等春，园护会都记得。灼痕果园是根庭伸到灰港这边的一条前哨根，也是灰港唯一稳定的果园。

| 项 | 内容 |
|---|---|
| 领地 | 苔庭（根网中枢）、深根井（地热与幼体）、灼痕果园（前哨园圃） |
| 人口 | 约 300 名园护与更多不能离开根网的幼体 |
| 经济 | 食物、菌丝药、净水、生物材料；缺热、缺金属、缺外部劳力 |
| 政治 | 园护会按根段推举，幼体保育席有强烈否决建议；**青枝是最高决策者**，可以强行决定，但要承担园护会离心 |
| 诉求 | ① 果园与暖谷的水量稳定 ② 深根井不被抽干 ③ 灰港停止向北排水 |
| 红线 | 断根、抽干深根井、把幼体当作物 |
| 能谈 | 粮食换材料、菌丝药换医疗、联合修井、净水技术、代际供水承诺 |
| 会怎么打 | 不远征；封渠、让根网吸水、放菌雾、拒绝供粮，必要时让整片果园枯死 |
| 最怕 | 连续两季缺水，幼体整批死，根网退回暖谷深处 |

根庭的时间单位和人类不一样。它们谈“这一季”时，往往已经把下一季、下下季的根算进去了。跟根庭签供水条款，最好写清“连续多少日、缺口怎么发现、谁来补”。 [青枝](../characters/qingzhi.md)

## 降落锚区 · 泊星者

泊星者是战争末期没能离开的外来者。锚区有半截轨道电梯、三座观测塔与一座还能工作的工坊。他们人少，靠技术、能源与精密修复换粮食和材料；内部有观察使、工务派与议会三股声音，对外由洛拍板，但三股声音会制约、拖延、要求复议。

| 项 | 内容 |
|---|---|
| 领地 | 降落锚区（议会与工坊）、观测塔（通信与气象）、残轨场（核心部件） |
| 人口 | 约 120，技术员比例极高 |
| 经济 | 高效修复、能源、预制件、加密通信、气象数据；缺食物、缺普通劳力、缺地面政治承认 |
| 政治 | 观察使管外务，工务派管技术与合同，议会管授权；**洛是最高决策者**，可以拍板，但三方的制约会让执行更慢、更贵 |
| 诉求 | ① 星图与校准数据 ② 残轨场的核心部件不被盗采 ③ 锚区安全距离被写进灰港法律 |
| 红线 | 闯入锚区核心、逆向工程军用技术、把泊星者拖进地面战争 |
| 能谈 | 修复合同、能源换粮、通信加密、气象预警、联合观测、技术许可 |
| 会怎么打 | 不占领；精准打击关键设施、切断通信、扶持代理人、以修复为筹码勒索 |
| 最怕 | 锚区被围、补给线断、地面战争把工坊打掉 |

泊星者的合同像工程验收：写清对象、读数、完成定义与验收人。它们不怕付高价，怕的是“完成了但没人承认”。 [洛](../characters/luo.md) · [乔述](../characters/qiaoshu.md)

## 三方的结构关系

| 一对 | 共同利益 | 结构性矛盾 | 最容易被谁利用 |
|---|---|---|---|
| 巡裔 ↔ 根庭 | 都不想让灰港继续北扩；牧道与暖谷边缘可以共存 | 暖谷北缘的水与地；巡裔的畜群会踩根网 | 灰港：用粮食或药分别收买 |
| 巡裔 ↔ 泊星者 | 都需要一条不被灰港垄断的通信线 | 锚区的巡逻队挡了北线迁徙；泊星者嫌巡裔“不可控” | 根庭：用净水或根网情报换巡裔让步 |
| 根庭 ↔ 泊星者 | 地热与净水技术可以互补 | 泊星者抽深层地热，根庭怕根网被烤干 | 巡裔：把双方的枯水账搅在一起 |
| 人类 ↔ 巡裔 | 粮食、药、畜力换通行 | 城墙、哨所、牧道归属 | 根庭：用粮价拉巡裔 |
| 人类 ↔ 根庭 | 食物、药换材料与技术 | 果园水、北排水、深根井 | 泊星者：用净水技术插一脚 |
| 人类 ↔ 泊星者 | 修复、能源换星图与承认 | 锚区安全距离、技术扩散、内部派系 | 巡裔：用路权换泊星者的通信 |

三方没有永久同盟。谁都可以和谁做一笔生意，谁也都记得上一次被谁卖过。 [四阵营与五派系](../factions/README.md)

## 中立遗址

| 遗址 | 有什么 | 谁能进 | 风险与争夺 |
|---|---|---|---|
| 战前档案库 | 旧时代数据库、星图、工程图纸、运输记录 | 任何有侦察能力的队伍；部分档案要权限或译员 | 风险 1；泊星者想先看，砾火想封锁，公社想公开 |
| 残轨场 | 轨道残骸、核心部件、稀有金属 | 泊星者名义控制；人类可以盗采 | 风险 1；被发现会掉关系，被抓会变成外交事件 |
| 旧战场 | 废金属、未爆弹、旧工事 | 任何队伍 | 风险 2；材料多，但伤病与爆炸会拖垮队伍 |
| 断讯站 | 战前中继分站，可能有备用炉芯 | 需要工程队与通行 | 风险 2；修好可给灰港 +1 热级覆盖，也可能是巡裔的圣地 |

遗址不属于任何一方，但每一方都声称自己有优先权。玩家可以把它写成联合工程、租借、共管或直接占——每种写法都会改变三方的关系。 [行动与任务](../gameplay/02-logistics-and-actions.md)

## 外域的行动规则

| 玩家想做的事 | 需要什么 | 谁会说不行 |
|---|---|---|
| 遣使 | 使节馆、一名可派角色、对方愿意见 | 对方党魁可以拒见；边境紧张 > 60 时拒见概率上升 |
| 贸易 | 商队、货物、对方需求 | 对方可能压价、要求搭售或拒绝某些货物 |
| 驻队 | 对方许可、补给线、营地 | 驻队会被视为军事存在，边境紧张上升 |
| 联合工程 | 双方各出一队、材料、期限 | 任一方内部反对派可以拖慢或破坏 |
| 战争 | 议事会动员法案 3/5、宣战理由、民兵 | 反战派系、泊星者、根庭都会趁机要价 |

外域不会因为玩家点了一个按钮就变成敌人或朋友。每一次关系变化都要有事件、交易或伤害作为来源，并且被三方各自记住。 [外交与谍报](../gameplay/10-diplomacy-and-intrigue.md)
