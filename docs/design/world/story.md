# 故事圣经

> 本页是《炉边议会》的叙事基准：主题、历史、谜团、季节节拍与结局。它不规定玩家必须做什么，只规定世界为什么这样运转、别人为什么这样想。
> 与[设定速查表](canon.md)冲突时，以速查表的数字为准；本页负责「为什么」与「后来怎样」。

## 一、主题

《炉边议会》不是「人类对抗怪物」的故事，也不是「英明领袖拯救世界」的故事。它讲的是：

1. **互相依赖。** 五派共享一台炉、一座水闸、五枚印。任何一派都不能单独把城点亮。政治不是权力的游戏，是「谁离不开谁」的账。
2. **合法性是借来的。** 玩家的一票由 8 个人托着；城里的每一派都由自己的 8 个人托着。权力不是拥有的，是每天都要续借的。
3. **记忆会回来。** Agent 记得你救过谁、骗过谁、在谁的葬礼上缺席。世界不会因为你换了存档就忘记。
4. **生存有价格。** 多送一度热给边环，通信就慢一刻；多收一批难民，粮就少一袋；多修一座哨塔，医院就少一批药。没有免费的选择。
5. **陌生人也是人。** 巡裔、根庭、泊星者不是资源点，也不是怪物。他们有自己的葬礼、法庭、笑话和底线。玩家可以与他们为敌，但很难说他们是错的。

## 二、时间线

| 约 2260 | 轨道电梯与中继网络建成；人类把能源、通信与气候管理交给「炉心协议」 | 五座中继主节点、五枚物理印、一套无人能完整读懂的协议 |

## 三、五印

中继炉不是一台普通的炉子。它是战前「炉心协议」的一个节点，控制着热、电、通信三种输出。协议被军方拆成五份，每份配一枚物理印，交给五个机构保管：

| 印 | 持有者 | 形状 | 作用 |
|---|---|---|---|
| 炉印 | 灰港公社 | 一枚烧黑的铜盘 | 授权中继的日常功率切换 |
| 墙印 | 砾火同盟 | 一枚嵌铁的木牌 | 授权城墙、哨塔与防御设施的能源优先 |
| 根印 | 地生共约 | 一枚包着树脂的石片 | 授权水闸、泵房与温室的水热分配 |
| 门印 | 止戈议团 | 一枚刻着人形的骨片 | 授权收容、医疗与撤离通道的电力 |
| 星印 | 远星协进会 | 一枚刻着轨道图的银片 | 授权远程通信与锚区联络 |

规则：

- 中继日常运转只需一印；**联合模式**（满功率、全城供暖、远程通信全开）需要至少三印同时插入。
- 三印同意，意味着至少三派愿意把命脉交到同一张桌子上。这就是 3 票门槛的物理原因。
- 五印不能由一派独占；如果一派试图夺印，另外四派会立刻知道——印被拔出时，中继会发出一声长鸣。
- **印随机构，不随席位。** 一派被吞并时，它的票与地块可以由吞并者接管，但印会进入**封存**：吞并者不能用，联合模式少一枚可用印，直到该派复权或新宪章重新指派。这是「吞并很贵」的物理原因，也是其他派系愿意为被吞并者说话的原因。
- **第六印的传说**：老砚的旧地图上标着第六个插槽，但议事厅的投票板只有五个孔。祁录知道建城档案被撕掉的 11 页与这个插槽有关；也有人说那不是「印」，而是「第六席」。

## 四、白障

「白障」不是普通的寒潮。它是尘幕、海冰与大气环流一起塌下来时形成的白色墙，能把整座城埋进三天三夜的雪里。

| 项 | 普通寒潮 | 白障 |
|---|---|---|
| 频率 | 每季末 | 数十年到百年一次 |
| 持续 | 3–5 日 | 5–7 日 |
| 热级 | −2 | −3 |
| 能见度 | 下降 | 近乎为零 |
| 道路 | +2 小时、风险 +1 | 全部关闭 |
| 外域 | 行动变慢 | 迁徙、封渠、断供、袭击都可能发生 |
| 死亡 | 可控 | 取决于准备与 coalition |

白障是整局的**压力测试**：它不直接杀玩家，它把玩家这一季所有的欠账一次性摊开——热够不够、粮够不够、医院有没有床、哨塔有没有人、盟友会不会在最后一刻撤票。

## 五、信号

2964 年，灰港中继开始收到一段重复的信号。它来自轨道残骸，间隔 47 分钟，内容是一串旧时代的导航码与一段无法完全解码的气象模型。

| 派系/势力 | 对信号的解读 | 想要什么 |
|---|---|---|
| 公社 | 这是中继的校准信号，应该公开、共享 | 用它稳定中继，避免白障期间断讯 |
| 砾火 | 这是军方的残留指令，可能是武器 | 封锁、解密、掌握在自己手里 |
| 地生 | 这是旧时代的气候模型，能预测白障 | 用它保护果园与幼体 |
| 止戈 | 这是某艘船/某个人的求救信号 | 回应它，救可能的幸存者 |
| 远星 | 这是泊星者的救援船，或别的什么 | 用它换技术、换撤离通道 |
| 巡裔 | 这是「路重新打开」的信号 | 找一条不被雪埋的迁徙路 |
| 根庭 | 这是根网深处那段「绿色记忆」的回声 | 让根网把信号读完 |
| 泊星者 | 这是他们的船，或不是 | 回家，或者确认家已经不在了 |

信号是**可选故事钩子**：玩家可以追查、分享、隐瞒、利用，也可以完全不理。它不会强制玩家做主线，但它会在白障、外域谈判与结局里反复出现。

## 六、第六席

灰港的建城档案缺了 11 页。祁录知道它们在哪，但不敢看。老砚的旧地图上有一条通往「第六席档案室」的旧隧道。议事厅的投票板有五个孔，但地板下有一个被焊死的第六个插槽。

关于第六席的传闻有四种版本：

1. **第六派**：建城时原本有第六个派系，代表「没有派系的人」——难民、流浪者、没有户籍的工人。后来五派把它除名了。
2. **第六印**：五印之外还有一枚「总印」，能单独启动中继。它被藏起来了，因为没人敢让任何一派拿到它。
3. **第六人**：炉心协议里有一个人类操作员的位置，不是派系，是一个人。那个人可能还活着，或者他的记忆还在中继里。
4. **谎言**：第六席根本不存在，是有人为了让五派互相猜疑而编的。

玩家可以追查，也可以不追查。追查会解锁额外真相与结局；不追查也能正常玩。真相不改变五席的基本规则，只改变玩家对「这座城为什么是这样」的理解。

## 七、三个非人势力的来历

### 巡裔

巡裔不是「辐射变成的动物」。他们是轨道战争期间的**信使与撤离向导**的后代：基因改造让动物谱系能在地表极端环境里工作，战争结束后，这些信使留在了冻原上，学会了用氏族、口述契约与季节迁徙活下去。

他们的牧道，其实是战前的**撤离走廊**。他们记得每一段路，也记得人类曾经把哪一段路关掉，把谁留在了雪里。他们对「封路」的敏感，不是迷信，是记忆。

### 根庭

根庭不是「植物成精」。他们是战前**种子库与生态修复计划**的后代：植物谱系在暖谷地热带上结成根网，根网深处保存着旧时代的种子与数据。所谓「绿色记忆」，是根网对气候、土壤与战争的长期记录。

幼体是根庭的下一代，也是根网的新节点。失去幼体，不只是死人，是整片根网的记忆断代。所以他们把幼体看得比交易重。

### 泊星者

泊星者是战争末期**滞留在地球轨道与降落锚区的外来者**。他们的船坏了，救援船可能永远不会来。锚区的半截轨道电梯是他们唯一的回家路，也是他们不敢放弃的执念。

他们不是侵略者。他们人少、技术高、补给线长，最怕被拖进地面战争。他们来灰港，是想找一条除了「等船」之外的路——可能是中继的信号，可能是根网的记忆，可能是五印的联合模式。

## 八、灰港的建城神话

灰港人讲建城，通常讲三个版本：

- **官方版**（公社广播）：五个机构在长冬中放下分歧，共同点亮了中继，建立了五席共治。
- **砾火版**：守备队用血守住了城墙，工务队才有时间修炉；没有墙，就没有城。
- **地生版**：第一批幸存者是跟着水源找到这里的；没有水闸与果园，城早就死了。

三个版本都不算错，但都不完整。祁录知道，建城档案里还有第四个版本：**没有派系的人**也参与了建城，但他们没有席位。第六席的传闻，就是从这来的。

## 九、叙事结构

不设固定主线。每一季有一个**压力主题**，由世界导演、玩家行为与 Agent 选择共同决定：

| 季 | 压力主题 | 核心问题 | 可能的节拍 |
|---|---|---|---|
| 第 1 季 · 春汛 | 水与路 | 轮换供水、迁徙通道、第一笔外务 | 伤员救援、果园谈判、隘口通行、第一次表决 |
| 第 2 季 · 扩张 | 地与粮 | 用地、收容、工业优先、根庭的粮 | 收容所冲突、矿场事故、锚区技术报价、第一次吞并试探 |
| 第 3 季 · 囤积 | 热与兵 | 寒潮准备、民兵动员、条约批准 | 袭击、抢修、伤亡追责、庇护交易、支持崩解 |
| 第 4 季 · 白障 | 存与亡 | 五印联合、白障、信号、吞并/庇护 | 全城动员、最后表决、白障、结局 |

每一季的节拍不是任务清单，而是**压力事件**：它们会发生，玩家可以选择怎么回应；不回应也有后果。

## 十、结局

结局不是菜单，是若干条件的组合。以下是八种主要结局：

| 结局 | 触发 | 基调 |
|---|---|---|
| **炉火不熄** | 城市活过白障，五席仍在，中继稳定 | 艰难但完整的生存 |
| **五印合一** | 五派同意联合模式，中继满功率，签署新宪章 | 脆弱的联邦，希望 |
| **一家独大** | 一派通过吞并/庇护控制 ≥3 票，其他派系臣服或流亡 | 秩序，但代价是自由 |
| **庇护之下** | 玩家接受某一派/外域庇护，保住派系但失去自主 | 生存，但屈辱 |
| **白障** | 城市在白障中崩溃，人口 <200 或中继 0 | 悲剧，但幸存者会带走记忆 |
| **信号** | 玩家追查信号并回应，轨道残骸/泊星者船/根网记忆给出真相 | 神秘，开放 |
| **出埃及** | 玩家与巡裔合作，沿旧撤离走廊迁出灰港 | 离开，但带走火种 |
| **被吞并** | 玩家失去党魁身份，派系被另一派接管 | 失败，但世界继续 |

结局之后进入**编年史**：记录存活季数、法案、建筑、死亡名单、背叛者、留下的人、城市最终状态。编年史可以带入遗产局。

## 十一、叙事规则

1. **不 retcon。** 已经发生的事件、死亡、承诺、投票不能被后来的剧情改写；只能用新证据改变「理解」，不能改变「事实」。
2. **不可靠叙述。** 历史有多个版本；角色会记错、说谎、保护别人。玩家看到的是「谁在什么情况下说了什么」，不是「真相」。
3. **秘密有边界。** 每个角色只知道自己的部分；分享需要授权；玩家不能用「上帝视角」逼问。
4. **死亡有名字。** 不写「死了 20 人」，写「死的是谁、他本来要做什么、谁在等他回家」。
5. **不审判玩家。** 游戏不设置「道德分数」；玩家的选择会带来后果，但不会弹一个「你做错了」的提示。
6. **希望是具体的。** 不写「人类必胜」，写「今天食堂的队短了一点」「穆枝多了一张床」「白露的哨塔修好了」。
7. **外域不是反派。** 巡裔、根庭、泊星者有自己的逻辑；玩家可以与他们为敌，但要知道他们为什么这么做。

## 十二、可写的场景种子

| 场景 | 涉及的人 | 冲突 | 可能的后果 |
|---|---|---|---|
| 白障前夜，医院的暖气停了 | 穆枝、陶安、阿禾 | 先修医院还是先修住宅 | 病人死亡、支持者离心、法案追责 |
| 巡裔的迁徙队被堵在隘口 | 追风、岑雁、白露 | 开哨塔还是开城门 | 关系、边境紧张、袭击 |
| 根庭的幼体需要灰港的废热 | 青枝、林芜、谷寻 | 停北排水还是保温室 | 粮、水、根庭关系 |
| 泊星者的修复队要求进核心环 | 洛、乔述、简宁 | 安全距离还是中继稳定 | 技术、主权、远星支持 |
| 温原的妹妹被砾火接走 | 温原、岑雁、阿禾 | 放人还是追回 | 物资岗位、支持态势、吞并 |
| 陆沉收到砾火的第二封信 | 陆沉、岑雁、玩家 | 留人还是放人 | 民兵、边环安全、支持去留 |
| 祁录打开那 11 页 | 祁录、闻昭、老砚 | 公开还是烧掉 | 第六席真相、公社分裂、结局 |
| 白障中，五印只插进两枚 | 五个代表 | 谁先让步 | 联合模式失败、城市冻伤、结局 |
