# 游戏背景

2964 年，长冬已经持续了六百年。轨道战争打碎了近地轨道，碎片与尘幕遮住了太阳，地表年均温度跌到旧时代的零下。幸存者没有等来春天，只等来一批还能运转的旧时代设施：中继炉。它们本是战前的通信与配电网节点，战后成了唯一稳定的热源、电源与信号源。有炉子的地方才有城，有城的地方才有政治。

灰港就是其中一座。它不算大，四百八十人，一圈旧堤、一座水闸、一台还在喘气的中继炉。它恰好卡在四条地理线的交点上：往北是巡裔的季节牧道，往东是根庭的暖谷，往西是泊星者的降落锚区，往南是战前档案库与旧战场。四方都不肯让，也都没法独吞。

## 长冬的三条硬规则

| 规则 | 物理事实 | 政治后果 |
|---|---|---|
| 热是命 | 城外年均 −38°C，寒潮时 −70°C；只有中继炉与热站覆盖的街区能住人 | 供热分配就是生存分配；靠炉近的地块贵，边环的地块便宜但会冻死人 |
| 路是权 | 雪、冰裂缝与辐射尘让道路季节性地不可用；谁控制路口，谁就能决定谁先过 | 通行许可、护送与封锁是最常用的外交筹码 |
| 信是账 | 中继同时承担通信；功率分给供热，远程应答就变慢；降到零，灰港就成了孤岛 | 通信优先还是供热优先，是每周都要吵一次的法案 |

还有一条不写在教科书里的规则：**印是城**。中继的联合模式需要至少三枚印同时插入；五派各持一枚。这不是宪法，是物理事实。五派可以吵架、可以交易、可以互相挖角，但不能把对方赶走——赶走一派，就少一枚印，整座城都可能点不亮。

## 四方的来历

| 阵营 | 从哪来 | 怎么会变成现在这样 |
|---|---|---|
| 人类 · 灰港 | 战前工务队、守备队、医政队、外务站与地方公社的后代 | 五套旧机构各自守着一部分基础设施，谁也没能吞并谁，最后谈成五派共治 |
| 巡裔 | 轨道战争的基因武器与生态改造后，动物谱系在冻原上重新社会化 | 氏族沿季节迁徙，靠向导、口述契约与畜力活着；不建城，但记住每一条能走的路 |
| 根庭 | 植物谱系在暖谷地热带上结成根网，演化出可移动的幼体与园护 | 以根网、幼体与净水为生活中心；能种出人类种不出的东西，但根网一断就整片死 |
| 泊星者 | 战争末期滞留在地球轨道与降落锚区的外来者 | 人少、技术高、补给线长；靠观察使与工务合同维持存在，最怕被拖进地面战争 |

巡裔、根庭、泊星者都不是“怪物阵营”。它们有交易、有法庭、有内部争论，也有不想被人类知道的秘密。人类也不是天然的主角：灰港只是四份势力里人口最多、炉子最大的一份。 [世界观与日常](societies.md)

## 从旧世界到灰港

| 时段 | 灰港人会怎么讲起它 |
|---|---|
| 轨道战争末期（约 2360） | 高处的通信先断，近地轨道变成碎片带。地面上的水、电与能种地的暖谷，逐渐成了聚落自己的事务 |
| 长冬最初一百年 | 大批聚落冻死或南迁。守着中继炉的工务队收留难民，慢慢形成了灰港的雏形 |
| 战后三百年 | 五套旧机构在灰港合流：守备队管城墙，工务队管炉与水闸，医政队管医院，外务站管锚区往来，公社管库房与配给 |
| 近一百年 | 巡裔的季节牧道与灰港的扩张路线开始重叠；根庭的暖谷被灰港的排水与取水影响；泊星者的锚区成了唯一能修好中继的外援 |
| 近十年 | 中继炉老化，修复需要泊星者的技术与根庭的材料；三方都开始用手里的东西换灰港的票与路；中继开始收到一段重复的信号 |
| 2964 年 | 灰港五派共治，五席议事会；城外三阵营各有使节常驻或往来；寒潮周期缩短，百年一遇的白障被提上议程 |

## 五派是怎么来的

灰港不是先有宪法再有派系，而是先有五套人马，再有议事会。

| 派系 | 前身 | 今天守着什么 | 一句话主张 | 8 名支持者 |
|---|---|---|---|---|
| 灰港公社 | 库房、配给与广播 | 中继、水闸、公库与行政 | 先让城活着，再谈谁的主义 | 闻昭、伊诺、温原、陶安、穆枝、陆沉、阿禾、祁录 |
| 砾火同盟 | 守备队与巡逻队 | 城墙、隘口、矿场与民兵 | 路要通，墙要厚，灰港不求人 | 岑雁、沈砾、霍岩、石雀、铁砧、白露、荆离、罗盘 |
| 地生共约 | 医政队与生态站 | 医院、温室、果园与水源 | 人、根、水是一件事 | 林芜、谷寻、青禾、苏木、白芨、杜若、甘棠、辛夷 |
| 止戈议团 | 救济会与停火调解人 | 收容所、救援队与谈判桌 | 先救人，再算账 | 唐箴、苏回、闻笛、沈青、陆离、白芷、顾言、韩石 |
| 远星协进会 | 外务站与译员 | 锚区往来、贸易与条约 | 灰港太小，必须向外借力 | 乔述、柯岚、叶舟、沙鸥、简宁、周野、闻莺、老砚 |

五派共享一座城、一台炉、一个水闸、五枚印，所以谁也不能把谁赶走。议事会五席，普通法案三票通过——这意味着任何一派都必须至少再找两派；宪制法案四票，任何一派都无法单独吞并另一派。[席位与表决](../gameplay/09-council-and-laws.md) · [支持与吞并](../gameplay/13-support-and-annexation.md)

## 2964 年的开局

| 事实 | 开局状态 |
|---|---|
| 中继炉 | 稳定度 45，供热只能覆盖核心环与部分内环；一次完整修复要泊星者技术或大量材料 |
| 水闸 | 优先供应灰港，果园水量从 50 开始下降；轮换与优先果园都是可谈的政策 |
| 迁徙隘口 | 六名伤员，t48 前不救会恶化；巡裔的南迁将在第 5 日开始 |
| 议事会 | 五席，各 1 票；民意支持：公社 29%、砾火 22%、地生 20%、止戈 17%、远星 12%；第一周议程待定 |
| 外域 | 巡裔 −15、根庭 +10、泊星者 0；边境紧张分别为 40、25、20 |
| 信号 | 中继每 47 分钟收到一段重复信号；内容不明，各派解读不同 |
| 世界导演 | 第一道战略指令已下达到三个外域，内容对玩家不可见，只能从使节、传闻与动向里推断 |

序章的九张局势卡仍然按原时点发生。区别是：t168 之后不再收尾，而是进入第一个完整的议事周与第一个季节。 [序章](../gameplay/05-chapter.md) · [世界导演](../gameplay/12-world-director.md) · [故事圣经](story.md)

## 历史留下的四笔账

| 年份 | 往事 | 留到今天的分歧 |
|---|---|---|
| 2956 | 灰港一夜断讯 | 有人把未获回应误报为确认送达，次日才发现一批补给根本没获准出库。伊诺坚持记发送和收讫，温原坚持分开记计划与实收 |
| 2959 | 果园枯渠 | 账面配水和实际抵达的水量不一致，一段幼圃失水。青枝把缺口延续到来春一起计算，谷寻开始保留实测和勘查版本 |
| 2961 | 隘口雾夜救运 | 岑雁守住会合点，苏回与林芜接力收治，追风提供当段向导。有一队人因模糊的口头交接迟到，唐箴从此要求说清“谁在何处接手” |
| 2963 | 第一次锚区对勘 | 乔述与洛把同一个词分别理解成“等量”和“对风险负责”。沈砾通过分段读数完成了同一晚的工务核验，争执由此能一步步复盘 |
