# 角色与 Agent 身份册

> 状态：目标设计，尚未实现。角色名册与人格契约以本文为准；数量与范围以 [首版基线](../00-scope-and-invariants.md) 为准。

## 1. 数量与职责

标准 roster 共 20 个自主身份：8 个战略 Agent、12 个角色 Agent。玩家是独立 principal，不生成 Agent；一个模型可以承载多个身份，模型数量不等于 Agent 数量。全部身份共享同一 lore 版本，各有独立目标、记忆、知情与行为权限。

战略 Agent 与角色 Agent 的职责不同，即使同派也不自动共享信息。策略层决定阵营政策与授权，角色层决定自身意愿与现场行为。不得为每次会话、任务或反思再生成一个隐藏自主身份。

## 4. Persona 内容契约

角色定义分四组字段：身份（agentId、角色类型、factionId）、能力与取向（职责/技能、价值取向、表达特征、底线）、关系与初始信息（初始关系、初始已知来源、出生地点）、装配引用（目标触发条件、profileRef、toolsetRef）。初始目标不意味着已经发生相应事件。

稳定身份与可变状态分离。长期成长通过带来源的目标/印象修订表达，不能让反思改写角色 ID、固有权限、种族能力或系统规则。任免/受伤不重置人格与记忆；新任务不是新角色。

roster 不含 provider/model/temperature/API key；模型分配从 [模型池挂载](../agent/model-pool.md) 解析。toolset 只引用共享定义及 binding，不复制 executor。人格内容也不能携带可执行脚本。

## 5. 初始关系图

岑雁与沈砾共同维护防御；林芜与苏回有救援合作；谷寻与青枝存在供水互信但有时间尺度分歧；乔述与洛有翻译合作及概念误解；伊诺与温原负责消息和配送，容易发现承诺冲突；追风对其他派系保持条件性合作。

这些初始关系来自版本化背景来源，不是默认每人知道所有私史。派系一致不必亲近，派系不同也可互相信任。初始关系强度与后续记忆修正分开，以免实验重建历史时重复累计。

## 6. 人格与行为验收

同一请求至少存在三种可辨别倾向；变化必须有当前情境或经历依据。不能让所有角色总是同意、总是道歉或每次都重述背景；拒绝时要给出合理条件、替代方案或明确底线。

每角色准备一组：无经历基线、正向共同经历、违约/误会、反证、主动任务场景。人格一致性、记忆事实与行为合法性分别评估，不能用固定台词判定“像人”。

每个 Agent 只因授权消息获知别人行动；知道秘密也未必有权公开。详细约束见 [感知](../agent/perception.md)、[记忆](../agent/memory.md) 和 [行为运行时](../agent/runtime.md)。
