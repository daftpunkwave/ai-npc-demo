# 玩家循环与派系开局

## 1. 首版体验目标

单玩家在 2.5D 沙盘中看见 NPC、寻找证据、交涉并组织行动。局势通过 Agent 的选择和世界结果变化；玩家能感到“它因为过去的事改变了现在的决定”。数字提供约束，NPC 互动提供主要乐趣。

单玩家不等于静态世界：其他派系与角色会交流、争执、提出要求、执行合法任务；但只在事件或到期触发时决策，不每帧调用模型。玩家客户端与服务端控制台分别通过 `:5173` 与 `:3000/console` 访问；玩家只看到授权投影，控制台负责三势力剧情运营、模型挂载与观测评估。

## 2. 选择人类派系

开始新 campaign 时选择五派之一。玩家是该派驻灰港特派员，不直接替代派系战略 Agent，不为玩家生成第 21 个 Agent。玩家拥有派遣与谈判的有限授权；派系 Agent 保留对政策、增援和长期协议的立场。

| 开局 | 初始接触角色 | 首个委托 | 信息/授权差异 |
|---|---|---|---|
| 砾火同盟 | 岑雁、沈砾 | 核实隘口安全并修复守备通信 | 防御设施可见，需为外部合作提供担保 |
| 地生共约 | 林芜、谷寻 | 保住果园与迁徙双方的救援通道 | 生态调查与地球种族联络优先 |
| 止戈议团 | 唐箴、苏回 | 为伤员建立临时停火与运输 | 救援授权，军事升级需另行协商 |
| 远星协进会 | 乔述、洛 | 核对修复交换中的翻译与通行条款 | 提前获得可公开的交换草案 |
| 灰港公社 | 伊诺、温原 | 整理物资与消息，召集一次议事 | 公共物流与通信渠道，特殊权限需争取 |

共同地图、基本资源与核心局势不变，避免设计五套独立游戏。初始消息、关系和任务以有来源的初始化事件产生；不直接在 prompt 偷塞未来情报。实验比较固定同一开局，研究“开局效应”时才把派系作为变量。

开局选择在当前 campaign 中固定；切换派系重新开局或建立明确的转派剧情/实验分支，不原地清空旧关系。首版不实现自由转派系统。

## 3. 核心循环

1. **观察局势**：地图、公告与角色通信显示各自已知信息；未知之处仍未知。
2. **接触人物**：点选交谈、查看公开经历、问证据、了解其主张与需求。
3. **提出方案**：谈任务、承诺、交换、担保或信息分享，允许 NPC 拒绝或给替代条件。
4. **组织行动**：选择目标、参与角色与可用物资；角色是否愿意参与由 policy 决定。
5. **等待并介入**：任务按逻辑时间结算，途中可收到求助、冲突或新证据。
6. **面对后果**：NPC 评价兑现/违约，主动回访或改变下次条件；局势进入新阶段。

玩家可执行：交谈、转交证据、提案/签协议、请求角色协作、授权内派遣、运输/救援、据点通行决议。世界内结果均由服务端规则确认。

## 4. 首章的可玩节点

| 检查点 | 玩家选择 | 观察的 Agent 能力 |
|---|---|---|
| 求援 | 先救伤员、护送迁徙还是修复供能 | 人格、派系倾向、替代方案 |
| 分水 | 争取轮换或补偿；接受暂时不公平 | 关系、权衡、协商 |
| 延迟 | 约定材料稍后送达，插入其他事件 | 前瞻记忆、主动提醒 |
| 传闻 | 相信、求证、转述或暂缓公开 | 来源归因、环境感知与不确定性 |
| 反证 | 新证据推翻旧说法 | 印象更新、道歉/坚持的条件 |
| 履约 | 完成、协商改约或违约 | 行为记忆、信任与下次授权 |

没有唯一最优路线，也不以 NPC 全部服从判胜。阶段目标是形成可维持的局势，例如轮换供水、有限停火或有监督交换；失败形成补救任务与关系代价，不立即销毁存档。

## 5. 十二角色的出场节奏

开局重点接触两位派系相关角色和一个跨派系联系人；随着消息、地点和任务触发逐步接触其余角色。十二位角色都有独立决策能力，但不同时轰炸玩家。

通知分紧急任务、承诺到期、主动邀请、公共消息四级，按队列合并；非紧急请求可稍后回应。战略 Agent 主要通过授权、信函和议事表达，不增加八个强制聊天窗口。

## 6. 界面结构

- 场景：平移/缩放、人物与据点点选、路线、位置与任务状态。
- 交互：对话、证据卡、提案、参与意愿、协议确认。
- 玩家笔记：玩家已知情报与亲历历史，不是全知事件列表。
- 人物册：公开主张、玩家获准了解的经历、关系线索与未解冲突。
- 设置：语言、显示、声音、镜头、输入辅助、图形质量、暂停/保存，以及获准的测试 preset。
- 研究入口：不放在玩家默认界面；需要从服务端控制台 `http://127.0.0.1:3000/console` 显式进入，切 profile/assembly 创建分支并查看信息与成本差异。

玩家界面由 client 域模块贡献到场景/HUD/对话/侧栏/设置 slot；替换 HUD、renderer 或人物册不改变世界结果。玩家面板不裸露全部信任数值、秘密记忆或模型 prompt。研究员才拥有深层观测权限，调试所见不能自动变成角色知识；两个本地端口与角色边界见 [双端拓扑](../architecture/two-endpoints.md)。

## 7. 可玩性验收

五种派系开局均能进入同一首章；十二位角色均有至少一个接触机会和有后果的互动；至少一次拒绝能转化为协商；兑现/违约至少影响一次后续行动；角色主动行为可追到合法事件或到期触发。

首版容量目标是一名玩家与标准 20 Agent roster。多人玩法仅保留协议扩展边界，不能混入本版通过条件。具体游戏规则见 [系统设计](systems.md)，实验验收见 [交付计划](../delivery/roadmap-and-acceptance.md)。
