## 1. 三十世纪的地球

2964 年，轨道战争结束已近六百年。幸存人类居住在光穹、地下城和散落聚落，依赖旧文明遗留设施。最后一组仍能连接聚落的通信、导航与能源中继网络，维系着文明互相看见的能力。

战争中的辐射、基因武器和漫长生态选择催生了新的地球文明。新物种的智慧属于虚构设定，不能把辐射直接等同于必然产生智慧。地球不再只属于人类；不同文明对土地、时间、个体和承诺有不同理解。

## 2. 三个非人类势力

| 势力 | 社会与诉求 | 合作机会 | 冲突来源 |
|---|---|---|---|
| 巡裔：动物后裔 | 氏族与迁徙路线；重风险共担与口述契约 | 护送、侦察、开放通道 | 封锁隘口、背弃保护承诺 |
| 根庭：植物后裔 | 根网与栖息地；重长期水土与代际责任 | 医疗材料、生态修复、缓冲地带 | 短期抽水、污染与毁坏幼体 |
| 泊星者：地外生命 | 降落锚与远距交换；内部有多种主张 | 供能修复、翻译、技术互换 | 不对等通行权、意图误读与安全距离 |

三方均可合作、敌对或保持条件性中立。物种不是道德标签；角色也不是外域最高决策者的传声筒。策划可以持续设计各方攻防与交换，不预设某方永远是敌人。

## 3. 人类五派

| 派系 ID | 名称 | 核心主张 | 内在张力 |
|---|---|---|---|
| human-independent | 砾火同盟，人类独立派 | 自主、防御与可撤回合作 | 安全优先容易错过援助 |
| human-earth-alliance | 地生共约，地球种族联盟派 | 人类与地球新种族共治 | 对泊星者不信任，盟友诉求也会冲突 |
| human-pacifist | 止戈议团，和平派 | 保护平民、避免升级、坚持救援 | 停战不能自动消除资源压力 |
| human-alien-accord | 远星协进会，主和外星生命派 | 以可监督的交换寻求出路 | 必须面对技术依赖和主权风险 |
| human-neutral | 灰港公社，中立派 | 保持通信、贸易与调停通道 | 中立也要承担决断与资源成本 |

玩家的席位是出身、初始授权与关系，不是强制结局。设计支持五席；本切片只开放公社席。派系可修订政策，但不能因一次聊天无代价逆转基本立场。

## 4. 灰港及六个节点

灰港是中继网络的交汇点，也是四种文明仍能会面的中立区。六节点道路图支撑序章全部行动：

| 地点 ID | 地点 | 独特压力 |
|---|---|---|
| grayharbor | 灰港中继站 | 通信、聚落议事、供能维修 |
| watergate | 旧堤水闸 | 分水、控制与轮换承诺 |
| orchard | 灼痕果园 | 根庭栖地、医疗材料与生态损害 |
| pass | 迁徙隘口 | 巡裔路线、护送与封锁 |
| archive | 战前档案库 | 证据、历史争议、误读 |
| anchor | 降落锚区 | 泊星者修复交换与通行权 |

地图和道路属于内容包，NPC 不会凭语言创造新路或新设施。设计地图共 13 节点/16 路；外域 7 节点/7 路在 t168 后启用，本切片不加载。场景可以扩展节点，但须同步内容 schema、感知范围和验收场景。

## 5. 可持续的剧情框架

剧情按“压力、提议、承诺、行动、后果、新压力”的循环推进。策划发布局势卡；Agent 与玩家在规则内回应，形成暂时均衡。攻防与结盟来自事实事件；结局不由隐藏的总导演 Agent 强制制造。

序章“水闸之前”只规定共同压力：灰港供能不稳、迁徙季临近、果园面临失水，泊星者提出修复交换。允许联合轮换、补偿式封锁、受监督援助等路径，也允许符合规则的其他组合。

## 6. 真相与叙述

公开 lore 是所有 Agent 可读的共同背景；未发布剧情、秘密行动、玩家私聊和角色回忆不是 lore。历史文献可以存在不可靠叙述，但必须标明作者/出处；客观事件与其解释分别存储。

旧战争的未知真相可成为后续内容，但不能反向改写已经记录的世界结果。策划修订通过新版本和必要的新事件表达。角色设计见 [角色册](characters.md)，玩法见 [玩家循环](gameplay.md)。
